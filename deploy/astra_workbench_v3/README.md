# 中性回路承保决策工作台（前端 v3）

独立设计的新工作台前端，纯静态（原生 ES 模块，无构建步骤）。只消费工作台服务 `tools/astra_workbench_v20.py` 的同源接口。

## 页面结构（信息密度从高到低）

1. **状态条**：现价与事实时效、空间门（关闭为琥珀色，并标明已关闭多久）、运行中的 FMZ 版本、持续采集来源的健康度、今日复核额度、登录。
2. **价格地图（空间层）**：一条价格轴，三条轨道，按屏幕实际宽度绘制，文字保持真实像素大小。
   - **责任区**：两侧短腿到保护腿，颜色越深赔付越深；到期前隐含预期波动及其 2 倍（按百分比标注）；盈亏平衡。
   - **Gamma 结构**：周度与 0DTE 墙，高度按 √|GEX|，正值向上（蓝），负值向下（紫）；另有翻转位、磁吸位和最大痛点。
   - **成交与成本**：KPF 接受区与链上成本（短期、长期、全体）。
   - 超出视窗的价位收在两侧边缘，只列最近两项并计数其余。
3. **本轮前置条件**：一行说明两侧共同的承保前置条件是否满足（空间门、μ 来源）。观察复核与锁定追踪不受其限制。
4. **两问决策卡**：Put 在左、Call 在右，与地图方向一致。
   - 关键数字：短腿距现价（贴近时变色）、盈亏平衡距现价（区分“不存在”和“未能计算”）、短腿 Delta 与选约规则、信用占宽度（含净信用、费用是否为假设、报价时间）。
   - 距离标尺、四要素对本单的方向对照（固定规则）、Q1/Q2 要点（标明模型解释或程序摘要）。
   - 操作：观察复核、锁定追踪。两者都需要登录，并在页面内二次确认；冷却时显示剩余时间。
5. **四要素读数**：空间结构、量价路径（TMV、15 分钟动量、路径效率；无移动时不计算）、主动成交（4h/12h CVD，积累中单独标示）、宏观环境。
6. **推理审计**：模型逐点结论 ↔ 证据账本。
   - 点击结论，高亮它引用的证据；点击引用，定位到对应证据。
   - 回执还列出程序护栏选出的支持、反证与重新评估条件。
   - 没有模型回执时显示程序读法、两问完整摘要和同一保单的窗口变化，并给出程序证据链接。
7. **锁定追踪**（位于决策卡下方；有追踪进行时状态条显示"追踪中 N"，并自动展开最新一条）：点击一行在原位展开。
   - **锁定时**：短腿距离、固定盈亏平衡价、扣费后信用、最坏到期亏损，以及币本位到期赔付曲线。
   - **锁定后过程**：同一时间轴上的三条泳道——现价相对锁定时的短腿、保护腿、盈亏平衡线；按当前平仓报价估算的账面结果；空间门、主动成交（相对本单有利/不利）、Gamma 体制的状态条。标出采样缺口与实测采样间隔，鼠标悬停读数。
   - **之后的变化**：按当前平仓报价估算的账面结果（不是成交盈亏），距离与报价各项的锁定时、最新与变化。
   - 市场背景与两问摘要的变化、采样过程（点数、覆盖、最长间隔、缺口按原因汇总）、读法说明。
   - 操作：停止追踪；已停止且未到期的追踪可以用最近一点重新开始。
8. **资金与慢背景**：资金费、永续 OI、ETF、链上成本、已实现盈亏、期权情绪、外部资本条件。
9. **数据与审计记录**：来源分为持续采集、按需记录、本机不采集、不消费四组；空间门变迁、每日快照、邮件通知、版本身份（运行版本与发布清单不一致时提示）；主链路审计日志（按日文件、记录与事件数、哈希链状态、原文链接，说明见 `docs/astra/CHAIN_AUDIT_LOG.md`）；定时模型复核（每天 UTC 02:00 / 14:00 两侧各一次，下一次时间与上一轮结果）。

## 接口

| 用途 | 方法与路径 |
|---|---|
| 页面主数据 | `GET /api/workbench?view=page`（页面投影，只含本页用到的字段，压缩后约 60 KB；每 30 秒轮询，标签页隐藏时暂停） |
| 锁定过程 | `GET /api/workbench/locked-candidates/<id>/series` |
| 审计日志 | `GET /api/workbench/chain-audit`（索引）、`GET /api/workbench/chain-audit/<文件名>`（JSONL 原文） |
| 复核进行中 | `GET /api/workbench/review-state`（只在有复核进行时每 5 秒查询） |
| 锁定对照 | `GET /api/workbench/locked-candidates/<id>`（展开中的追踪随页面刷新） |
| 会话 | `GET` / `POST`（`Authorization: Bearer`）/ `DELETE /api/workbench/session`；令牌只用于换取 HttpOnly 会话 cookie，页面不保存 |
| 观察复核 | `POST /api/workbench/review`，`purpose: "observation"` |
| 锁定 / 重新追踪 | `POST /api/workbench/locked-candidates`（重新追踪带 `new_reference` 与 `source_episode_id`） |
| 停止追踪 | `POST /api/workbench/locked-candidates/<id>/stop` |

## 本地预览

预览服务器 `devserver.py` 放在会话 scratchpad，不进仓库。它把 `/api/*` 只读转发到 EU 工作台（经 SSH 隧道），拒绝一切 POST/DELETE。

`?fixture=1` 加载由当日真实冻结快照与真实模型回执拼成的示例数据，页面顶部会明确标注“示例数据”。示例文件只在本地预览提供，线上打开会提示不可用。

## 部署（待用户确认“当前本地页面可推送”后进行）

把本目录复制到工作台静态根目录的子目录，例如 `/opt/signal-audit/workbench-v3/`，再访问 `/workbench-v3/`。

现有页面不受影响，无需修改服务端代码。

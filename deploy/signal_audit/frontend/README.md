## 当前页面口径

沿用正式页面的报告式布局：受控正文宽度、章节标题与说明两栏、整块灰底审计结论、白底证据行。评级和推理链并入同一审计报告，避免各数据同权平铺。

- v2 新卡主阅读顺序为：最高辅助交易决策（行动、两侧评级、有效适配判断与量价/主动流倾向）、空间约束动力学、关键变化骨架、LLM 独立复核意见、下一观察与失效条件、中文市场事实及完整审计资料下载。结论在前，具体数值在后。
- 独立复核先给出同一次模型评审明确填写的价格倾向（偏多、偏空、中性或多空分歧），接依据、主要反证与改变判断的条件，再读两侧适配论证。价格倾向不从价差等级或文字关键词反推，不改评级/行动许可。旧卡未单列方向时明确提示，不补造历史模型结论；方向局部无效时保留合法两侧评级。仍是一次模型调用。
- 空间模块解释墙位的相对触及距离、Gamma 反馈及压力响应，退出三列事实摘要复述。只采用可用事实；过渡区或体制缺失不能因净 Gamma 为正就升级为抑制。净规模不另算强弱分，体制与净值相悖时显示分歧。
- 净Gamma摘要沿用美元与M单位，例如`+$243.84M`，完整数值保留在事实区。导航用轻量标签，证据入口和正文回链使用统一的墨色样式，保留键盘焦点及手机换行。
- 市场事实不按固定数量截断，0值、缺失与陈旧事实默认可读。最后的数值附录采用正式版的紧凑网格，墙位与对应距离相邻；重复数值句、一般解释和采集时点进入“来源时点与解释边界”。支持、反证、竞争解释和评级缺口保持默认可读；有效适配判断只在顶部全文呈现，独立复核提供回链。
- 关键变化只读取本版已核验的变化事实。仅有差值时就显示差值，不倒推前值、不恢复未经核验的旧变化对象；无有效变化时用一行提示，具体原因可直达下方缺口。
- 证据来源按中文主题归并导航；来源数目不表示独立证据票数。无效侧的原评审始终明确标为未采纳。
- 新卡消费 `signal_evidence_summary@2.0.0` 和详情内的 `side_evidence_ratings` / `local_action_state` / `market_facts` / 可选 `price_bias@1.0.0`，并用摘要中的结果校验标记绑定详情对象。主审计schema保持2.0.0，Prompt扩展为2.0.1；2.0.0历史Prompt仍可读。
- 本地`design-preview/`为独立模拟展示页，明确标识模拟方向、评级及六项变化；不回填真实历史卡或生产档案。变化的共同窗口/时点合并，例外时点保留在对应行。
- B/A/S 表示该侧适配解释的总体证据强弱；行动准备由本地边界另行说明。等级不表示胜率，缺候选报价时也不能声称具体价差值得成交。
- v2 新卡不并排渲染旧最高 advisory、旧 LLM 深入区、独立 24 小时长报告、旧置信分、耐用分或底层公式。
- 旧 `side_comfort_ratings` 只作为历史行动评级阅读，不能进入 v2 的“B及以上”和“A/S”筛选。
- 普通阅读页不展示内部路径、schema、哈希、公式、权重、旧置信分或耐用分。需要完整机器资料时，使用页面底部“下载完整审计资料”。
- 来源链接以“空间结构”“价格路径”“主动成交”“资金费率”“宏观背景”“变化与缺口”等中文名称跳到市场事实区。
- LLM 错误、旧卡缺字段、单卡加载失败都以中文状态隔离，不能影响其他卡加载。

## 边界

- 前端只展示审计数据，不生成信号、不修改旧算法、不改变通知、触发、WAIT/BLOCK、交易许可或执行权限。
- `signal_evidence_summary` 是发布层认可的 v2 列表来源；详情页完整评级必须与该摘要的结果校验标记一致。页面不重新评分，也不另算全局总等级。
- 旧 24 小时推断只作为历史深层辅助说明；v2 新卡不在普通页面显示独立 24 小时长报告。
- 后续涉及前端内容变更，仍需中文语义、桌面/移动样式、链接可达性、加载隔离和渲染契约测试；提交、推送或部署前必须经过本地页面浏览器确认门。

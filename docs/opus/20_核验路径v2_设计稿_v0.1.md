## 1. 为什么改

现行路径 `dp-2026-10-14.1` 设计于 12–17 号研究之前，读法是“位置 → 运动 → 外部 → 变化 → 风险质量 → 补偿”。按已有结论，它有以下问题：

| 位置（`tools/astra_decision_path_v1.py`） | 现状 | 冲突的结论 |
|---|---|---|
| D2 `:300-303` | “空间位置相对有利”显示为绿色 | X：空间位置不能当缓冲，且用的是周度 / 0DTE 墙（17 号 §3.4） |
| D2 `:51-53, 298` | “正 Gamma 收敛”“短腿处对冲逆势”显示为绿色 | 口径：GEX 不带符号，无法判定钉住还是加速（17 号 §7.2） |
| D3 `:343-349` | 量价 24h/48h 与主动成交按票数比较，“背离责任区”显示为绿色 | A：方向不能逐日外推；C：这些读数多为同源（17 号 §2.4） |
| D5 `:388-402` | 再次使用 24h/48h 量价，第二次计入 Q1 | 同上，重复计数 |
| D4 `:370-375` | 宏观“顺风 / 逆风，朝某侧责任区” | 方向类读数；公开信息已计入一天期报价（B，17 号 §2.2） |
| Q1 `:447` | 没有不利项时，显示绿色“未见指向责任区的读数” | 17 号 §1：没有明显预警不是做的理由 |
| Q2 `:492` | IV 低于近期实现时标黄色警示 | “隐含低于实现 = 危险”已撤回（16 号第 4 条） |
| 全路径 | 没有“时间”这一维 | 风险按时段分布（A）；建仓时点（B）；否决层；未触及时剩余风险衰减（B） |
| 全路径 | 没有执行和持有计划 | 执行是唯一不依赖预测的杠杆（17 号 §6）；持有中按时钟管理（§4） |

## 2. 原则

- 正向判断只有一处：Q2 的价格与执行。其余各步只能给出否决或描述。
- 色调规则：
  - 绿色只用于有 A/B 级证据支持的“风险较低”描述；
  - X/C 级读数和口径说明一律用中性色；
  - “没有否决项”不用绿色。
- 每一行读数都在 `basis` 中写明等级与出处。测试强制执行这些规则。
- 路径仍是纯函数，不调用模型，不给概率。

## 6. 实施与审查后的修订（2026-10-26）

独立代码审查发现 3 个必须修、9 个建议修，均已采纳。下面几处与 §3 的原设计不同，以本节为准。

1. **D2 缓冲分档改为相对于标准短腿。**标准 0.35Δ 短腿本身约在 0.4 倍预期波动（17 号 §3.2），原来“< 0.5 倍为窄”会让几乎每张候选都显示否决。现在的分档：
   - 已进入；
   - 窄：< 0.25 倍，明显近于标准，否决，阈值未验证；
   - 标准附近：0.25–0.55 倍；
   - 较远：≥ 0.55 倍。
   - 后两档都只作描述，用中性色。
2. **D3 不再是否决。**原条件因为缓冲门槛的问题，退化成了“剩余 12 小时以上，且 15 分钟走势朝短腿”，而 15 分钟走势没有检验过的预测力。现在只作说明（黄色）：早段若被触及，约四分之一会走到保护腿。
3. **建仓时点只作描述。**附录 A 中只有“16:00 优于 08:00”达到 B；08–12 与 20–00 都和 08:00 相近。原设计的“最差时段否决”说过了，17 号同步作更正。T 步写“16:00 前后为较好时段，其余时点与 08:00 相近”，并且只对 08:00 交割、剩余 ≤ 24.5 小时的合约给出。
4. **Q1 只汇总三类否决：**D0 资料缺口、T 否决层触发、D2 已进入或窄。
   - D4 事件不进否决：公开事件已计入一天期报价（B），落在持有期内的时段风险已由 T 步的窗口和否决层覆盖。
   - 否决层“高波动窗口且缓冲不足”附注 17 号 §3.2 的冲突说明，修订仍待用户决定。
5. **本期状态（21 号）：**
   - 只在 08:00 交割的日期权、且使用本合约自身 ATM IV 时显示；
   - 措辞写明“边缘、未证明大于其他状态、一个半年反向”；
   - 不进否决汇总。
6. **否决层数据：**核验会话从页面已有的读视图取否决层；视图没有时按同样规则当场计算。原实现中会话拿不到否决层，T 步永远显示“不可用”。
7. **兼容旧版本：**
   - v1 会话照常打开和标记 D5，记录按会话自己的步骤保存标记和“定于哪一步”；
   - 报告按各版本自己的步骤顺序汇总；
   - 刷新时版本不同，只比较共有的步骤，并写明版本已变。
8. **其他：**
   - 成交口径成本按正负号措辞；
   - 持有计划跳过正在进行的窗口；
   - D0 写出 FMZ 事实的年龄；
   - 案卷 0.1.7 的 L8 标签不再写死步骤名；
   - 依据的显示：单列时显示在数值下方，开始与现在两列对照时显示为悬停提示。

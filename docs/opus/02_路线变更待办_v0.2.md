## 上线门（替代影子运行）

全部满足后，新链路接管定时时段：

1. 案卷体量与覆盖：L0–L8 无静默缺层；缺数据的层显式标为 `unknown`。
2. 提问者在最近一批离线样本（≥10 份，含 Put/Call 与不同市场状态）上：
   - 前提数值校验通过率为 100%（程序校验）；
   - 被整份作废的为 0；
   - 用户评审认可“事实讲清、问题高价值”。
3. 至少 3 份外部 Agent 报告完成两段流程，用户认可它们可以作为决策参考。
4. 回归维持基线；自检无新增 FAIL。
5. 🔒用户确认上线。上线时一并决定旧 `evidence_points` 定时复核是停用还是保留：代码与回放保持冻结，只决定是否继续调度。

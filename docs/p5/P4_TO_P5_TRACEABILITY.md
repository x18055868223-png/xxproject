## 明确不采纳的研究项（控制复杂度）

- **不直接晋级完整 `@1.1-candidate`**：无择侧提升证据，却增加强冒号固定段落约束（3,306 字节 > `@1.2` 的 3,073 字节）。
- **不将 `@1.0` `astra_player_rulebook.md` 或独立二次 LLM 抽 C 环节接入 v1.3**：规则已随 User `input.md` 注入，且后验二次调用会使成本翻倍并破坏首次承保一致性。
- **不把 C 接入任何自动止损、拆腿或改仓**：P4 零实证支持 C 具备可替代 M 的止损准确度。
- **不在 `astra_player_input_v1.py` 引入针对 H2/H3/H4 的特例规则或从 `outcomes/` 反推提示词**。

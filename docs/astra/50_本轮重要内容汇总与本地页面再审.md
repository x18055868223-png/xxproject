固定置顶的 R17 裁定已经从页面首屏移除。R17 的商业裁定仍保留在研究文档中，但不再作为每张审计卡顶部的固定输出，避免把已收束的保单研究结论误读为卡时动态判断。

页面新增“本轮重要内容汇总”栏。该栏按当前卡面和验证数据生成摘要，用来优先提示交易员这张卡本轮最值得注意的变化、异常、限制和缺证据项。它不是固定文案，也不新增统计数值；当卡面没有足够证据支撑某项判断时，应明示证据不足。

摘要先读取当前卡已核验的两侧比较与联合复核限制，再读取与本卡绑定且通过哈希核验的前后变化；无可比前卡时显示缺口。每栏最多四项，异常优先。17:10 卡显示“联合建议暂不采用”，随后显示 TMV `-0.5429 → -0.2881`、净 Gamma `$126.75M → $162.95M`、Pin `78,000 → 80,000 USDT`；07:12 卡显示 Call 侧证据比较，并说明前后变化暂不可用。这些变化仅是两张卡的时点差，未进入当时模型评审，也没有同期净信用。卡面下层仍保留完整关键变化骨架、来源和原始意见；不以新价格再平衡影子事件替代自然卡效果。

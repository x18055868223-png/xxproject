# 末日垂直价差的局部最优方案

## 1. 核心结论：用少量条件分支替代全市场统一规则

更合适的主方案是：保持有保护腿的信用垂直价差基座，用少量前置条件区分“单侧承接”“压力继续传导”“双侧收缩”，分别比较Put、Call或不进入。卖出腿允许贴近、等于或越过结构位，取决于少赔的钱能否覆盖少收的权利金；不设置统一Delta或距离门槛。

这比“信号偏多就卖Put，偏空就卖Call”多了一层必要判断：相同的负主动流，既可能是下行仍在穿透，也可能是抛压已被消化。前者通常需要审视Put风险、研究Call；后者可能构成Put的局部机会。决定分支的是结构、压力及同窗价格响应的关系，符号本身不够。

本轮能严格证明的是各类改变何时改善收益，而非宣布已经找到历史和未来都最优的参数。最值得优先保留的组合是“单侧机制识别 + 少量腿位比较 + 失败情景”；双卖和对冲保留为具有独立成立条件的分支。报价缺失不妨碍推导取舍边界，也不妨碍计算对冲的平均增量；它限制的是对具体历史净收益和当前成交价值的确认。

| 候选分支 | 为什么可能改善 | 不应被偷换成 |
|---|---|---|
| 单侧承接后卖该侧 | 下行或上行侵入较难继续，降低该侧尾赔 | 触到墙就必然反弹 |
| 压力传导时卖相反风险侧 | 分布远离该侧赔付区，同时反向尾部仍受约束 | 量价负就机械卖Call |
| 双侧收缩时分别评估两侧 | 两份补偿可能覆盖两侧合计赔付 | 中性标签就无脑双卖 |
| 向外调整短腿 | 少赔的收益大于放弃的信用 | 越虚值越安全、越好 |
| 失效后有限对冲 | 在侵入继续而非恢复的状态下抵消损失 | 触腿后无条件对冲 |

“局部”应当指可在入场前识别的一类机制，不能指看过结果后圈出一群赢家。现有样本支持继续研究这些分支，但不足以给其未来优势背书。


## 2. 统一数学目标：改善赔付，而不是只抬高胜率

以1 BTC名义、卖出行权价K、保护宽度W、到期交割价S、已扣成本净收入C为基础，BTC币本位两腿赔付为：[1]

`X_put(S) = [max(K-S,0) - max(K-W-S,0)] / S`

`X_call(S) = [max(S-K,0) - max(S-K-W,0)] / S`

`Pi = C - X(S)`

因此净盈利率为P(X<C)，平均盈亏为C-E[X]。两者不是同一个目标。更高胜率若伴随更薄补偿或更大平均亏损，可以降低长期平均表现。侵入仍按到期净亏损定义，不把盘中碰到卖腿直接判负。

同一组前置信息I下，把做法a换成b，改善平均收益的精确条件是：

`Delta = (C_b-C_a) - E[X_b-X_a | I] - 额外成本 > 0`

若C已经净扣全部费用，不再重复扣成本。不同保证金或持有期限时，还需比较资本占用与尾部承受能力；不能只比较每份1 BTC合约的均值。这里的“>0”是经济恒等式，不是已经估计到小数点的现行交易门槛。

局部规则不需要战胜全市场的每一种做法。若条件组X外仍执行基准，X内替换后的平均改善为P(X)×E[Delta|X]，再扣识别与操作成本。只要该值为正，就可以改善总体期望；但若重复信号共用资金、持仓互斥或持有时间改变，必须按实际机会集合比较，不能把局部高APR直接相加。

长期生存还取决于仓位。在财富始终为正、收益矩存在的范围内，较小仓位f的对数增长近似为：

`E[log(1+fR)] ≈ fE[R] - 0.5 f²E[R²]`

这是泰勒近似，不是用114张样本求“最优Kelly仓位”的许可。它说明削减尾损可能比提高胜率更重要，也说明降低波动但牺牲少量均值有时仍可改善资本增长。[2]

必须保留币本位边界：两腿美元内在价值差至多W，但Put的BTC赔付W/S在深跌时会扩大；不能称为固定BTC最大亏损。BTC收益与美元账户权益变化也不同，BTC抵押品本身的价格变化另有影响。新增对冲后，原期权保证金不能充当整个组合的真实保证金分母。


## 3. 空间约束为什么可能有用：反馈机制与失效混合

墙、Flip、Pin和Anchor是不同性质的观测或加工结果。位置关系本身只说明几何距离；它们要产生交易价值，还需要某种使不利推进减弱的机制。例如局部对冲需求、订单承接或冲击后的供需恢复。当前OI推算净GEX不能直接等同于做市商真实净持仓，更不能单凭正号证明有稳定回复力。[3]

一个局部线性示意可以说明机制。设外部净流量u、价格冲击系数lambda>0、真实对冲流对价格的反向斜率G；若对冲近似即时且线性：

`DeltaS = lambda × (u - G×DeltaS)`

`DeltaS = lambda×u / (1 + lambda×G)`

G>0时，反馈在这组假设下削弱冲击；G<0且分母仍为正时会放大。若分母接近零、对冲延迟、深度骤降或交易商实际持仓估计相反，模型失效。现有“净Gamma多少M”与这里的G单位、定义并不相同，不能把看板数值直接代入。这是解释反馈的玩具模型，不是已估计的BTC价格方程。

即使存在回复力，也必须看回复中心与卖出腿的位置。围绕价格锚的低波动，只有在其主要分布落在本侧较少赔付区域时才有利。若价格已经跌入Put赔付区并在低处稳定，波动更低可能让亏损更确定。垂直价差的赔付曲线不是全局凸函数，“波动越小，期望赔付越低”不是普遍定理。

无需建立持续数值贝叶斯系统，也能把结构问题压缩为两个竞争机制。设约束维持时平均赔付为l_hold，破坏时为l_break，且后者更大；约束维持的条件概率为rho，则：

`E[X|I] = rho×l_hold + (1-rho)×l_break`

`rho > (l_break-C)/(l_break-l_hold)`

这个阈值说明：需要相信结构到什么程度，取决于补偿和破坏后损失。不是所有机会都需要同样“完美”的证据。若C已超过两机制赔付，均值上不再依赖高rho；若C连维持状态的赔付也不够，仅提高相信程度无法挽救。存在第三类严重机制时，应扩展混合，不能硬塞进两类。

示例均以W/S0归一化，完全是假设：l_hold=2%、l_break=40%。C为10%时rho阈值约78.95%；C为6%时约89.47%。这是补偿越薄、需要的约束优势越强的数学解释，不是当前信号已达到这些概率。


## 4. 最少的信息：区分赔付相关机制，而非解释所有行情

真正需要的信息可以收束为三类关系：价格与赔付区在哪里；不利压力是否正在传导；如果当前解释错了，损失会怎样扩大。无需先准确预测完整24小时路径，也无需先把所有因子压成一组概率。

Blackwell意义上的更多信息，在正确概率模型、可自由使用或忽略信息的决策问题中不会降低最优价值。现实中使用错误模型或反复挑选样本，可以把这项理论优势变成损害。信息量、解释长度和真实交易增益不能划等号。[4]

可以使用贝叶斯推理结构而暂不输出数值后验：比较“如果存在承接，这种压力与价格响应是否常见”和“如果正在破坏，这种响应是否仍然容易出现”。负CVD配合价格稳定，只能增加承接解释的可能性；错窗、低成交、价格源差异或潜在大单未出现，也能解释它。不能把“吸收”文字当作观测到了隐藏订单。

同源事实应按依赖组织。墙、净GEX和Pin可能来自同一批期权资料；TMV和主动流可能重复包含同一段价格确认。新增一个名字不应再次累加独立证明力。宏观与Funding在确实改变风险时参与，不强迫所有来源投票。

对于有限个候选，在只比较均值时，足够的信息是它们各自的E[X|I]或候选之间的E[DeltaX|I]；不必估计市场的每一个可能状态。需要比较胜率或尾损时，再补相应的P(X<C)和尾部损失范围。D–S可以继续组织证据，但无需先变成概率，也不构成局部规则的硬许可。

条件识别本身也有门槛。假设正确切换平均改善a，误判平均恶化b，识别及操作成本c，状态识别准确率p，则：

`p×a - (1-p)×b - c > 0`

`p > (b+c)/(a+b)`

当a=4、b=16、c=0.5个同一收益单位时，需要p>82.5%。这不是预测涨跌准确率，而是“是否该采用这条局部方案”的准确率。错一次损失很大的方案，应需要更强的识别依据；小幅、可逆的腿位调整可能允许较弱依据。若损益不稳定或依赖状态强度，应直接使用完整条件期望，不能迷信二元简化。

有用的门控应是：输入可得、论证针对本侧赔付、相对收益有正向机制、误判成本可承受、与基准比较不靠事后挑选。样本数达到10或某个评级达到A，均不能替代这些条件；也不要求所有来源齐全才允许研究。


## 5. 两个优先单侧定式，以及一个次级双侧分支

### X1：承接存在，压力传导减弱，研究承接侧

Put示例：下方存在来源可用的结构区域，现价与候选赔付区有合理关系；曾出现卖压，但在同一观察窗内，下行推进明显弱于此前，或价格恢复而结构没有同步向下撤退。方向可以中性，主动流也可以仍为负。需要的是“卖压不再以同样效率侵入”，不是所有指标转正。

候选是下侧有保护腿的Put价差。可比较较近短腿与结构附近短腿：前者多收的钱是否值得承担更多赔付。局部增益来自降低下行尾赔，而非押注大涨。主要竞争解释是短暂流量间歇、结构失真或即将发生的新冲击；若价格继续推进、结构随之下移、近端响应重新增强，应削弱承接解释。Call镜像成立，但不能假设两侧数据表现必然镜像。

### X2：压力确实传导，反向风险受约束，研究另一风险侧

Call示例：主动卖压与价格下移在同窗一致，下方承接尚未成立；但上方存在可解释结构，近端反弹不足以重新侵入上侧候选赔付区。此时研究Call，是因为上行赔付分布相对更有利，不是因为“负指标越多，Call等级就越高”。

主要竞争解释是卖压耗尽后的反弹、上方约束失效或宏观冲击。若当前价格离上方短腿已经很远，但Call权利金也几乎耗尽，方向正确仍不等于值得卖；若此时转去卖Put，也必须回到X1证明承接，不能只因为Put报价厚。向上压力持续时，Put为镜像候选。

X1与X2面对同样“量价负、主动流负”可以给不同答案。这是条件分支比统一方向规则更有解释力的地方：先判断压力属于继续推进还是传导受阻，再比较赔付与收入。

### X3：双侧约束与补偿共同成立，才研究双侧组合

若两侧均有可解释约束、主要分布处于两条赔付区之间，双侧组合有机会。但第二侧必须证明其新增净补偿覆盖新增预期赔付，并考虑额外资金和尾部风险；一侧便宜不是另一侧自动成立的理由。同到期两边通常不会同时达到最坏内在赔付，不代表到期前组合保证金必然减半。

已有无脑双卖对照中，信号样本相对同日期/期限对照的情景回报差仅约+0.027个百分点，区间跨零。中性48张双卖胜率68.75%，情景回报仍约-0.24%。因此X3保留为次级条件分支，不作为中性标签的默认动作。[5]

这些条件描述是建议式研究定式，不是已通过实盘检验的规则。所有分支都允许“当前比较优势不足，继续等待”；等待必须有下一观察目标，不能成为永远缺最后一项证据的空转。


## 6. 腿位局部优化：不强制远虚值，比较交换斜率

固定到期和宽度，Put短腿向下移、Call短腿向上移，在每个到期价格上都不会增加赔付。因此，无需预测未来也能证明“远移可能少赔”。但若价格穿过新旧两条保护腿，二者赔付又都是W/S；外移主要减少部分不利区域的赔付，并没有消除最深尾部风险。通常还会少收权利金；改善均值的条件是：

`放弃的净信用 < E[原赔付 - 新赔付 | 当前条件]`

若两候选保证金不同，则还需另比较资金效率或统一风险预算。墙位可以帮助提出候选，但不能让经济比较失效。较近短腿只要额外收入超过额外尾赔，就可能优于更远短腿。相反，远腿即使胜率高，信用损失过大也可能更差。

本轮用114张普通轮的原入场、到期和实际合约做了一个不补造报价的诊断：在卡时墙位可用且仍位于现价相应一侧时，将最近OTM短腿移动到墙位或下一外档；严格保持原保护宽度，合约须在入场前已创建。没有同宽保护腿即列缺失。

| 同侧实际发生移动 | Put | Call |
|---|---:|---:|
| 可比较卡数 / 独立交割日 | 45 / 32 | 64 / 38 |
| 平均向外移动 | $1,622 | $2,422 |
| 原平均赔付 / 原W入场折算价值 | 10.43% | 10.20% |
| 新平均赔付 / 同一折算价值 | 2.69% | 0.48% |
| 样本内允许少收的信用比例 | 7.74个百分点 | 9.72个百分点 |
| 到期实现未节省赔付的卡数 | 30 / 45 | 34 / 64 |

这里的比例是总BTC赔付除以总(W/S0)，不是保证金收益率。7.74/9.72个百分点是整个组的历史信用损失交换预算，不是每张卡可少收这么多，更不是新报价下限。例如Put原组赔付10.43%、新组2.69%；新方案即使比原方案改善，也仍需要净收入覆盖自己的2.69%及未计风险，才能有正样本均值。

上述减少主要来自少数不利样本，零节省只说明当次到期没有落入节省区间。它证明可以量化几何取舍；不能证明墙比等距离的任意点更有信息。原短腿等于墙位而无需移动的Put22、Call8张另存；缺墙各28张、无同宽组合各13张、价格已到或越墙Put6/Call1张均未隐去。这里不报告新胜率，因为没有新腿历史净信用。[6]

固定短腿、扩大保护宽度则是另一件事。设D为到期不利距离，X_W=min(D,W)/S；扩大W的边际条件为：

`C'(W) > E[1{D>W}/S]`

它要求多收的权利金覆盖新增尾部暴露。实际远端保护腿已很便宜时，继续外移保护腿新增信用可能很少；不能从假设C与W线性同比增加的历史表，推出实盘应扩大宽度。


## 7. 择时：等一次有信息的确认，不是机械等到更晚

NR修复事件的潜在价值，是冲击后状态发生变化，而不是附赠了一个固定寿命。当前代码以冲击、锚偏离和连续修复确认形成事件；effective Anchor还经过来源与迁移过滤。这些机制提供状态识别线索，但没有估计真实回复力，也没有保证到期不穿腿。[5]

如果保持同一到期、同一候选，晚些进入可能少承担一段风险，也可能失去权利金、错过机会或遇到更差成交。比较现在进入与等待后条件进入，应使用同一信息集和完整机会集合：

`等待价值 = E[等待后可选动作的价值 | 当前信息] - 当前最佳动作价值 - 等待成本`

等待后价值包含“不做”分支及真实变化后的价格、信用、资本和剩余期限。不能只把未来确认成功的样本拿回来比较。若选腿随价格变化，新的赔付函数也改变，不能把全部改善叫作时间衰减。

最小等待规则应针对一个可改变判断的事实：例如下方卖压是否仍推进、结构是否随价格撤退、反弹是否已重新进入上侧赔付附近。它不要求建立每秒滚动贝叶斯状态机；一次后续卡或一段现有缓存的核对，可以承载同一理论判断。具体运行实现本轮不启动。

美股收盘后与周末可以作为条件先验，但不是独立优势的证明。当前普通轮04:00-08:00北京时间同时对应约8-12小时剩余期限；时段和期限绑定。周末约55小时的低振幅表现也不代表报价仍足够厚；新市场事件可能让历史周末条件不再成立。普通轮与周末应保持不同条件组。

一个严格的反例是：如果事件后的市场在给定当前充分状态后满足马尔可夫性质，那么过去曾出现NR修复这个标签，本身不再提供额外信息。若事件仍有价值，必须来自标签包含了截面没有表达的历史、潜在机制或状态转换信息。不能同时宣称当前事实已完全描述未来，又把重复事件标签当额外一票。

本轮建议的择时方向是“冲击之后，等待能分清X1与X2的最低必要证据”，而不是固定延迟几分钟、只做某个钟点，或为取得更高评级一直等。时间越短并非无条件更有利；权利金、尾赔和新信息同时变化。


## 8. 对冲：继续侵入与恢复需要不同处置

垂直价差已有保护腿，再加期货会改变整个收益形状。对冲可能减少尾损，也可能伤害原本会恢复的交易，不能把降低波动与提高平均收益混写。逆向期货以USD名义U计量时，BTC增量为：[7]

`H = U × (1/F_entry - 1/F_exit) - 费用 - 资金费`

对于同一原期权持仓，E[H]不依赖原净信用C。因此，缺历史期权报价不妨碍研究对冲平均增量；但组合胜率、资本增长及入场价值仍依赖C，真实期货基差、资金费、滑点和保证金也不能省略后冒充实绩。

Put侵入后考虑空头U<0，其均值条件不是“跌了所以该空”，而是后续倒数价格的条件期望使E[H]>0；若卖压已衰竭并预计恢复，对冲反而可能亏。Call镜像须使用对应符号。若目标是减少方差，条件变为对冲收益与原持仓负相关，并且风险降低值得其成本；即使均值略降，也可能改善小仓位下的增长，但不是必然。[8]

示例：Put短腿79,000、保护腿77,000。在79,000触发、忽略基差和费用，一次性做空79,000 USD名义的逆向期货。到期78,500时，期货盈利恰好抵消两腿赔付；若价格恢复81,000，期权本可收全信用，但该期货约亏0.02469 BTC。需要识别的是侵入后继续还是恢复，不是简单的触腿事件。

本轮在114张卡的两侧分别检验了固定触腿对冲，共228个侧别、161次触发；不把它们视作228张独立信号，也不合成双卖。1倍指Put取U=-K、Call取U=+K的USD名义，0.5倍折半，不是Black-Scholes Delta对冲。以假设单边手续费2bp、原期权净补偿10%为例：

| 侧别与对冲比例 | 平均对冲增量 BTC | 净盈利率：原 → 对冲后 | 最差组合损失 BTC |
|---|---:|---:|---:|
| Put / 0.5倍 | -0.002120 | 85.96% → 61.40% | -0.030501 |
| Put / 1倍 | -0.004240 | 85.96% → 60.53% | -0.063788 |
| Call / 0.5倍 | +0.001107 | 68.42% → 64.04% | -0.011195 |
| Call / 1倍 | +0.002214 | 68.42% → 73.68% | -0.024718 |

不能只凭合并均值为负否定对冲：Call侧增加了平均盈亏，半量还缩小了样本最差亏损，代价是胜率降低；Put侧则明显受损。Call全量的组合均值约+0.001462 BTC，高于同卡直接卖Put的+0.000991 BTC，但胜率更低、最差亏损更大，且不含实际对冲资本成本。相对Put的正差主要由8月21日的4张卡贡献；去掉该日后差值转负。该日仍完整保留，因为尾部处置本来可能依赖少数大行情；这只说明优势尚不稳健。它是值得保留的局部候选，尚未识别出可在事前稳定抓住其优势的条件组。[6]

这项诊断只检查一个固定触发形式，不覆盖所有对冲。采用首次完整分钟收盘侵入、下一分钟开盘成交、只开一次、到期退出；分钟现货仅代理期货成交，期权仍用官方交割价。它不使用同柱高低点顺序，不优化触发阈值，不增加真实API或LLM调用。未计资金费、实际基差、滑点和新增保证金，结果不得称实盘对冲收益。[6]

最小方案因此不默认安装对冲。保留的局部分支是：原承接解释失效且继续侵入的证据较强时，比较减仓、有限对冲与继续持有；若只是压力触及后仍明显受阻，对冲没有自动正当性。没有期权退出报价，本轮不假装已经比较出减仓与对冲哪个更优。


## 9. 收束后的最小闭环与局部优先级

整个闭环可以只有五个判断，不必先建设重型跟踪系统。

| 环节 | 需要得出什么 | 不够时如何处理 |
|---|---|---|
| 识别条件组 | 当前更像承接、继续传导，还是双侧收缩 | 保留竞争解释，等待能区分它们的观察 |
| 提出少量候选 | 哪侧、哪两个相邻或结构相关腿位值得比较 | 不强迫生成交易单或固定Delta |
| 比较交换 | 多收/少收多少，增加/减少多少预期赔付 | 给信用交换范围，不伪造点估计 |
| 明确错误代价 | 什么变化推翻本分支，错一次可能怎样亏 | 缩小承担，不靠“高胜率”淡化尾损 |
| 到期或前提变化后核对 | 机制错、腿位错、补偿不足，还是处置错 | 只修依赖环节，不重调全部权重 |

建议优先级是：先保留X1/X2两类单侧分支，围绕“压力是否已传导”解释同样的方向数据；把短腿相对空间位置与信用的交换作为主要局部优化。X3双侧收缩和失效后对冲保留为独立候选，不因名称成熟或实现便宜就并入默认路径，也不因工程尚未存在而排除研究。

门控分三层：数学恒等式是否正确；机制在什么假设下提供增量；已有事实是否足够支持本次采用。第一层可以严格通过测试，第二层可以用反例和情景边界约束，第三层仍需局部事实与损失分布。不能把未证明未来优势写成已有效，也不能因尚未达到全市场统计显著性而禁止一切低风险局部研究。

假设分布的演示已给出非空的可行区域：在同一宽度、较近腿信用10%、较远腿6%的假设下，窄的无方向分布中两侧较近腿都优于较远腿；向上偏移时Put较有利，向下偏移时Call较有利；宽分布下四个候选均不如零持仓。这仅验证“不同条件可以有不同优选动作”的数学自洽性，参数没有拟合BTC，也不是实际报价。[6]

目前仍没有证据证明这些局部标签已被当前模型稳定识别。历史资料下，原方向、可读主动流与简单历史分布规则没有稳定超越同卡朴素基准；墙位相等组小且集中，A/S缺样本。不能据此直接发布新过滤器。但本轮已把更优方案从泛泛的“多研究信号”收束为可比较的具体取舍，而非停留在“等更多数据再说”。

样本可继续用于提出和反驳机制；反复用同一资料挑出最优条件，会夸大效果。局部规则应固定少量解释明确的分支，记录未选和误判，而非搜索大量阈值再给获胜组起名字。[9]

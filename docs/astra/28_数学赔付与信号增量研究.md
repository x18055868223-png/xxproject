# Astra：空间约束、尾部赔付与信号效用

## 结论与研究边界

**目前最值得推进的是“空间位置与候选赔付的连接”，而不是继续强化方向分数或细分 D–S。** 这不是已经证明的新交易规则，而是本批证据中最具体、最可检验的下一步。数学给出评价尺度；真实行情决定这条假设能否成立。

原有思路没有被整体推翻：Flip 可以作为空间参考，冲击后的修复确认也值得保留。但“贴近轴”不等于存在回复力，“修复确认”不等于次日不穿越卖出腿，“高等级”也尚未被证明带来稳定的经济增量。当前应停止把这些不同层次直接连成因果结论。

本次新增检验使用原176张事件中的114张普通候选，期限严格为8小时以上、24小时以内；另有2709个固定时钟入场、86个交割日。62张短期限卡不展示收益。普通候选覆盖2026年6月19日22:31至9月12日17:11（北京时间），实际61个交割日。周末沿用12个成熟观察点，9月12日一轮截至本次研究核验仍未到期，不加入分母。[1]

主情景仍为最近严格虚值的真实卖出腿、目标2000美元保护宽度、净补偿为实际宽度入场折算值的10%。5%／20%及1500／2500宽度是敏感性，不是真实报价。表中“保证金回报”为总BTC净盈亏除以逐笔估算保证金之和，不是账户累计收益；保证金系数沿用单例校准λ=0.951659。

| 问题 | 当前裁定 |
| --- | --- |
| 中性回路是否整体无效 | 不能这样裁定；当前使用方式尚未证明稳定增量 |
| 方向越明确是否越好 | 没有支持；方向准确与到期赔付是不同目标 |
| Flip是否比任意轴更有用 | 有研究迹象，尚未胜过同样本固定Put且月份不稳 |
| 哪条线索优先 | 卖出腿与同侧墙、有效空间的相对位置 |
| 是否上线新过滤器 | 暂不；先以同一赔付尺度作简短前向比较 |

这批资料已被多轮查看。方案虽在本轮新分组前冻结，仍属于探索与反证研究，不是未触碰的样本外验证。按交割日与周重抽样，报告覆盖、未选样本及失败；不从多项结果中挑一个最高胜率就宣布成功。[2]

## 数学起点：赚的不是“方向正确”

设入场价格为S0，到期交割价格为ST，卖出行权价为K，保护宽度为W，每1 BTC名义的净权利金为C BTC。研究假设C=qW/S0，其中q为5%／10%／20%；真实交易应代入实际净收入。Deribit币本位期权赔付以美元内在价值除以交割价格，因此不能将W直接当固定BTC风险上限。[3]

Put信用价差：卖K、买K−W。

X_put(ST) = [(K−ST)正部 − (K−W−ST)正部] / ST

Call信用价差：卖K、买K+W。

X_call(ST) = [(ST−K)正部 − (ST−K−W)正部] / ST

“正部”指max(x,0)。每侧净盈亏Π=C−X；侵入定义为Π&lt;0，持平单列。双卖使用两侧C之和减去两侧X之和，不能平均两侧胜率。盘中触及不直接判负；本研究不含提前平仓、强平或保证金追加。

**期望为正的条件：C &gt; E[X]。** 胜率只计算P(X&lt;C)。用盈利概率p、平均盈利g、亏损概率l及平均亏损绝对值a，可写成E[Π]=p·g−l·a。90%的胜率仍可能负收益：九次各赚0.0025 BTC，一次亏0.05 BTC，总计亏0.0275 BTC。

把赔付归一化为L=X/(W/S0)，则单笔估算保证金回报为(q−L)/λ。相同期限、几何位置与补偿下，信号真正有用应表现为L的分布更有利，尤其是损失区间的概率和深度改善，而不只是预测涨跌。

**样本持平所需补偿：q*=ΣX／Σ(W/S0)。** 它使样本总BTC盈亏恰为零，是事后描述值，不能直接成为下一笔交易的门槛。相同样本只改变q，回报机械变化为Δq/λ；增加一个百分点净补偿，估算回报约增加1.05个百分点。尾部赔付与真实补偿必须同时比较。

[3] 合约结算规则见Deribit官方Inverse Options；本页期望、归一化及分段推导为该规则下的数学结果。

## 盈亏平衡、空间约束与分布

在常见低补偿条件下，Put的盈亏平衡价格为K/(1+C)，而不是K减去固定美元权利金。Call的常见下方盈亏平衡为K/(1−C)。这些表达式有分段适用条件，最终判断应始终计算完整两腿净盈亏。

例如S0=80000、W=2000、q=10%，C=0.0025 BTC。卖79000 Put、买77000 Put，盈亏平衡约78803；卖81000 Call、买83000 Call，常见盈亏平衡约81203。深度价内Call赔付为W/ST，在极端上涨至800000时又与权利金持平，此后BTC计盈亏转正；这是币本位数学边界，不是短期期权策略优势。Put极端下跌时BTC赔付则可继续增大。

**空间约束不是“方向越强越好”，但也不是“方差越小越好”的无条件命题。** 假设到期价格分布收窄：如果中心仍在安全区，通常能减少侵入；若中心已在亏损区，收窄可能让亏损更确定。锚的中心位置、可相信的离散程度及尾部，都要相对当前两腿解释。

用一个仅供推导的固定锚模型说明：x=ln(S/A)，假设dx=−κx·dt+σ·dB，A固定、κ&gt;0。则未来对数收益均值为−(1−exp(−κT))ln(S0/A)，方差为σ²(1−exp(−2κT))/(2κ)。它展示了回复速度、剩余时间和噪声如何共同决定分布，**没有证明真实Flip具有κ&gt;0**。锚迁移、跳跃和模型失效都不在这个简化模型里。

以下只是假设分布演示：相同S0、两腿及10%补偿，对数收益均值为0；离散度是到期窗口标准差，不是年化IV，也不是用BTC样本拟合的参数。

| 假设到期对数标准差 | Put盈利概率 | Call盈利概率 | Put持平所需q | Call持平所需q |
| --- | --- | --- | --- | --- |
| 0.6% | 99.40% | 99.36% | 0.16% | 0.17% |
| 1.2% | 89.55% | 89.32% | 3.66% | 3.70% |
| 2.5% | 72.68% | 72.48% | 17.18% | 16.53% |

固定补偿的模拟不代表现实：低波动环境可能同时给更薄报价。应比较真实世界下的预计赔付与市场净收入，而不是仅从“低波动”推断值得卖。风险中性定价分布也不能直接当真实胜率；市场报价包含风险补偿、供需和费用。[4]

## 当前模型到底在识别什么

当前正式代码为FMZ 1.6.2，权威分支codex/astra-signal-rating-v1，远端提交cc37445b。本轮只增加隔离研究，不修改生产权重、事件、权限、LLM调用或前端。1.6.2本身是GEX时间语义审计补丁，不是新的预测算法。[5]

实际链条是：上游Flip → 有效锚状态机 → Anchor偏离与贴合 → M-DIE冲击后的破坏／修复 → 连续确认 → 接管事件。有效锚会保留raw／effective／pending并处理异常跳变；它不等于原始Flip逐次直接替换。NR触发需先有冲击和破坏，再恢复到既有分数与确认条件，不是“价格靠近Flip就发卡”。

旧EDB才组合量价、主动流、宏观、资金费率及期权信息形成机器方向。D–S在人工审计层组织证据，不直接改变执行许可。原注释中的24—72小时方向职责与当前8—24小时研究用途并不完全一致；这构成需要检验的目标迁移，不能靠改名消除。

| 当前信息 | 数学上能表达什么 | 不能自行证明什么 |
| --- | --- | --- |
| Flip、墙、Pin、有效锚 | 空间位置与候选约束机制 | 不可穿越边界、真实回复系数 |
| NR修复确认 | 已发生的冲击—修复事件 | 到期仍受约束、卖出腿安全 |
| TMV、主动流 | 已发生的压力与价格响应 | 未来同方向持续、价差必然适配 |
| 净GEX、GGR | 期权结构代理与位置分类 | 同一独立dealer库存观测 |
| 冲突、D–S | 不同解释的组织与审计 | 校准后的胜率、正收益概率 |

GGR部分体制由价格相对Flip推断；净Gamma也可能使用call正、put负的OI代理。不能再把这些同源变换当多份独立确认。Cboe的原始分析说明净头寸及其相对市场流动性的规模重要；其SPX结论不能直接移植成BTC效应量。Amberdata的BTC分析也依赖交易方向重建假设，不能将本项目上游数据当作已知dealer真实库存。[6][7]

应退出当前解释中的“中性即均值回归”“正净Gamma必然压波动”“靠近墙即承接成立”；保留相关原始事实和历史记录。代码中的旧Anchor Mean-Reversion已被解释为方向中性兜底，不能恢复成已证实机制。

## 择时与中性回路：哪些收益来自信号

固定时钟对照与信号用相同真实行情、期限和选腿方法。2709个时点有大量重叠，不能当2709次独立市场试验。同交割日与两小时期限箱配对可比较信号之外的基准，但也会消去信号可能包含的日期／期限选择作用，因此不能把被匹配消去的差异一概视为无效。[1]

| 使用方式 | 胜率 | 保证金回报 | 样本持平q |
| --- | --- | --- | --- |
| 完整时钟 Put | 74.12% | 0.32% | 9.69% |
| 完整时钟 Call | 77.04% | 0.88% | 9.16% |
| 信号时点 Put | 85.96% | 3.69% | 6.48% |
| 信号时点 Call | 68.42% | -2.74% | 12.61% |

匹配后，Put信号回报相对对照约高0.84个百分点，按日／周重抽样区间跨零，时钟偏移15分钟后差约0.39。Call没有一致正增量。无脑双卖的信号回报增量仅0.027个百分点；不能因为多收一侧权利金，就认为消除了选侧问题。

美股收盘后04:00—08:00的样本同时只有约8—12小时到期。美股交易时段是21:30—次日04:00；21:30入场到次日16:00为18.5小时。时段与期限在固定16:00交割下紧密关联，当前无法识别“收盘后”的独立因果优势。

12个成熟周末，固定周六09:01入场、周一16:00到期的双卖为11/12盈利，保证金回报约5.31%；补偿从10%减到5%，回报仅约0.06%。周末同长窗口波动较低值得保留为候选环境，但这项成绩本来来自固定周末入场，不能归给来源卡。

**择时目前是合理的分层变量，尚不是已验证的择优规则。** 普通轮和周末继续分开，前者按期限匹配、后者承认55小时暴露；不把周末低波动当作全天安全，也不为了高胜率删除不利月份。

需要比较当前既有腿与交易员实际愿意考虑的邻近腿，保留未选方案；不自动设置Delta≤0.2，不追求“越虚越安全”，也不把一次全胜子组改成生产硬门。

本批有效负净GEX下Put反而较好，这不证明“负Gamma是好环境”；它反证了“正净GEX才允许做信用价差”的机械规则。量价与可读主动流方向同时不利于Put的39张，Put胜率92.31%、回报6.94%；两者同时有利的26张却为80.77%、−1.62%。这是方向已兑现、反转、空间、期限或市场阶段的竞争解释，不能在同一批数据上挑一种原因定案。

建议保留净GEX、压力与冲突原始事实，退出“同向票越多就越可靠”的解释。评级可以指出强反证与未知，但本轮没有证明它应充当自动下单过滤器。

## 朴素历史分布能否替代复杂评级

每张卡只取此前已交割的最近28个日期，每日选与当前剩余期限最近的一个时钟样本；历史交割后至少五分钟才能入训练。将历史结算／入场比例投到当前价格，按当前真实两腿与假设补偿计算赔付。先封存预测和训练身份，再连接本卡结果，不提供当前未来行情。

早期36张缺足28个历史日，保留为训练不足；78张可预测。两个固定规则分别选择历史经验盈利概率较高侧、历史平均保证金回报较高侧；概率规则另有6张平局，不强选。

| 规则 | 选择数 | 实际胜率 | 汇总保证金回报 | 同卡固定Put回报 |
| --- | --- | --- | --- | --- |
| 较高经验盈利率侧 | 72 | 79.17% | 0.48% | 4.88% |
| 较高经验回报侧 | 78 | 76.92% | 0.49% | 4.16% |

两个规则都没有胜过同样本固定Put，也未超过随机侧的汇总保证金回报。概率规则胜率79.17%，平均单笔保证金回报却为−0.85%；汇总口径为+0.48%，差异来自各笔保证金不同。这再次说明高胜率、平均一笔回报与总资本回报不可互换。

**本轮不把“滚动28天经验胜率”升级成新生产核心。** 它是简单、可复算的挑战者，说明仅把历史分布搬过来也不够。28日不足以稳定认识小概率尾损，重叠和市场变化还会进一步减少有效信息。程序上没有偷看未来，不等于经济上已经具备样本外预测能力。

信息论可以帮助定义目标，而非给模型盖章。令Y为到期赔付或是否净亏，B为期限、两腿距离和补偿等基准信息，X为新增锚或压力信息。关心的是给定B后X是否仍改变Y的预测与决策，而非X自身有多复杂。两份来自同一价格序列的衍生量不自动产生双倍信息。

本样本不适合直接估计高维互信息或多状态贝叶斯网络。可以先让一条清楚的结构假设接受结果检验，再谈概率更新；不需要现在为每张卡维护昂贵的持续跟踪系统。

## 下一步的最小有效闭环

**建议保持生产信号不动，下一轮只补“候选赔付比较”，再冻结一条结构假设做前向观察。** 不推倒数据采集、NR生命周期、审计归档、来源时间、两侧证据和现有页面；这些是可复用资产。也不将当前固定Put或墙位相等的小样本全胜组直接上线。

| 处置 | 内容与理由 |
| --- | --- |
| 直接复用 | 卡时事实、原始Flip与有效锚、墙位、已闭合价格窗口、来源身份、审计与旧对照 |
| 新增一项 | 对实际考虑的两腿录入行权价、到期、卖价／买价与费用，计算净收入、完整赔付及相对空间；可手工完成，无需新增交易单系统 |
| 优先验证 | 相同期限／距离／补偿附近，结构相容的腿能否降低赔付；只预留这一主假设，不交叉搜索十几个条件 |
| 保留次级 | 原方向、冲突、D–S作为对照和解释；不能自动升格为收益概率 |
| 退出主解释 | 方向正确即价差适配、正GEX必定压波动、接近锚即有效、全胜小组即安全 |
| 暂不建设 | 更细评级、复杂权重优化、强制Delta门槛、持续贝叶斯窗口、更多数据订阅 |

一次决策只需形成四个可复用结果：当前为什么可能受约束；实际两腿的赔付区间在哪里；收到多少净补偿、主要牺牲什么；哪项变化会使当前解释不再成立。B可以支持人工研究，A/S也不能替代报价与风险判断；建议不改变既有机器权限。

结果更新按交割日归并，而非每分钟重评。新卡自然到期后保留选中与未选候选、失败与缺口，比较固定Put／Call及原方向；周末单列。先检查来源与赔付计算，再看稳定性和最差亏损。不得因某次盈利修改阈值，也不因某次亏损追加指标。

晋级条件采用证据条件而非任意胜率门槛：在预先约定的后续观察块中，优势不能只来自一个日期／月份；实际净补偿下仍需经受尾损；覆盖率及放弃机会应可解释；同样本朴素基准必须保留。如果优势消失，就保留信息展示、撤回过滤主张。小样本区间过宽时结论是尚不能判断，不是继续优化直到通过。

这条路线把工程集中在“市场事实怎样改变这笔赔付”上。数学负责检查逻辑，历史资料负责提出少量假设，真实候选与自然新卡负责下一阶段验证。完成这些之前，没有依据承诺提升多少胜率或收益。

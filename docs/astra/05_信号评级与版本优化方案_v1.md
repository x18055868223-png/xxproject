## 1. 目标与机制

信号评级回答当前上下方压力、结构依据及其冲突，不评估具体候选腿、报价、补偿或交易许可。结构、压力、来源质量和状态分别说明，不能合成新的百分制置信。信用价差风险侧不同：Put 信用价差关注下方侵入，Call 信用价差关注上方侵入；方向支持不等于经济补偿充足。

第一性收口继承原始 soul 的事实、机制、目标、执行分工。GEX/Anchor/NR 是机制代理；同源因素不按名称数量计独立票。未来行情不能参与事前评级；TTL 与已持续时间不是预测寿命。

## 2. 冻结接口

producer 在完整审计记录计算 integrity 之前原生写入 `signal_rating`，使用普通 JSON 对象：

下方仅示意字段结构；`as_of_ms: 0`、空主张与空数组是占位，不是可通过验收的样例。真实对象必须提供有效时点和完整主张。

```json
{
  "schema": "signal_rating@1.0.0",
  "rating_scope": "side_environment_v1",
  "candidate_quote_economics": "not_evaluated",
  "as_of_ms": 0,
  "claims": {
    "structure": {},
    "put_pressure": {},
    "call_pressure": {}
  },
  "market_state": {
    "legacy_label": null,
    "interpretation_cn": "",
    "mean_reversion_validation": "not_established",
    "trend_acceleration_available": false
  },
  "context": {
    "episode_id": null,
    "nr_state": null,
    "nr_active": false,
    "analysis_round": null,
    "future_validity": "unknown",
    "source_refs": []
  },
  "model_constraints": {
    "support_label": null,
    "side_hint": null,
    "has_block": false,
    "hard_veto": null,
    "execution_allowed": false
  },
  "next_observations_cn": []
}
```

每个 claim 固定包含 `status`、`summary_cn`、`required_inputs`、`support`、`opposition`、`unknowns`。状态只接受 `SUPPORTED`（有支持）、`CONFLICTED`（有冲突）、`OPPOSED`（有反对）、`INSUFFICIENT`（依据不足）。support/opposition 条目为 `{source_ref, source_group, basis_cn}`；unknowns 条目为 `{source_ref, reason_cn}`。引用以当前审计记录为根的点分路径，数组使用数字索引；support/opposition 的实际证据引用必须可解析；必要输入与 unknowns 可保留缺失路径作为待补来源，不能伪装成存在的证据链接。required_inputs 每项为 {source_ref, source_group, status, usable, reason_cn, impact_cn}，最后一项说明缺失影响。

`put_pressure` 与 `call_pressure` 是方向压力对该侧的关系，不是完整候选评级。每项必要输入不可用时该项为 INSUFFICIENT；有效正反依据并存为 CONFLICTED；仅支持为 SUPPORTED；仅反对为 OPPOSED；无有效方向证据为 INSUFFICIENT。可用的非投票数据不冒充缺失。缺失只影响对应的子主张，原有有效依据仍留档。

新计算不读取旧 confidence、agreement、coverage 或 EDB 总分作为等级。可复用已有因素离散语义、参与状态和单项方向；来源缺失/过期按现有 freshness、quality、data_ready 及配置判断，无时效事实则注明未知。不得由审计层默认补的 OK 推定来源新鲜。GGR 的空间票不再与同一 GGR 结构重复计票。

结构主张依赖 Anchor/GGR 的当时有效来源，正 GEX 单独不能生成回归成立。旧 `Anchor Mean-Reversion` 主解释为“TMVF 方向中性，回归尚未证明”；旧 `Directional Drift` 仅解释已有方向倾向；未实际产出的 Trend Acceleration 不充当检测结果。NR 与旧阻断独立显示，不借评级改变原机器权限。

列表 `summary.signal_rating_summary` 仅含 schema、rating_scope、as_of_ms、structure、put_pressure、call_pressure；后三项只保存 status/summary_cn。完整证据在单卡中。缺对象的旧卡不生成评级或 summary；显示历史版本未评级。格式不合法的新对象显示评级不可用，不回填为正面评级。

### 实际条件与时点

| 主张/来源 | 采用的现有事实 | 用途与边界 |
| --- | --- | --- |
| 结构 / Anchor | 自身 ready、freshness、gex_source_ts_ms；现有 Attached/Detached 与 anchor_gravity_valid_score/weak_score（默认 60/30） | 贴附/有效区提供局部约束依据，脱离/弱区形成反对；过渡状态未知，不是概率或回归证明 |
| 结构 / GGR | 有效 gamma_regime.regime/veto | 正 Gamma/钉扎提供结构背景，负 Gamma/放大区反对稳定约束，过渡区未知；不读 confidence_multiplier，不复活已忽略的 gex_info |
| 两侧压力 / TMVF | 当时来源质量、EDB 单因素参与/投票符号；Unclear/window_conflict、24h/48h final | 保留上下压力与未参与原因，不以最终分数覆盖分歧，也不把未参与时窗强行变成新票 |
| 两侧压力 / CVD | 4h/12h 实际数据与 data_ready、单因素参与条件 | 同源窗口成组，坏窗口排除而好窗口保留；联合激活条件未满足时明确说明 |
| 两侧压力 / MACRO | 原始背景、macro_shock 与单因素方向 | 只表述该背景的支持/反对，不能单独证明近端走势可靠；旧阻断独立保留 |
| 两侧压力 / Funding | 当卡 canonical_funding_semantics、raw_available 与参与条件 | 温和非投票和原始费率缺失分开，旧归一化拥挤标签不覆盖原始语义 |
| 两侧压力 / SRD | 同期期权偏斜及现有单因素方向 | 只作为截面压力背景，不替代候选报价与补偿 |

结构必要来源为 Anchor/GGR；两侧压力必要来源为 TMVF/CVD/MACRO/Funding/SRD，用于分别识别量价骨架、主动流确认、宏观背景、拥挤反身与期权偏斜限制。要求来源可读，不要求全部投票或同向。缺其中一项时，两侧压力状态为依据不足，有效正反证据仍保留，不拖累结构主张。这是首版有界解释的覆盖选择，不是五因子优于更少因子的实证。

时效沿用原输入边界：Anchor 默认 40 分钟陈旧/70 分钟失效；TMVF K 线最大年龄 3 小时；Funding 12 小时；GGR/SRD greeks 15 分钟；CVD 最新输入沿用 5 分钟现价年龄门；MACRO 沿用自身刷新记录与两倍刷新间隔（默认 2 小时）的既有降级口径，并保留数据背景年龄区别。这些全部是输入可用判据，不是预测寿命；运行时读取配置，表中仅为当前默认。

事件按 identity.confirmed_time_ms；固定轮次的 identity 保留计划时间，新评级 as_of_ms 使用真实 snapshot_collected_time。只有计划时点而无实际采样时，评级时效未知，不能借未来行情补足。full 页面核对实际时点，列表摘要只校验时间格式，不自造 5 分钟等有效期。

## 3. 链路与资产取舍

一处计算：producer → 审计 JSON → materializer → 页面/现有 LLM。评级不注册进 materiality/transition 触发器，不更改调用次数、推送频率、NR 或置信分类。LLM 可提出异议但不能改写评级，盲评不得提前看到新评级；完整核对阶段才解释它。旧权限校验照常生效。

| 处置 | 资产 |
| --- | --- |
| 复用 | 数据质量、因素事实、episode/固定轮次、source_ref、既有审计存储与页面按需加载 |
| 合并展示 | confidence/时区/耐久等重复主指标；低层原文与数值保留在证据区 |
| 兼容保留 | confidence 与真实消费者，原 lean/side/support/veto/NR/trigger；首版不改权重 |
| 修正解释 | 中性兜底不能称回归成立；保留枚举不能称已检测；同源解释不增加独立证据 |
| 次级知识 | KPF、SLRP、旧自动桥、旧零权重契合项；保存原文、负面证据与重启条件 |
| 候选层后续复用 | 两腿、报价、DTE、费用、VRP、退出与事实优先执行；首版不复制或接入 |

## 4. 验收矩阵

覆盖同置信不同证据、方向中性非回归、GEX 与流压力冲突、非投票/缺失区分、来源陈旧、同 episode 重复、NR 失效、时区不生造寿命、旧卡缺字段、LLM 异议、同源引用和补偿未评估。

producer 测试直接调用实际 FMZ 文件；对基线固定输入进行旧字段 golden 对照，保护 confidence/lean/side/support/veto/NR/trigger 和权限。新增字段须在完整性哈希覆盖内。materializer 原样保留单卡评级且不新增触发；LLM 维持盲评和核对边界；浏览器检查桌面/移动、长中文、历史卡、错误卡和证据引用。

模拟仅验证语义/序列；真实同版本连续记录分别按 episode 和固定轮次归档，冻结 30/60 分钟路径诊断窗，分开终点与期间不利移动。窗口不是寿命；记录不足报告缺口，不造数据、不按少数盈亏调权、不在缺报价时报告期权净收益。

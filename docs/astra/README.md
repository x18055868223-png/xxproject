## 先读什么

当前主研究问题是信号信息怎样支持判断并改善决策。垂直价差是现行用途，不能因资产成熟或此前暂时收口就认定单一方案更优。先读[项目记忆第0节](PROJECT_MEMORY.md)：AI 负责从事实分析、纠正和推荐，工具候选保持开放；[内容信任协议](knowledge/03_单次信号内容信任协议.md)由 AI 执行，是诊断步骤，不能代替效力与用途研究。

接管先读[项目研究记忆](PROJECT_MEMORY.md)：记录用户目标、资源约束、当前工作判断、待验证建议和路线变更理由。现行末日轮垂直信用价差是研究信号用途的重要案例，不能限定全部合理用途；具体试验与方案排序仍需 AI 论证，不是已接受交易规则。

## 证据阅读约定

“代码已核对”只表示对应 SHA 或本地哈希处存在该实现；“材料记载通过”表示历史文档的测试/部署记录，本次没有复跑；“当前运行已核实”必须有本次具体采样的服务或 FMZ 证据。首次资料整理未做运行端核验；v1 实施阶段新增的只读源记录核验、测试和 API 证据另列于方案与进度页，不据此宣称 FMZ 已升级。

远端文档用固定提交链接。本地独有资料用项目名、相对路径、必要摘录和 SHA256 留证，详见台账；这些路径是来源标识，不伪装成 GitHub 可打开的链接。没有将本地原文件整批发布，也未纳入服务器访问文件、凭据或运行日志。

接管时先核验台账中的版本与证据边界，再阅读建议路线。不要把“最新标签”“最高版本数字”“README 当前状态”中的任何一个单独当成全系统事实。

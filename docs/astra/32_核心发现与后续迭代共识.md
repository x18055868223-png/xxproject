## 一、首先保留的核心认识

| 认识 | 目前可以说什么 | 不可进一步推断 |
|---|---|---|
| 高胜率不等于好交易 | 必须同时看平均盈利、平均亏损、尾部赔付、补偿和覆盖率 | 胜率提高就代表净收益或资本效率提高 |
| 空间优先，随后解释方向 | 先说明什么机制可能限制哪一侧侵入，再看压力及实际响应 | 有墙、正净Gamma或价格处在锚带内，就证明约束有效 |
| 正确描述市场不等于交易优势 | 信号要解释具体两腿、到期与补偿之间的关系 | 方向判断正确就能超过已经反映信息的期权价格 |
| 风险进入权利金，但是否充分计价未定 | 风险中性定价与真实发生频率不同，风险承担可以得到补偿 | 失败证明市场完全有效，或存在风险溢价就证明本策略赚钱 |
| 信用价差同时买入保护 | 卖出腿收入、保护腿成本、费用共同决定净价值 | 直接把裸卖期权或整体波动率风险溢价移植为价差收益 |
| 低波动不必然更划算 | 赔付可能下降，净权利金也可能下降 | 周末、平静时段或更远虚值天然构成经济优势 |
| 保证金是另一个分母 | 实际占用影响资金利用率和账户风险 | 较少占用可以把负期望交易变成正期望 |
| 局部方案可以不同 | 条件X研究Put，另一条件研究Call，也允许不选择 | 必须找到一种全市场通用方案，或把某批最优侧永久固定 |

关于定价的理论说明，沿用[研究30](30_局部定式长期验证结果.md)核对过的[BIS风险溢价说明](https://www.bis.org/publications/volatility-concepts-and-risk-premium)及[Bitcoin风险溢价研究](https://arxiv.org/abs/2410.15195v2)。这些来源支持概念区分，不证明本项目的末日价差盈利。

## 二、统一的数学口径

令S为官方到期交割价，K为卖出腿行权价，W为实际保护宽度，C为已扣入场费用的净权利金，单位BTC。每1 BTC名义合约：

`Put到期赔付 = [max(K−S,0) − max(K−W−S,0)] / S`

`Call到期赔付 = [max(S−K,0) − max(S−K−W,0)] / S`

`净盈亏 = C − 到期赔付 − 尚未计入的成本`

**研究中的侵入按到期净亏损定义，恰好盈亏平衡另列。**短期触腿不直接判负。净盈利率与卖出腿到期无内在价值的比例不是同一个指标。

`平均净盈亏 = 盈利概率 × 平均盈利 − 亏损概率 × 平均亏损绝对值`

盈利75%、赚1；亏损25%、亏4，平均仍为−0.25。提高胜率不保证改善整条盈亏分布。

`条件方案相对净优势 = 可取得净权利金差 + 条件预期赔付节省 − 额外成本`

因此，最关键的比较是：**风险减少是否值得少收的权利金？**没有真实报价时可以推导赔付与信用边界，但不能把假设补偿称为真实收益。

BTC反向结算包含1/S权重。美元内在价值宽度封顶，不等于固定BTC最大亏损；Put深跌时BTC赔付可能继续增大。Call在极远端存在特殊的BTC结算关系，也不等于账户安全。不同名义、宽度和实际保证金须明确归一化口径。

## 三、最近新增且应长期保留的发现：外移只购买部分区间的保护

在**同侧、同到期、同宽、同名义**下，将两腿一起向外移动：

1. 最终两组都不赔：外移没有减少赔付，若少收权利金，其净结果更差。
2. 最终处于两组的中间侵入区域：外移可以减少赔付，是否划算取决于少收的权利金。
3. 最终两组均穿过保护腿：两组BTC赔付均为W/S，外移没有减少该处赔付；少收权利金仍会降低净结果。

上述结论针对持有到期，不涵盖中途保证金、强平、移腿或对冲。**“外移相对更好”的交割区间包含少亏，不等于盈利区间，也不是该区间的发生概率。**

[研究31](31_真实报价下的空间与补偿比较.md)的2026-09-14盘口快照提供了实际例子：同宽2,000美元，Put短腿77,500→77,000，扣费净信用少57.6%，邻近现价的盈亏平衡点外移约338美元；Call短腿78,000→78,500，少52.2%，盈亏平衡点外移约372美元。它说明空间需要付费，不证明本次哪一组最终更好。

这使信号用途更具体：**判断哪一侧、哪一段到期侵入区域受到什么约束，并将其连接到实际候选的赔付差。**不应只把“偏多／偏空”换成卖Put／卖Call，也不应只凭更远距离选择腿位。

## 四、实证结论及证据强度

| 来源 | 已完成的观察 | 当前边界 |
|---|---|---|
| 原始信号研究23—25 | 176张接管事件；普通轮114张满足8小时＜期限≤24小时；按方向、时段、周末和评级比较 | 大部分成绩使用5%／10%／20%假设净补偿；不是历史实际盈亏或APR |
| 无信号与双卖对照26—27 | 高胜率也出现在固定时钟策略；匹配后信号附加改善不稳；中性不自动等于适合双卖 | 不能把所有胜率归因于中性回路，也不能把它全部归因于期权结构 |
| 数学与局部假设28—29 | 把空间、方向、信用、尾部和有限对冲放在统一赔付尺度中比较 | 仍属推导与探索；没有产生已验证生产规则 |
| 长期验证30 | 2,643次入场、881个交割日、5,286份单侧价差；训练、选择与锁定期分开 | X1/X3锁定检验未通过；X2未取得主候选资格 |
| 真实报价比较31 | 一次公开盘口，6组候选、12条盘口、4组同侧外移比较 | 非同步组合成交；没有同期新评级及到期结果；不是胜率验证 |

长期验证中，X1与X3的匹配赔付节省点估计分别为+0.401、+0.462个百分点，分母是实际宽度的入场BTC折算价值，区间均跨零。**不能写成“已经微弱有效”。**未通过也不等于证明真实效果严格为零。

长期主主动流为USDT合约30／240分钟，现行生产较长CVD为现货成交量柱；长期资料没有完整历史Anchor、GGR与墙位。不能用这次失败否定完整中性回路，不能把滚动价格区间冒充空间墙，也不能将研究阈值直接复制到生产。

研究30的经济描述中，同一条件可能约76%盈利而平均净结果仍负；15分钟与60分钟报价覆盖子集不同，不可只留下正收益子集或将差异全部归因于时间陈旧。历史成交附带mark，不是同步可成交bid/ask。

周末研究的“12轮成熟、1轮未成熟”是原封存截止口径。周末约55小时独立于普通轮，不从11／17／23小时研究外推。美股开盘后与美股收盘后必须分开；固定16:00到期使时段与剩余期限耦合，不能声称已识别纯时段优势。

## 五、明确不采用的推断

- 不因某个历史侧别更好就永久固定卖Put或卖Call。
- 不把中性自动转成双卖；两侧胜率平均不是组合胜率。
- 不把22笔Put及8笔Call的小样本全胜写成“墙外全胜”：历史核对为卖出腿**等于墙位**，严格墙外为0。
- 不把D–S评级当作经过概率校准的胜率、价格优势或执行许可；不为挽救表现增加B+等细分。
- 不将正净Gamma、墙距、流量受阻直接称为已证明的抑波、承接或隐藏订单。
- 不把假设净补偿、历史mark、当前顺序盘口和实际成交混为一谈；不把宽度归一化回报写成实际保证金回报。
- 不把看到的0.4个百分点赔付节省当作可以放心少收的信用额度。
- 不用已经查看的锁定期继续调参，再宣称新的独立通过；未选、缺失与失败样本均保留。
- 不把新的报价回填到旧卡；旧卡倾向和等级不自动延续为当前判断。
- 不先以连续贝叶斯跟踪、更多指标、更多LLM调用或对冲工程替代当前补偿证据缺口。

## 六、后续优先方向：建议／待验证

优先复用已有审计与候选资产。先在离线解释中厘清“环境限定到期情景、空间解释约束、微观检验传导”的职责，再连接候选净补偿；不因缺报价停止理论分析，也不因环境解释顺畅就跳过经济检验。详见[评估33](33_环境状态与倾向性职责再评估.md)。建议的小规模只读对照为：

**自然新卡的环境、原生空间事实及近端检验 → 同到期实际候选报价 → 预先说明选择或不选理由 → 官方交割 → 全部候选结果。**

每侧两三组足以开始；不设统一卖出Delta、行权价距离或权利金门槛，不默认越虚值越好。保留选择自由，重点解释“多获得一段空间，少收多少补偿”。

同卡对照可以降低日期差异干扰，但不能单独证明条件在其他日期有效。需要新日期或真正未用资料，分开假设形成、规则冻结和检验；同时报告净胜率、平均净值、尾部、覆盖率与独立日期。新的条件允许探索，旧失败必须保留。

当前数学关系已经可用；“信号能否可靠识别这些有价值的区间”仍未证明。上述链路是下一项研究建议，不是已接受的交易条件，不要求新增交易界面、自动采集或定时跟进。

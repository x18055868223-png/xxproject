## 数据身份与过期规则

唯一产品目录为 `demo/shared/data_product_registry_v23.json`，随包显式复制到工具目录。源码与 flat 安装均可定位；缺失、非法、空目录 fail closed。既有因子目录不替代数据健康目录。

过期规则统一由后端登记的具体用途判断。盘口的 5 秒、连续事实的 300 秒、候选发现的 300 秒，以及按日发布资料自己的观察/披露时钟，不强行改成同一个 TTL。300 秒 FMZ 导出周期不是延长源资格的理由；配置为 600 秒时，超出现有当前用途资格的区间仍会阻断。页面另对健康汇总超过 10 分钟、缺时钟或未来时钟做显示守门，不把技术健康当作市场有利。

现有 GEX 原始/已接受/待接受/净 Gamma 代理保持分开的登记身份，未报告原始记录不能冒充已收到。不得用价格反推历史净 Gamma。未接 ETF、BRK、借款、实际利率及只读 MAP 均保持未接或受阻；本轮不引入新业务因子。合格历史模型文件 hash 仍为 `71fb23ff9cbb55a789cc1c95862e7e242d8647ce8ac883047d10bded01fd5860`，不重训，不替换失败尾部头。

真实样本保存在本轮 artifact 目录：当前公开 Put/Call 两张理论保单及五类来源 manifest；另保留旧服务器原生 DecisionSnapshot 中的真实宏观历史材料。后者仅作为历史导入，源钟不重写，不进入当前冻结，不能算作当前慢源生产消费证明。

## 服务器实作与保留范围

数据服务安装在 `/opt/astra-data-engine-v23`，以 `bitnami` 运行，只读取既有 FMZ 文件。没有新端口、外部请求、LLM、训练或交易调用。服务器安装的 7 个模块和 registry 与最终本地文件逐一 hash 一致。服务实际在 UTC 06:16、06:21、06:26 完成三次运行，间隔约 300 秒；Result=success，最近一次约 621 ms。

清理前先盘点、dry-run，然后仅处理精确 allowlist 的过期 `decisions.jsonl-日期-时间.gz`。六个 09/18—09/23 文件各保留其最后完整原生 DecisionSnapshot，含原 schema、版本、源钟、完整行、行 hash 与删除回执；均先 fsync、读回核验、检查源文件未变化，再删除动态压缩原文件。实际删除合计 **686,252,902 字节，约 654.46 MiB**。这是六个压缩段末截面的保留，不声称保留了所有逐分钟冗余诊断行。

每族最新两文件、近 48 小时及空快照源的安全保护仍有效：当前快照文件为空，因此 8 个历史快照压缩文件全部保留，另保留最近 2 个决策压缩文件。原始 signal_review、所有研究与失败、日留底、人工评审、预算、密钥配置、生产卡和部署备份不属于清理名单。旧 current decisions 文件也未被覆盖或删除。

新快照环已从旧 logrotate 规则移出，原决策日志规则保留，配置备份及 hash 回执已保存，`logrotate -d` 验证通过。这样新环不会因日志轮转被切出空文件；旧压缩快照继续受上述保留保护。

保护盘点覆盖 1,487 文件。1,484 保持 hash；三个既有运行派生文件（transition_state、卡索引、BTC trajectory）在旧生产 timer 活跃期间改变，不能把整棵运行目录称为全 hash 不变。卡正文、LLM 回执与预算/密钥等冻结证据未出现在变化名单。本轮没有回写这三项，也没有回退正在更新的派生状态。原 materialize 与旧自动 LLM timer 仍活跃；数据服务的零 LLM 不代表整个旧生产栈已迁移为纯手动。

## 本地验证与性能对照

- 最终适用 pytest：**162 passed, 1 skipped**，跳过为 Windows 无法创建符号链接的拒绝测试。79 条既有 UTC API 弃用提示保留，不是错误。
- FMZ 本体导出与 SpaceGate 脚本、旧 157/161/162 producer 合约脚本通过；旧脚本按自己的 main 入口运行，不把其函数签名误当 pytest fixture。
- 前端脚本及 JavaScript 语法检查通过；完整打包脚本含引擎、registry、维护 unit/installer 的资产检查通过；flat 独立目录导入通过；服务器 installer 的 bash 语法通过。
- 浏览器审计：桌面六类两列，390 px 为一列、无横向溢出；展开项刷新后保留。健康区域未出现 schema/hash/can_use/registry 等原始机器字段。
- 实测 10 次缓存 GET：同一采集版本，外部请求预算和研究 LLM 账 hash 未变化；响应约 1.18 MB，中位 51.636 ms，最大 79.216 ms。另由 HTTP 测试直接证明五次页面读取不增加采集次数。此为本机当前负载结果，不是容量承诺。
- 新数据服务三次实际运行均无外部 HTTP、无 LLM；六份保留截面重新读回 hash 全部一致。

本轮失败亦保留：首次集成受非确定 bridge_read 时钟影响已修复；初版部署包依赖与 PowerShell 无 BOM 中文路径问题已修复；首次 dry-run 因目标父目录不存在拒绝；验收探针曾未处理 journal 空 MESSAGE，修复后通过；测量脚本曾使用错误状态文件名，修复后通过。FMZ worker 初次曾误改旧根目录，被发现后精确撤回，再在正确工作树实施并重跑。历史验收不替代上述新验证。

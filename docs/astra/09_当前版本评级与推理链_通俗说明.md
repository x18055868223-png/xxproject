# 当前版本评级与推理链：通俗说明

本文解释 Astra v2.2。服务器已更新，FMZ1.6.1交付已同步，运行实例待用户替换。它帮助交易员研究末日垂直信用价差；本地验收、服务器部署及 FMZ 自然新卡是三层不同证据。实施与发布状态见[回执18](18_v2.2发布与兼容验收.md)；旧卡保留当时的原生评审，不自动改成新版建议。

## 先读什么

先读“本卡建议”：哪侧值得研究，主要取舍是什么。再看卡片时点价格、独立价格倾向、Put／Call 两侧等级与比较；随后看机制和主要反证，最后核对市场数值、来源时间与变化。

Put 信用价差关心**下行侵入是否受到可解释约束**；Call 信用价差关心**上行侵入是否受到可解释约束**。偏空不等于 Put 适配，也不自动证明 Call 值得成交。横盘可以适配信用价差，强单向移动也可能意味着结构正在被穿透。

## 字母怎样读

| 等级 | 证据含义 | 阅读用途 |
| --- | --- | --- |
| D | 有效事实总体反对该侧适配解释 | 看清当前反对事实及重新判断条件 |
| C | 可以判断，但没有明显支持优势 | 普通观察，保留新证据入口 |
| B | 有值得关注的支持，竞争解释仍有实质分量 | 可以研究、比较和准备，不必等到 A 才开始思考 |
| A | 整体论证较强，适配解释更有依据 | 优先细看具体结构与报价取舍 |
| S | 整体支持很强，关键竞争解释更难成立 | 优先处理，但仍需核对实际交易的补偿与风险 |
| 未评级 | 必要证据或有效判断缺失 | 看缺口；有效观察仍保留 |

字母不是胜率、交易许可或保证获利。A／S 不要求全部指标同向、一定正 Gamma 或刚发生完美承接。未出现 A 本身不能证明门槛错误，也不能成为放宽标准的理由。两侧同为 B 可以有相对差异，由比较说明，不另造 B＋／B－。相对更有利不等于必须交易，也不表示同时做两侧。

## 一次评审如何形成结论

1. **先解释结构。** 现价、锚带、墙位、翻转点和 Pin 分别是什么；数据从哪里来、何时取得。离墙远只说明距离，不证明墙能守住。墙向外移动也可能意味着原约束在退让。
2. **看本侧的不利压力。** Put 看下行，Call 看上行。主动流、量价、宏观和资金费率按各自作用解释，不强迫每个因素投票。
3. **核对同窗价格响应。** 卖出压力是否带来下行推进，还是传导较弱；传导弱只提示可能存在缓冲，不表示看见隐藏买单。
4. **分清近端和较长窗口。** 最近15／30分钟反弹，可以与4／12小时下行同时成立。近端说明当前正在怎样变化，长窗提供背景，不压成一个统一方向标签。
5. **保留竞争解释，再给等级和建议。** 实际反证、未知和未来条件分别列出。仅仅“未来可能反转”不独自压低等级；可靠反证也能胜过多个同源的弱支持。

GGR 的价格位置分类和看板净 GEX 是不同事实。正净 GEX 为对冲缓冲提供一种解释，但不能单独确认抑制波动；过渡区尤其需要结合响应。锚、墙和 Gamma 派生量存在来源重叠，不能凑成多票确认。旧置信与耐用总分不在新等级里加权平均。

## 新增近端资料能证明什么

FMZ 1.6.1 从已有一分钟缓存记录已闭合的15／30分钟窗口，不增加行情请求。保留实际起止、样本数、缺口、开高低收、净变化、区间位置、分钟收盘采样效率和同窗净主动量。

主动买入基础币成交量来自 USD-M 合约 K 线已有列，参见[Binance 数据格式](https://github.com/binance/binance-public-data#futures)。

一分钟收盘采样不是逐笔路径，开高低收也不能证明同一分钟先碰高点还是低点。缺分钟不补齐；缺主动买量只使该项主动流无法判断。旧卡没有这些资料时，使用其当时确实保存的十五分钟变化等证据，不把模拟数据放回历史。

期权“24小时目标档”可能实际还剩17小时，以真实剩余期限为准。某期限的波动率不等于本笔价差报价。比例和百分数统一解释，例如0.001605的收益比例约为0.1605%。

## 建议如何用于交易研究

建议可以指出值得考虑哪侧及什么条件改变看法，但不预设卖出 Delta、行权价或统一距离。把卖出腿放得更远，可能增加价格空间，也可能使权利金不足；更近可能有更多补偿，同时更容易受到不利侵入。需要结合实际两腿、净权利金、费用及退出风险比较。

信用价差的损益取决于两腿行权价和净权利金，参见[OIC 信用价差说明](https://www.optionseducation.org/strategies/all-strategies/bull-put-spread-credit-put-spread)。

没有真实候选报价时，市场分析仍然有用，**补偿是否足够保持未评估**。原信号窗口、硬风险和机器权限单独显示；建议不能开交易开关，也不能消除硬风险。窗口未开不等于禁止人工研究。

情景只在能增加判断信息时展示：说明依据什么事实、出现什么条件会影响哪侧、下一张卡怎样核对。可以给四小时近端情景、二十四小时背景情景、两项都给或都不给；不会为了填满框而重复“继续关注变化”。这是条件分析，不是信号能维持多久的承诺，也不会额外产生一次模型调用。

机制说明回答“目前如何约束本侧风险”，等级依据回答“为什么落在这个等级”，主要反证列出当前具体的不利事实；三个位置不应重复同一段结论。近端数值区以短指标和实际分钟覆盖辅助核对，完整来源与局限在展开区保留。

## 下一张卡怎样帮助复核

同版本事件卡和固定轮可以比较市场事实，前提是身份、品种、时序、来源和方法可核验。第一张跨版本卡或缺前卡时可以有明确比较缺口。每一项结构迁移与价格变化分开解释。

历史卡补出的变化只作为独立本地核验显示，并标明没有进入当时模型评审。原卡、旧评级和原评审哈希不改写。对新解释的实际用途，需要继续看自然连续卡与人工判断，不能用两张隔离测试卡证明收益。

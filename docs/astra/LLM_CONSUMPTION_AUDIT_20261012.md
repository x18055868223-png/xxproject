# 核心链路 → LLM 消费审计（2026-10-12）

依据：EU 生产环境 4 次真实 DeepSeek 调用（`deepseek-v4-flash`，观察用途，共享用量账本计数）、调用前后的完整 provider 请求、代码审查。分支 `claude/astra`，提交 `abe4ce9`、`2d40b75`。

## 结论

1. **改造前，链路前置产出基本没有转化为决策支持。** 模型拿到 25 个证据单元，但新接入的 GEX 期权数据（近端墙、最大痛点、隐含波动、PCR、巨鲸、对冲情景）在事实层就被丢弃。KPF 接受区和期权墙只有原始价格，没有与本单行权价的关系。提示词禁止用距离判断远近，Q2 只能写“μ 缺失，无法判断”。
2. **改造后，同一条链路给出了可核对的关键判断。** 例如短腿按隐含波动不足半个 σ；0DTE 负 Gamma 墙与周度磁体落在短腿至保护腿之间；近现价 KPF 接受区包含现价；可见信用约占价差宽度一成；盈亏平衡在一个 σ 以内。以上逐条与发送给模型的证据核对一致。
3. **另发现并修复一个阻断问题。** 观察复核在生产中整体不可达（见下节），这是 10-12 放宽 GEX 有效期后出现的回归。

## 阻断问题：复核不可达（已修复，`abe4ce9`）

- **现象**：两侧候选均为 `wpem_evidence_unavailable`，复核按钮不可用。
- **根因**：GEX 有效期放宽到 2 小时后，MAP 的冻结清单开始包含 `gex.effective.accepted`。该产品在每个 FMZ 快照上按当前价格重新打分，但观察时钟沿用 GEX 源时钟。于是候选自身清单与 MAP 清单对同一身份持有两个不同版本，as-of 校验判为冲突（`source_identity_version_conflict`），WPEM 回放全部失败。
- **修复**：身份/版本唯一性改为在每个冻结清单内部校验；跨清单只要求同一 record_id 一致，各采集方自己的首见时钟除外。修复前后均已在生产快照上验证。

## 消费矩阵（上游 → 快照 → 证据 → 模型）

| 上游数据 | 改造前 | 改造后 |
|---|---|---|
| 静态 Gamma 墙、磁体、波动触发 | 进快照，不进证据 | `options.structure`，标出相对现价与责任区的位置 |
| 近端 0DTE/周度墙 | 事实层丢弃 | 同上，并保留 gex_usd 正负 |
| 最大痛点（含下一到期） | 事实层丢弃 | 同上，并标是否与本单同到期 |
| 做市商对冲情景 | 事实层丢弃 | 只保留不利方向情景，并给出到短腿所需涨跌幅 |
| ATM IV、期限结构、IV 分位、DVOL、RR 偏斜 | 事实层丢弃 | `options.vol`：按本单期限取 IV，程序计算短腿与盈亏平衡的 σ 距离、信用/宽度 |
| PCR、成交/持仓、巨鲸 1h/24h | 事实层丢弃 | `options.flow`；巨鲸活跃行权价标出位置；声明无基准 |
| KPF 成交接受区 | 只有原始价格区间 | 加上是否包含现价/短腿/保护腿 |
| TMV、Flow、Skew、Funding、宏观、MAP 背景 | 已进证据 | 不变 |

证据正文由约 22K 字符增至约 28K 字符，prompt tokens 由 5.3K 增至 10.4K。

## 提示词评估

| 问题 | 处理 |
|---|---|
| “支持/反证”没有参照物，模型把“行情偏离本单不利方向”写成关键反证 | 明确：支持指降低不利方向风险的证据，反证指增加该风险的证据 |
| 禁止用距离判断远近，最关键的“短腿离现价多近”无法表达 | 远近只能用程序给出的 σ 距离表述，原始百分比仍禁止 |
| Q2 没有可用的事实，3 点里有 2 点重复“μ 缺失” | Q2 可用信用/宽度与盈亏平衡 σ 距离描述交换条件的形状；μ 缺失只说明一次 |
| 关键词闸门把否定式分类句判为缺引用，整次回答作废 | 分类否定（“不是/不能当作/并非……”）不再要求该主题的引用；“未出现/并未增加”等缺失断言仍须引用 |
| 期权墙与期权持仓被视为期货 OI 主题 | `持仓` 主题接受 `options.structure` / `options.flow` |

仍存在的结构性问题：规则约 30 条。改造前，推理过程中超过一半在逐条自检合规（“Potential issue … Good.”出现数十次），对市场本身的推理很少（KPF 出现 0 次）。目前的单次调用没有自动重试，任一句命中闸门，整次结果都只留档、不展示。

## μ_ref：现有数据能否做出严谨结果

**不能。**

- μ_ref 是这张价差在真实分布下的预期赔付。对 28 小时、短腿 0.2–0.5σ 的价差，进入赔付区的概率约在 30%–45%。可见信用只占宽度 10%–17%，要判断补偿是否足够，概率误差必须控制在几个百分点以内。
- 现有材料不足以证明能达到这一精度：
  - 研究阶段的冻结模型系统性低估赔付（R17 结论：风险工具有用，业务未成立）；
  - 链路中没有到期交割核对，无法做样本外验证；
  - FMZ 快照只保留约 1 小时。
- 硬做出来的 μ 会给出看似精确、实际未经验证的数字，正是第一性设计里要避免的东西。

**另行考虑（按严谨程度）：**

1. **已实现（描述性，非概率）**：按市场 ATM 隐含波动把短腿与盈亏平衡距离换算成 σ，以及信用/宽度。全部由程序计算，不拟合。
2. **下一轮建议（市场隐含，严谨但不是真实测度）**：在报价时把两腿的 Deribit mark price / mark IV / delta 冻结进快照（发现阶段已经在取短腿 greeks，但没有保存）。
   - 价差 mark 价值就是风险中性预期赔付，可视信用与它的差就是执行摩擦；
   - 短腿 delta 是市场隐含的价内程度。
   - 这需要扩展快照 schema。
3. **之后**：已实现波动率与隐含波动的差（VRP）。这才是卖方真正的边际来源，需要明确标注窗口与样本量。

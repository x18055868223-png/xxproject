**3．哪些数可以信到什么程度？**

| 数值身份 | 能支持的判断 | 证明上限 |
|---|---|---|
| 原生合同支付 | 给定合约、数量与官方交割价，可核算确定支付 | 不证明卖出值得，也不是实际成交损益 |
| 冻结预计组合赔付 | 条件补偿参考、金额误估诊断 | 预测不等于确定支出；“情景最低净信用”不是安全底价 |
| 共享情景价与费用 | 指定假设下的静态净值、成本敏感空间 | 默认 IV/费用不是同期市场价或账户费率 |
| 顺序公开盘口 | 某时点可见双腿价格与数量 | 六个相关备选只有一个交割日，无同步组合成交保证 |
| 报价条件到期结果 | 保存盘口加费用假设对应的到期演算 | 不填为实际执行损益；实际成交、对冲和账户成本仍未知 |
| 已实现损益与条件 EV | 未来若有真实账，两者分别记录 | 单次盈亏不等于期望；当前 actual_EV 保持 null |

采用集合的偏差必须与参考保本要求同时阅读：RV×1.25 情景中，统计 Put 预测余量 0.064346 被后验赔付低估 0.052354 消耗约 81.36%，剩 0.011991；Call 的低估超过余量。数字是逐笔归一后的均值，不能用平均 B 换成 BTC，也不能将 81.36% 当新校准系数。各政策集合不同，不能据此作因果优劣判断。

**4．生意成立了吗？** 尚未成立。简单筛选相对全做有情景内价值，自适应报价下绝对余量仍接近零且不确定；统计和局部状态没有稳定的新采用依据。同期真实净补偿、完整执行账以及账户资本/容量/维护费用尚未闭合。当前不用于稳定现金流、扩大仓位或杠杆的论证。

**5．还缺什么才值得重新开启？** 只保留同一保单的真实单位经济性命题：

```text
事前固定合约/政策 → 当时冻结风险输出 → 同期报价与执行身份
→ 采纳/拒绝/因果否决/未成交 → 实际费用、退出或对冲净账
→ 官方交割和责任解除 → 账户约束下净结果与采用集合风险误差
```

只有已有资料能补齐，或用户另行授权必要验证，才继续这条链。需要的是可保留净信用没有被风险低估、真实成本及资本/维护要求耗尽的可复核证据；一次盈利、一个有利 IV 情景或新模型名称不足以重开。缺失保持缺失，不补造历史判断、Gamma、信用或“当时已知”的预测，也不无限延长研究直到显著。

# MAP v2.4.1 表达修订冻结

2026-09-26。依据用户新提供的《MAP决策表达与真实价格轴》及全合成交互样机继续当前工作。附属文件是设计和验收依据，样机数字不是市场输入。本修订在查看新表达结果前记录。

## 修改理由与范围

v2.4 已接数据对象、来源冻结、区域响应与合同责任，排序表不能直观表示距离与宽度。本版撤销表格代替主价格轴的兜底，增加线性 SVG 数值轴、默认外露的四条定量背景、最多三句事实组合摘要，以及选择区域后的责任和响应联动。表格保留在审计详情。

本地 C/P 指 Put/Call 候选：卖出行权价、保护行权价来自 `snapshot.contract`，近端 BE 来自后端已核算 `economics` 与 MAP 合同参照。链上 `CP_STH` 是资本成本代理，既不是 Call/Put，也不是权利金。期权结构墙与候选腿保留不同角色。

新增纯呈现模型不发 HTTP、不调用 LLM、不计算第二套赔付。SVG 只做原始数值到像素的线性转换；责任金额直接读取原 MAP `policy_link`。合成、回放、实盘资料身份分开。异源/名义价格不精确叠加；远参照可全览，当前保单两腿与合格 BE 在聚焦域内。

## 主要评价与停止条件

以附件 U01–U20 为验收范围，重点验证等价差等像素、近 BE 不移位、单边候选不补造对侧、选侧不改源事实、区域跨腿责任来自原金融函数、不同源钟与异源降级、旧评审版本保留、桌面/窄屏无页面水平滚动。真实来源冻结样本与异常夹具分别验收，不用全合成页面代替来源证据。

若缺合格原值、费用、可比价系或响应覆盖，显示局部缺口，停止相应比较或结论，不填零、不移价、不造区间。没有合格 mu/M 时不补参考余量。没有新来源证据时不称承接有效。

SpaceGate、候选选腿规则、统计模型、mu/M、手动一次/最多两次 HTTP、600 秒冷却、四小时邮件和日快照十五张规则保持原边界。未授权新前端推送/部署；本轮交付到本地验收。原协议、失败、来源记录和归档均保留。

## 真实链路发现的工程阻断

首次真实两侧截面取得 23 个待核对 delta 合约身份，但 Deribit 共享预算沿用单产品最大值 20；发现截面的第 18 个盘口起被阻断，后续两张保单均未形成快照。失败回执与输入另存 `real_workbench_*_attempt01`，不能算真实两侧通过。该缺陷属于既有数据管道请求预算不足，不是行情或模型结论。

改为显式 Deribit provider 每分钟 64 与盘口产品每分钟 64 的有限上限；其它产品预算不变，仍有 cache/singleflight/backoff，不能在预算失败后绕过引擎。这个值是本地工程配额，不是宣称交易所许可或改变交易阈值。发现链路遇到不完整 delta 取数不把未核验对侧当完整候选。重新验收必须记录真实请求计数、两侧同版冻结、零 LLM 和原门失败仍不准入。

## 字段与单位核对

- 净信用读取 `economics.net_credit_after_entry_fee_btc`；权利金差 `visible_credit_btc`、双方理论成交费用 `fee.entry_fee_btc`、含所列到期费用预算 `net_credit_after_fee_btc` 分别命名，不用 gross 当净信用。
- 到期近端 BE 只读取后端已合格的 `CONTRACT_LIABILITY / NEAR_BREAKEVEN`；费用缺失不造 BE。源价时刻读取盘口交易所 timestamp，与估值 cutoff 分开。
- 美元指数原 `change_5obs/20obs` 是指数点绝对差，新增 `change_5obs_pct/20obs_pct` 相对变化；收益率百分点差乘 100 才是 bp。
- BRK 成本是名义价系。撤掉未经注册比价的 Deribit 指数距 CP；只在 Bitview 自有价格与 CP 同源、同观察日时列 `gap_sth_source_price_pct`，明确是旧日同源比较，不称当前合同距离。原失败表达保留。
- 对侧保单冻结时点不同可以切换阅读，但不能在同一精确责任轨道假装同截面对照。

## 接线复核的必要修复

KPF build 阶段曾直接读取三件套、只保留前六区域并合成临时来源记录，不满足统一引擎与完整池要求。改为显式 refresh collector，同版文件、原时钟、价系与用途资格严格检查；GET/manual 只读缓存。完整有限池上限128，超过整体拒绝并保留 hash/计数；全部合格参照供责任分析，默认展示由 MAP core 限制为两条。即使三件套失败、没有可用参照，也冻结真实 artifact 身份，不隐藏失败。

这是数据身份与表达修复，不是候选算法或阈值实验。宏观短/长窗口使用唯一显示身份，避免按标签索引时20观察值覆盖5观察值；独立复审的失败结果保留，修复后重新验收。

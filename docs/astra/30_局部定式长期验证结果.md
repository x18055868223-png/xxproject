# 局部条件有没有留下交易优势
### Astra · 长期验证记录 · 2026年9月14日

允许因条件而变换 Put／Call，是合理的研究方向。本轮按预定流程处理三个候选族；X1、X3进入锁定检验，X2在训练与选择阶段未产生合格主候选。尚未找到通过预定检验、可以据此认可为稳定局部方案的候选。

这份记录区分三件事：条件是否减少赔付、减少的风险是否仍留下足够补偿、历史可观察价格能否代表真实成交。即便某个条件在样本里显示赔付点估计较低，也不能自动证明补偿足够或真实可成交。

| 候选 | 锁定检验 | 当前定位 |
|---|---|---|
| 较强主动流，但同窗价格传导较弱；卖承接侧 | 平均赔付节省很小，区间跨零 | 保留情景解释，未证明交易增益 |
| 压力继续传导；卖相反侵入侧 | 训练与选择期没有合格主候选 | 不进入最终通过检验 |
| 过去四小时波幅较小、近端流较弱；同时双卖 | 平均赔付节省很小，区间跨零 | 低波动本身不构成补偿优势 |

最值得保留的最小闭环是：当前条件支持怎样的到期赔付判断 → 实际两腿愿意付多少净信用 → 哪些变化会使原比较不再成立。不是把每个看似合理的条件都固化成交易开关。

本轮没有更改生产 FMZ 1.6.2、评级、LLM、仓位或定时任务。三类研究候选均不是自动交易规则。找到“显著改善交易表现的具体方案”仍是未完成目标；完成数据、程序和报告，不等于目标已经实现。

## 三个局部假设怎样被冻结

主对照是同阶段、同侧别、同入口、相近过去波幅与短腿距离、相同实际宽度的未触发机会，并排除同交割日。至少需要10个控制日期与4个七日区块，缺匹配直接保留缺口。它仍是观察性比较，不是随机实验；桶内剩余差异不能宣称已被完全消除。

每个入口预留三分之一风险预算；双卖各用六分之一。无条件时不使用该份预算，不将漏掉的机会放大到下一笔。主效应只覆盖匹配成功的触发预算，不能把其效果外推到未匹配或未触发机会。

## 数学上，真正要比较的是哪一项

记S为最终官方交割价，K为短腿行权价，W为实际保护宽度，C为已经扣除入场成本的净信用，单位BTC。单份1BTC名义价差持有到期的赔付为：

`Put赔付 = [(K−S)的正部 − (K−W−S)的正部] ÷ S`

`Call赔付 = [(S−K)的正部 − (S−K−W)的正部] ÷ S`

`净盈亏 = C − 到期赔付 − 尚未包含的到期成本`

因此，单侧适配不能只用“未来涨／跌概率”代表。Call关心K至K+W之间及之外的上侧分布；Put关心K−W至K及之外的下侧分布。币本位还带有1/S权重，Put下跌尾部的BTC赔付不会被一个固定BTC宽度完全封顶。

把小段行权价区间的侵入逐段累加，可以得到精确关系：Call预期赔付，是K到K+W每一小段上“交割价超过该位置且按1/S加权”的平均；Put则对应K−W到K下侧。空间、主动流与价格响应只有改变这些与腿有关的条件分布，才改变赔付判断。

`条件方案相对基准的净优势 = 取得的净信用差 + 条件赔付节省 − 额外成本`

这给出具体边界：假设某条件平均少赔0.4%宽度入场价值，但同时少收到2%的净信用，组合反而更差。若赔付节省尚不确定，更不能把0.4%的点估计当成已经赚到的折让额度。这是演示数学关系，不是给出统一补偿门槛。

同宽外移短腿点态减少赔付，却会改变信用；过去波幅较小也可能同时降低期权补偿。交易员要比较的是可取得的信用与风险，而不是默认越远、越静或评级越高越好。


## 胜率、定价与看似矛盾的目标

提高胜率在数学上可能实现，持续改善扣费后的净价值则需要另外证明。在相同风险预算下，暂忽略恰好盈亏平衡的情形：

`平均净盈亏 = 胜率 × 平均盈利 − (1−胜率) × 平均亏损绝对值`

例如75%盈利、每次赚1，而25%亏损、每次亏4，平均仍亏0.25。靠外移短腿减少行权价侵入，不能据此承诺净胜率与收益同步提高：净信用也会变化，盈亏平衡位置和尾损／收入比必须重新算。

权利金含有市场对风险的预期，也含风险偏好、保险需求与承接风险的补偿。定价中的风险中性概率与真实发生频率不同，所以“市场有效”和“承担风险可以获得正期望补偿”并不矛盾。BIS对此区分有明确说明。Bitcoin期权研究也发现风险溢价随状态变化，但不能据此证明本项目的末日垂直价差能取得该溢价。

| 看似矛盾 | 实际区别 |
|---|---|
| 环境越平静，反而可能越不值得卖 | 风险下降与净补偿下降需要一起比较 |
| 信号正确，交易仍可能不划算 | 预测准确不等于它提供了市场价格以外的信息 |
| 买保护腿降低尾损，也压缩收入 | 卖出腿收到的溢价与保护腿支付的溢价共同决定价差价值 |
| 样本越精挑细选，成绩越好看却越不可信 | 筛选需要未用日期和未选机会作对照，不能只保留赢家 |

不能从三个候选失败推出所有风险已充分计价，也不能从某些高胜率组推出存在尚未计价的优势。本轮没有完成对风险中性与真实条件分布的识别，更没有同步可成交报价，因此尚不能裁定市场完全计价或系统性错误定价。

最小推进方向是检验“某条件下的风险减少，是否大于为它少收的净补偿”。空间解释继续保留，补偿比较紧随其后；先用已有候选和可取得价格做小范围对照，不新增统一Delta门槛，不把整个系统升级成庞大的持续预测工程。


## 当前能用什么，下一步只补什么

局部定式可以成立于不同机制：有的情景适合Put，有的适合Call，也可能两侧都没有值得承担的补偿。问题不在于必须找出一种全市场通吃的方法，而在于每个分支必须交付自己的可核验增量。

本轮X1／X2／X3只留下“可解释的情景”，没有留下已证明的优势。不能把“未通过”改写为“微弱有效”，也不因为没有成功而放宽同一锁定期的条件。当前资料不能证明完整中性回路Anchor无效；长期没有历史墙位、GGR与原生修复窗口，不能用滚动价格区间冒充它们。

下一项最小研究应复用现有审计卡和候选报价资产，形成只读的同卡对照：同到期、相同风险预算，比较实际考虑的Put／Call或较近／较远两三组价差。记录真实两腿、可取得净信用、空间依据和未选原因；不规定必须远虚值，也不要求先补交易准备界面。

核心问题收敛为“为多一段空间少收到的信用，是否值得”。先保存入场快照与到期结果，下一张自然卡已有的前提变化另作说明；暂不建设连续贝叶斯窗口。评价同时保留净胜率、平均盈亏、尾部与覆盖率，不能只优化胜率。周末约55小时轮次单列，本轮11／17／23小时成绩不能代替周末验证。

| 当前可采用 | 当前不可据此认定 |
|---|---|
| 用局部条件组织询价和复盘，说明其对应哪一侧风险 | 条件满足就具有更高胜率或正期望 |
| 用实际信用差与历史赔付差放在同一单位中比较 | 用历史mark冒充当时可以成交的报价 |
| 保留原生空间、压力与响应的竞争解释 | 把合约固定窗口阈值直接迁到生产现货成交量柱 |
| 以后用新资料检验新的有限假设 | 在已查看的锁定期继续改规则，再称独立通过 |

这里没有要求固定Delta、强制深虚值或只研究A/S。数学上的候选排序可以比较“净信用－条件预期赔付”，但本轮尚未得到足够可靠的条件赔付估计器。最小闭环先补实际信用与决策记录，不能用估计器的名字替代已经验证的能力。

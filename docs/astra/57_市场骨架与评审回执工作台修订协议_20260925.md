# v2.0 工作台追加修订：市场骨架与手动评审回执

日期：2026-09-25。接续 [55](55_空间门与动态工作台v20修订协议_20260925.md)，不改原 v1.1—R17 研究身份、失败、FMZ 交易逻辑或经济裁定。

## 修订理由与冻结候选

当前工作台把 FMZ 每 tick 的原生 SpaceGate 和保单账接通，却没有把原审计卡中交易员需要的量价倾向、宏观压力、空间墙位、冲突与因果证据放到主阅读链。FMZ v2 当前事实缺失时，本地页面全是缺口，难以验收正常态的信息层级。手动 LLM 请求虽能返回结果，前端只在内存中短暂显示“请求中”，没有持续读取服务端持久回执并展示反证、适用性和缺口。

本轮仅评估一种确定性方案：从同一 FMZ `EvaluationSnapshot` 明确投影量价、宏观、空间、EDB 等已有字段，并附来源时点和质量；在结论之后、保单之前显示非 LLM 市场骨架。另建隔离的**本机模拟正常态**，只用于页面与交互验收，显式水印，绝不作为真实 FMZ、合格风险参考、当前 SpaceGate、交易许可或真实 LLM 输入。真实服务缺失时仍 fail closed，历史卡不伪装成当前事实。

人工评审沿用既有服务端 Gate、同版候选、Bearer 鉴权、全局冷却、幂等、共享 HTTP 预算、正常一次且最多一次恢复请求。点击后立即显示“正在推理”，从服务端 `inflight/last_result` 自动读取回执；页面刷新可恢复显示。回执仅属于冻结保单，不能因市场/报价刷新而附着到新候选。模拟态的演示回执必须写明模拟、零真实 HTTP；不因 UI 开放实际请求。

## 主要评价与停止条件

验收以字段来源可追溯、同一 FMZ 时点、质量/冲突/未知不被掩盖、中文可读层级、模拟与真实隔离、按钮忙态及完成/失败回执、刷新恢复、无第二次非授权 LLM 和移动布局为主。生产缺 FMZ v2 原生事实继续阻断；缺 `μ_ref`、报价或正 `M_ref` 继续关闭真实评审。任何字段若只能来自旧卡或推断，就标为历史/模拟或显示缺口，不补造当前事实。独立来源不足不能把 Anchor、GEX、EDB 重复计票。旧尾损与研究失败不截去；本轮不检验胜率或经济 edge。

若投影改变原 SpaceGate 或保单账、模拟数据进入真实账本、前端绕过 Gate、同版回执错误附着、实际 LLM 被模拟验收触发，立即停止本轮发布。页面需本地浏览器审阅；按 `AGENTS.md`，此版本只有收到用户再次明确“当前本地页面可推送”才能提交、推送或部署。

## 独立审查触发的状态身份修订

审查发现原评审尝试文件只按 `candidate_id` 隔离，同一双腿组合在报价或 FMZ 截面更新后产生新 `snapshot_id`，即使交易员再次明确点击，也被旧文件的快照不一致分支永久挡住。这与“当前具体保单、手动同版复核”不符。修订候选限定为：尝试文件按候选与**冻结快照**共同隔离；旧版同快照文件继续原样复用，绝不重置旧尝试或失败；不同快照只有通过工作台当前 Gate、全局冷却、幂等和共享预算，且由人再次点击时，才允许新的一次正常评审。页面刷新、每分钟状态刷新及重启恢复均不得自动发起新 HTTP。另只补只读 `review-state` 代理路径，不开放 HTTP POST。

主要评价为同快照重复点击零新增 HTTP、同腿新快照在明确新点击后最多按原额度调用、旧文件及失败不丢失、重启仅恢复回执而不补发、静态代理能读回执。若旧失败被覆盖、新快照自动请求、预算/冷却被绕过或代理扩大真实评审入口，停止发布。

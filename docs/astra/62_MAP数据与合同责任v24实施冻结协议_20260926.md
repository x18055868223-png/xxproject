## 本轮冻结范围

1. 消费既有 v2.3 DataEngine，不再造一套缓存、调度或事实库。有限公开来源的采集、退避和请求预算经引擎，页面读取不取外部数据。真实 first_seen 保留；历史未知披露钟不伪装为当时可得。
2. 五包背景 E1/C1/C2/C3/M1，主屏四行。ETF 3/7 个应交易日与前置 60 日尺度；CP 不等于 RP；损益日值/累计/滚动按元数据；OI 原生数量不以名义美元代替，Funding 实际结算不以预测代替；宏观名义/实际差分取共同端点。缺源与部分窗各自传播，不能填零或综合多空分。
3. 有限参照池和默认最多六个市场参照：期权 Put/Call/effective Flip 最多三，KPF 最近合格区最多二，固定 CP_STH 一。保留原始区间和显示档，主屏筛选不删除深赔付相关的有限目标。价格基准未核验只作名义参照，不能精确共位或称本到期保护。
4. 区域首次知晓/激活后才记前向响应。参考修订关闭旧段；价源断档不补路径。离散跨区、区内实际成交与闭合 K 线相交分别表达，不新增突破确认模型、触区邮件或自动退出。
5. 同一选定候选关联原合同核算。区域端点、卖腿和保护腿折点求准确赔付极值；inverse Call 区内保护腿峰必须保留，inverse Put 深尾不截。情景不扣 mu，费用身份明确；mu 缺失可继续合同演算，M 仍为空。触区不是到期交割或提前平仓损益。
6. MAP 实际值与 manifest 进入当前页、日快照和原人工冻结。LLM 只复用同版事实与已有手动路径，正常每卡一次/最多两次 HTTP、600 秒 CD、既有鉴权/共享预算不变。没有真实数据资格时只用桩验链；不使用新额度账。

## 主要评价与停止条件

验收外部规范 D/T/M/R/P/I 的相关故障和数学反例：真实日历/缺日/单位；历史修订和截止；默认名额与原始几何；未知价系；参考移动和缺口响应；Put A/B/C 与 inverse Call 折点；候选切换与同版冻结。相同原始输入的原 SpaceGate、mu、M、两腿选择、权重和执行输出必须不变。检查页面 GET 零新增外部请求、零自动 LLM，冻结对象可读回重放，部署包包含必要模块及目录。

来源真实样本、工程通过、当前实时消费、生产消费和经济有效分别报告。源受阻/未授权/仅历史不阻断无关核算，也不得宣称全覆盖；既有 FMZ 2.0.1 运行实例和当前连续截面仍未取得的生产缺口不得被 MAP 掩盖。KPF 无同次原盆地和审计时不重建 90 日逐笔；借款不申请新私有权限。达到四行背景、有限价格轴、可证响应、具体合同责任与同版冻结后停止扩张，不训练新状态模型、不搜索收益阈值、不启动 90 日或定时跟进。

本轮不提交/推送/发布新前端；发布仍需要用户针对当前本地页面明确“当前本地页面可推送”，权威目标为 xxproject。

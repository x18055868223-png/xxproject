1. 浏览器复现：在合成页从未选切换 Call，四问推荐 Call 结构参考，下方责任卡却默认显示 Put 结构参考。`selectedPolicyRegion` 只查 highlighted 或完整池首行，没有使用同版服务端 watch 主区域。该问题影响 G2/G3 的阅读连贯性，不改变已算出的金额。拟修为先解析同版推荐区域，保持显式手选优先；无有效推荐不把任意区域冒充观察重点。
2. 来源身份收拢：独立只读复现融资背景行将最新 OI 观察与更早借款 first_seen 拼接；同一成本 record 在顶层11条与 MAP 内12条来源清单中重复。修订按具体来源配对时钟，同记录去重且冲突拒绝；原始捕获不改。前端仅消费配对结果，不增加另一个事实层。
3. 评审入口收拢：主agent复现剩余冷却600000ms时两侧 gate.enabled 仍为true（`gate_before_repro.json`）。服务端合并冷却、运行中和共享额度状态，GET与刷新均更新当前可用性；保留POST时原子安全检查、幂等和已消耗预算。该项减少同目的分散判断，不新增权限。
真实回放缺原生 FMZ/SpaceGate、实际候选和合格风险参考，不能完成同保单交易前审查。软件不能用合成资料补齐这些事实；新服务器状态另行只读核验，旧回放身份不变。

## 2. 固定保单到底至少应收多少

主口径为原生 BTC：

```text
B = 数量 × 实际宽度 / 入场参考价                 # 参考尺度，不是保证金
D = 数量 × 两腿到期内在美元支付差 / 官方交割价
c = 卖腿收入 − 保护腿购买支出                     # 扣费用之前
情景静态净贡献 = c − D − 情景交易支出
情景最低净信用 = 原冻结预计组合赔付 μ × B + 情景交易支出
情景最低卖腿收入 = 保护腿价格 + 情景最低净信用
```

直接估计组合赔付，不再训练两个单腿尾部头相减。单腿的价格和最终支付分解仅用于查账，不能据此伪造各腿物理期望或“保护风险溢价”。如果 c 已用卖 bid 减买 ask，盘口价差已经在 c 中，不再重复扣保护费或盘口价差。

价目表中的 `required_net_credit_*_scenario_btc` 是**某个风险估计和费用假设下的保本要求**，没有加入用户资本回报门槛，也不保证已校准。实际费用未知时，实际保本要求仍未知；不会用情景 k=0.025/0.05 伪装账户账单。

完整算例按事前定义取最早原主截面 Put：2022-01-01 08:00 UTC，`BTC-2JAN22-47000-P / 45000-P`，入场现货 47,194.73、数量假设 0.1，B=0.0042377613 BTC。固定 IV60 下：

| 合成保护价格 | 0.0000865808 |
| 净信用，费用前 | 0.0009681924 |
| 原费用情景 | 0.0001059440 |

## 6. 保护、退出与资本三本账

`B=qW/S0` 只是参考币数。合成边界：q=0.1、Put 100000/98000、S0=100000，ST=97000 时 D=0.00206186 BTC，即 1.03093B；ST=50000 时 D=0.004 BTC，即 2B。零、部分、深度突破以及 Call 对照已通过现金流核算。历史主截面的 82 条 D>1 和母截面全部真实上尾均保留；这些压力价不是预测概率或未来最大损失。

若持有期权到期，完整执行账是 `c−D−f_option+H_net`；H_net 已含的手续费、资金费不再扣。若提前平仓，用买回价替代到期支付，不同时扣两份责任。现有退出实验已经证明尾部压缩有均值代价；本轮只复用 R16 的正确净亏口径，没有引入新退出规则或取消现行保护。

| 账本 | 当前能给什么 | 不能认定什么 |
|---|---|---|
| 静态合同 | 原生赔付、情景最低补偿、一次保存报价到期结果 | 情景价格等于可成交价 |
| 执行与对冲 | 支付恒等式；已有退出情景均值/净尾部证据 | 实际手续费、对冲和资金费为零；理想 maker 必然成交 |

当前官方说明确认 inverse 以基础币种计价与交割，保证金还依赖账户制度。[Deribit 产品说明](https://support.deribit.com/hc/en-us/articles/31424939096093-Inverse-Options) 因此如以美元经营，必须冻结换汇与持币约定；账中“BTC 现金流持有至交割再折 USD”只是明确的转换情景。抵押 BTC 的涨跌、单独不交易的持币基准应另列。

## 7. 最多三个缺口与明确停止边界

1. **主导缺口：同一候选可保留的净补偿。** 主历史缺同期双腿报价；现在的一日六个盘口也没有当时冻结风险输出、真实成交/未成交及执行后信用。高报价是否同时表示遗漏风险仍未识别。
2. **完整执行现金流。** 实际账户费率、买回或对冲净损益及资金费未知。此次官方交割只补齐合同责任，未补齐实际执行账。
3. **个人经营约束。** 账户保证金制度、两场所资本、同日容量、最低规模风险与维护成本未知，无法认定此账户值得经营，也不能推论市场中无人可做。

未来只保留一个需要区分的命题：**同一条事前固定保单，实际可保留净信用是否超过冻结预计组合赔付和真实成本，且余量足以容纳误差与资本/维护要求。**

解除方式是复用既有候选入口，连接同一 ID 的报价、冻结风险数值、成交或未成交、实际费用/退出/对冲净账及官方交割，并保留统计拒绝和因果否决的机会。先查已有记录，不要求重建全期权链；一次正成交、一个好年份或仅情景正值不会改变商业裁定。没有这些证据时，**现在就停止模型扩张，保留工具，不以“继续积累”拖延判断。** 没有自动开始采集、实盘或定时任务。

这同时给出三层裁定：品类有可成立的经济条件但实际补偿未证明；方法上保留简单风险工具，统计/状态/LLM 没有新采用许可；个人账户经营适配不足以裁定。可以接受未来朴素承保有价值而复杂模型没有增量，但当前不能提前承诺。

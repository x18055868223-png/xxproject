# GEX 时间语义补丁与 FMZ 1.6.2

本页是用户批准的缺口补丁规格。开发基线为 `codex/astra-signal-rating-v1`，完整资产提交 `4667aa5368554529575e322126af205fd93bc3d7`。本地候选、服务器部署和 FMZ 自然新卡验收分别登记；完成本地检查不代表生产已更新。

## 为什么需要修复

旧 GEX 接口把本次抓取时间填入观测时间；FMZ 的审计补全又可能从抓取时间或年龄重建观测时间。模型因此可能把“刚拿到的上游结果”理解成“市场刚被观测”。这影响来源解释，不能靠调整 D–S 或页面改名解决。

本补丁只改变时间身份及其消费。信号权重、方向、旧置信、事件触发、通知、交易权限、正常一次 LLM 调用及其最多两次 HTTP 恢复额度保持原职责。已有 15／30 分钟摘要继续复用。

## 四种时间

| 时间 | 能说明什么 | 不能说明什么 |
|---|---|---|
| 真实市场观测时间 | 源端明确标注的市场观测时点 | 不因有接口时间就自动已知 |
| 上游结果生成时间 | 所选结果或结构分组完成计算／更新的时间 | 不证明所有底层合约同时观测 |
| 接口抓取时间 | 此值何时被我们的接口取得 | 不证明此值刚产生 |
| 卡片记录时间 | 此事实随哪张卡归档 | 不替代源端观测时间 |

例如：13:00 生成的结果在13:03抓取，13:04进入卡片；若没有明确市场观测时间，页面仍显示“真实观测未知”。它可用于说明卡时已知结构，但不能用来宣称全部底层合约刚更新。

## 原生对象与来源选择

GEX 接口及 FMZ 的 `gex_info` 保留 `gex_time_semantics@1.0.0`。`fields` 按接口字段路径索引，分别记录 `source_ref`、`observed_at_ms`、`generated_at_ms`、`fetched_at_ms`、`time_basis`、`time_errors`。未知为空；有明确但不能解析的时间时保留异常状态。

| 当前取值 | 时间归属 |
|---|---|
| 净 GEX | 对应 `gex-latest` 结果时间，属于生成时间 |
| 总结构墙位与结构分组字段 | `profiles.total.meta.updateTime`，属于该分组生成时间 |
| 翻转点／现价／备用来源 | 与实际选中的来源一致，不能借另一条来源的时间 |
| DVOL | 只接受其专属观测／生成时间；没有则未知 |

顶层 `computed_at`、缓存 `data_timestamp` 与响应时间不能统一赋给所有字段。派生字段继承实际依赖的时间限制，不因换了名称获得新的独立观测。没有接入本次发现的其它上游指标。

抓取失败保留旧值时，旧值时间说明与内容指纹一并保留；最新请求及失败信息另记。磁盘缓存恢复保留同一身份。旧机器消费者的抓取年龄、质量和缓存行为不借本补丁改权重。

## 事实、引用与兼容

事实包增加 `available_at_ms`，表示卡片时点可得性。真实观测未知可以保留；已知观测、生成、抓取任一时间晚于卡时均不能绕过引用校验。依赖事实的时间异常向相关派生事实传播，不扩大为整卡否决。

旧卡按原事实包版本重建，不能把新时间字段写进旧包、改变其哈希。新事实包读取旧 GEX 数据时，不能把旧抓取回填当作新协议的真实观测证明；只有卡时归档可得性得到保证时，才允许带明确时间局限引用。

|---|---|---|
| FMZ 完整交付 | 1.6.2 | 仅审计增量，直接修改完整本体 |
| GEX 时间说明 | 1.0.0 | 原生透传，旧接口明确未知 |

| LLM 输出／摘要／展示投影 | 2.2.0 | 形状与评级职责不变；内嵌事实按自身版本 |

页面沿用中性纸面、当前模块顺序及惰性加载。既有来源区显示中文“市场观测／上游结果时间／最近抓取／卡片记录”，未知直接说明；机器字段仅在下载资料中保留。

## 本轮追加：栏目内容与阅读层级

用户进一步要求在本补丁中修复栏目错配。空间约束动力学直接呈现卡时现价、Call／Put 墙、Pin／最大 Gamma 位、翻转点及价格锚轴，并关联相对距离、净 Gamma 和压力响应。中文市场事实保留完整数值、各自来源时间和局限，主视图区不再重复铺开同一组关键点位。

关键变化骨架补充 TMV、看板净 Gamma、主动流、宏观、资金费率及 Pin 的前后对照。复用原卡的事实与比较检查，以独立 `signal_change_projection@1.1.0` 保存只读展示结果，并绑定原卡、原评审和自身哈希。旧投影1.0.0仍可读取；新增展示不改变事实包、原评审、评级或尝试额度，不触发模型重评。

这些补充行明确标注“本地核验，未进入当时模型评审”。它们帮助交易员对照证据，但不能被写成模型当时已采用的变化论据。前后卡品种、版本、时间或来源身份不符时不比较；逐项来源、方法、单位或观察窗口不同，只关闭该项。零值、负值使用实际刻度差，不用百分比除法制造夸大的变化。净 Gamma 增加、Pin／墙位迁移不自动证明约束增强。

界面保持中性纸面、既有模块顺序与惰性加载。桌面采用标题／前后值／解释，较窄屏幕把解释放到下一行；两卡时点差不称为期间完整路径。模拟前卡只用于验收展示，不进入生产资料。

## 验收与发布边界

测试覆盖：真实观测已知、仅结果生成、仅抓取、不同字段时间、异常／未来时间、失败保留缓存及恢复。producer 测试直接构造原生审计卡，对照旧方向、置信、触发和许可；只验证下游回填不算原生通过。

冻结真实卡只进行一次隔离新版 Prompt 检查，传输／格式恢复共用最多两次 HTTP；保留失败，不因等级或文案重试。模拟时间场景只验证语义与页面，不算真实 FMZ 输出。

本地页面、桌面／手机及独立审查完成后，仍需用户确认“当前本地页面可推送”。此后先更新兼容新旧 producer 的 GEX 服务与审计消费者，保留数据、缓存、预算、尝试状态和回退备份，再同步用户可见 FMZ 1.6.2 完整文件。用户替换实例后，以自然新卡核验原生时间对象和新版评审；不重评历史卡，不恢复 Codex 定时跟进。

A／S 持续跟踪仅列入[待研究企划21](21_A与S级有限跟踪待研究企划.md)，本补丁不启用它。

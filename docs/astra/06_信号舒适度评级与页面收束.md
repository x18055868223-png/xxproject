# 信号舒适度评级与页面收束

方案批准：2026-09-07；本地收尾：2026-09-08（Asia/Shanghai）。本规格承接 05 的原生四态证据链，替代其页面主展示与“等待上一版发布”的停点。本轮验收单独记录，不沿用上一轮浏览器/API 通过结论。

**后续评估说明（2026-09-08）：**用户要求校对“高等级是否更适合垂直价差”后，发现当前检查允许结构论证不足的 A、用途增量未充分核对的 S，以及页面删除真实反证等问题，详见[结构优先评级与 LLM 健壮性评估](research/2026-09-08_结构优先评级与LLM健壮性评估.md)。下文保留批准规格及当时实际工程检查记录；“通过/关闭”不包括本次新发现的语义缺口。当前代码未修复这些问题，高等级不能被解释为已经证明更适配，建议修复后重新验收再发布。

**最新用户澄清：**B–S 应代表总体证据等级，不逐级增加理想行情条件。新研究稿[总体证据等级与最小推断链](research/2026-09-08_总体证据等级与最小推断链.md)建议按相同目标综合现有证据，并把行动边界独立呈现。下文仍描述已实现的“LLM 建议 + 行动限级”契约；在显式版本调整前，不将现有 final_grade 冒称纯证据等级。

## 1. 当前裁定

在既有 reconciliation 调用中，对 Put/Call 信用价差分别形成 D/C/B/A/S 行动优先级；本地校验并限级。B 启动页面注意力与筛选，不新增通知；A 是信号层准入，启动人工准备，候选腿、报价、补偿与风控随后确认。等级不表示胜率，不更改旧 confidence、NR、方向、触发或执行许可。

| 等级 | 用途 |
| --- | --- |
| D | 有明确反对、失效或风险否决，本轮回避 |
| C | 数据可判断，但没有值得主动跟踪的适配机会 |
| B | 有可说明的机会，关键条件/窗口/反证仍待解决 |
| A | 适配机制明确、必要来源有效、关键反证已处理，既有边界允许该侧结构复核 |
| S | 满足 A，结构与不利侧压力均更有利，且有额外非重复依据值得优先处理 |
| 未评级 | 数据或有效评级缺失，不当作 C/D |

旧置信和耐用不平均、不新增数值阈值。Anchor/GGR/pin/GEX/SRD 按相互重叠的期权来源组织；TMV/CVD 的价格确认按重叠来源组织；Funding、宏观另组。生命周期只作状态，路径仍属于价格来源；来源分组不证明统计独立。时段先验和 24 小时预测不能单独升级。实际路径不得晚于评级时点；OHLC 不证明路径顺序。

## 2. 冻结接口

位置：LLM 响应的 integrated_trade_advisory.side_comfort_ratings；审计卡合入后为 llm_review.integrated_trade_advisory.side_comfort_ratings（没有额外 content 层）。producer signal_rating@1.0.0 不变。LLM output schema 与主 Prompt 均升为 1.6.0，producer 保持尚未发布的候选 1.6.0。

LLM 响应只填写 put_credit/call_credit 两个对象。每侧字段固定：

- grade：D/C/B/A/S/UNRATED。
- basis_cn、counter_evidence_cn、next_observation_cn：非空中文。
- unresolved_conditions_cn：中文列表，允许空。
- evidence_refs、counter_evidence_refs：当前 evidence_catalog 的 ID 列表；后者允许空，但有具体事实反对时必须引用。核心支持须有实际可用底层事实，不能只有旧分数、评级、时区或系统结论。
- s_upgrade_basis_cn：非 S 时允许空；S 必须说明比 A 多出的依据。
- s_upgrade_evidence_refs：非 S 时允许空；S 必须有可核验的非重复事实引用；不能只重复主支持的同一事实。

本地输出容器固定包含 schema=signal_comfort_ratings@1.0.0、rating_scope=signal_side_admission、candidate_quote_economics=not_evaluated、as_of_ms（沿用 native rating）、put_credit、call_credit、headline。

本地每侧保留上述中文和引用字段，将 grade 替换为 model_grade（D/C/B/A/S/null）、final_grade（D/C/B/A/S/null）、status（RATED/UNRATED），增加 cap_reasons_cn 中文列表。模型原评和本地最终评级不得混写。异常、缺关键数据和历史未评级均为 final_grade=null；有效但被限级时保持 RATED。

headline 固定包含 final_grade、focus_side（put_credit/call_credit/tie/none）、action_cn。按最终有效等级 S>A>B>C>D 取最高，同级标 tie，两侧均未评级标 none/null。action_cn 由本地固定等级含义生成，不能复制未经限级的模型准入文案。

列表 summary.signal_comfort_summary 仅透传容器的 schema/rating_scope/candidate_quote_economics/as_of_ms/headline，以及 put_credit/call_credit 的 status/final_grade/basis_cn/cap_reasons_cn。不修改原有 signal_rating_summary 语义。完整审计卡同时保存同一份派生 signal_comfort_summary；无有效摘要时为 null，索引则不发布该摘要。

发布前复用同一 core 的纯本地校验：从卡重建 evidence packet、检查现有完整评级、按已存模型建议重新核验最终状态是否一致；只决定摘要是否可发布，不改写评级、原文、native 或完整性记录，不发起 LLM 请求。页面核对摘要与详情是否一致，不另加“必须正 Gamma / 必须原生有支持 / 必须有全局就绪旗标”等新算法。无有效发布摘要的完整 comfort 不得绕过发布层显示准入。

完整包补齐现有 Anchor 原始截面与 EV_ANCHOR 引用，盲读信息边界保持。新增字段不得进入 materiality、trigger、通知或调用调度。旧 sidecar 无字段继续可读，不自动重跑历史。

## 3. 限级与异常

先核验对象、native rating、时点、引用、所依赖的必要来源，再判断既有 BLOCK/WAIT、实际失效窗口和侧别许可。缺有效输入为未评级，有局部有效事实仍显示底层观察。只读 execution_allowed=false 不构成降级；候选报价未评估不阻止 A/S。

必要来源的可用性与四态结论分别检查：原生结构“依据不足”可能只是锚/Gamma 处于过渡、尚无约束主张，而必要输入全都有效。此时不能机械判定为数据缺失；允许按事实作普通观察/关注，适配是否成立由具体机制与既有复核边界判断。来源有效但本轮不投票也不算缺失。

BLOCK/WAIT 不可得到 A/S；有机会但窗口未开最高 B，不能把所有 BLOCK 机械转为 D。A/S 须通过原有 advisory 的侧别/结构复核约束；producer 中性时只接受原有中性单侧语义，不能变成双侧同时交易。S 必须满足 A，额外依据与失效条件完整；仅升级证据不足时降 A，其它校验失败不能伪装成 A。

明确记录为过期、失效或失败的当前窗口，与尚未开启分开处理：前者按已知失效事实归本轮 D，并保存原因；后者仍可 B。格式/引用错误是未评级，不能用 D 掩盖。数据质量只决定证据可用性，不能作为额外市场事实升级 S；引用 ID 存在不代表对应来源当前可用，必要事实及升级事实都须核对原有质量与时点依据。

引用必须指向当前卡可用事实。格式错误、伪造引用、原字段泄漏、执行参数或无法核验的关键主张使评级无效，保留可读事实并显示未评级。既有主 advisory 的 fail-closed 校验继续生效；不无限重试，不扩展恢复次数。限级后的卡不能在顶部继续出现模型原评的“准入”结论。

真实复核暴露的窄修：comfort 文案中的合约执行价格/期限信息作废；当前支持与 S 升级依据声称价格位于 Gamma 翻转点另一侧、与本卡价格数值矛盾时，该侧未评级并擦除错误说明。明确未来条件与下一观察不被当作当前事实；另一路 GEX 的正 Gamma 状态不能覆盖本卡翻转点的位置。该检查只覆盖可明确核对的语义，不声称已能自动判定全部自然语言推理真伪。

## 4. 阅读页

行动结论 → Put/Call 对照 → 当前限制与下一观察 → 中文市场证据 → 深入分析。等级始终带侧别；并列为无单一优先侧。B+、A/S 筛选保留时间顺序，未评级不当作低等级。

普通页面、展开内容、tooltip、aria、错误消息都不出现字段路径、枚举、schema/hash、公式、权重、旧置信/耐用总分及实现说明。重要数值、单位、时间、时效/缺失状态和反证保留为中文事实。原始资料通过下载保留，不渲染到隐藏 DOM。历史重评仅简短提示身份。LLM 深入解释与 24 小时报告保留，不复写顶层结论。

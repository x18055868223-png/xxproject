## 结果前设计

主问题：原组合首次在30分钟观察点触短腿时，能否辨识继续持有的到期赔付风险，并改善选择退出的假设情景表现。次问题：同侧、同到期、同宽、同名义向外移动的赔付节省能否估得更适用。两者均保持原侧，不能将结果重新解释为猜 Put/Call 的胜率增量。

保留真实标的路径和官方交割赔付；不可补齐的历史期权报价只用明确的假设估值研究。**主判据是规则执行后的情景增量，不是 MSE。** 预测误差、校准、状态支持用于解释成功或失败的原因。

| 方法 | 同一个监督预测头所接收的输入 |
|---|---|
| WINDOWS | 结构几何＋已有多窗口收益、波动、资金流 |
| DYNAMIC | WINDOWS＋三个30分钟变量的上一期值、4小时和24小时指数平滑 |
| MIX2 | DYNAMIC＋两状态独立高斯混合的软分组概率 |
| HMM2 | DYNAMIC＋两状态高斯 HMM 的在线过滤概率 |
| HMM_RESET | 同一 HMM 发射分布，每行重置为稳态先验，隔离转移记忆的消融 |

状态训练使用每个行情时刻唯一一行，不输入侧别、腿位、期限或多个候选副本。三个变量固定为30分钟收益、对数波动、净主动流；相邻状态输入窗口不重叠。长窗口信息已给予共同监督基线，避免只和弱基线比较。状态按拟合期对数波动均值排序，不宣称发现了 Gamma 或均值回复的因果机制。

每个年度以前21个月拟合、后3个月校准，评价下一年2022—2025。所有这些年份已经研究，属于按时间滚动的开发对照，绝不是新增未见测试。标准化、混合/HMM参数、监督头只用拟合期；校准只用校准期；到期跨边界的机会排除并留可追溯分母。状态参数在校准与评价时固定，逐时只用过去及当刻已闭合资料。

缺失或非法闭合分钟中断序列；不跨缺口连接，不把不同候选当连续行情，不用全序列平滑给较早时点提供未来信息。官方库的全序列解码和平滑定义见 [hmmlearn API](https://hmmlearn.readthedocs.io/en/stable/api.html)；本轮只在拟合期使用 EM，评价采用手工前向过滤。状态概率是隐状态归属概率，不是赔付或极端事件概率。

两状态、对角协方差、200次迭代上限、三个固定初始化；只按拟合期行情似然选择初始化。监督头统一固定为100轮、7叶的 Poisson 均值梯度提升，分别拟合 Put/Call；真实目标包含零和超过1的币本位赔付，不截断。后三个月采用一个有30日先验的非负均值乘法校准，不搜索阈值或新增机制特征。

## 默认估值与动作对照

统一使用欧式 Black–Scholes 假设价，零利率、平坦 IV 40%/60%/80%，USD 值按当时参考标的价转为 BTC；60% 为主情景，另作60% IV 加高成本压力。全部默认值预先冻结，与 HMM 状态及结果无关。常规费用/滑点合计假定原入场宽度 BTC 价值的2.5%，压力为5%，不是交易所实际费率。此简化没有恢复历史偏斜、期限结构、盘口深度或可成交信用。[反向期权契约参考](https://support.deribit.com/hc/en-us/articles/31424939096093-Inverse-Options)

退出：若预测继续持有赔付大于原双腿假设平仓总支出，才在首次触腿点退出，否则持有到期。原建仓信用在同一持仓的增量中抵消。保留持有全部、首次触腿全退出及全部模型对照；未触发、未知路径、缺状态各自留账。退出后不重入、不移腿、不对冲。

结构：预测外移节省大于假设少收信用才选择外移，保留原结构和全部外移对照。两个结构都建两腿，统一建仓费用在相对差额中抵消。配不到同宽外移腿的原机会保留为覆盖缺口，不外推成功配对样本效果。

主比较族固定为两任务各 HMM2 对 DYNAMIC、MIX2，共4个98.75%七日块开发区间；14日块、不同 IV/费用、HMM_RESET 是敏感性，不从中挑通过版本。原机会按侧别/交割日等权，策略动作保留原机会权重；条件预测另按触发或配对日期等权。报告情景增量、ES95、年度稳定性、去十个最有利日期、覆盖、放弃的零赔付修复机会和状态支持。

主情景两项比较区间下界均大于零、至少3/4年非劣、两侧尾损不劣、去十个最有利日期仍为正，并且校准及状态支持通过，才有进一步研究支持。任何真实经济有效、自然NR消费效果、生产资格仍不得由默认情景代替。失败不增加状态数、特征、阈值、参数搜索或新的年份；负面结果只约束本配置，不能否定所有序列模型。

## 执行中发现的价格来源盲区与独立修订

`source_correction_02.json` 单独封存，SHA256 `ade31f6cc6d40bee827c409032b474ade3a6fff59588affe8101c085d5c2934f`。新 run_02 以显式适配器读取档案现货 `entry_price` 及现货分钟时间；缺失或陈旧时不回退永续。状态仍由原三项永续行情变量估计，同侧配对、全部模型超参数、估值假设和验收门不变。新增测试刻意让现货和永续分处短腿两侧，防止测试夹具再次掩盖来源混淆。

## 最终结果与本地验收

run_02完成四年度，143552条任务预测。主情景 HMM 相对DYNAMIC、MIX2：退出增量分别为 +0.00008119、−0.00008879；结构增量分别为 +0.00014170、+0.00014033，均按原宽度入场BTC价值归一。四个98.75%主区间均跨零，四个比较均未满足两侧ES95同时不劣。退出相对DYNAMIC去十个最有利日后转负；结构4/4非劣包含2023零差异，不是四年严格改善。

HMM对关闭过滤记忆的HMM_RESET也未证明额外效用；现有窗口基线在本轮两任务两侧的MSE点估计均优于HMM。不能由此否定所有序列模型，也不能把WINDOWS认定为永久最优。

包含时间价值和费用的主默认估值下，全部触腿退出相对持有的平均增量约−0.052712，尾损却明显降低；HMM选择退出约−0.001224。结构全部外移约−0.019139，HMM选择外移约−0.003003。默认估值会影响结果，这些不是账户收益率、真实市场EV或自然卡效果；不能再把即时内在差额当平仓价格。

独立验收：工程通过，研究采用门未过。2023年度Put退出的一个状态只有9个校准交割日，低于冻结10日要求。全部模型/研究失败记录15条，保留于R15 `validation_01/failure_ledger.json`。本轮49项相关测试通过；四主区间和ES95独立复算一致，最大主量差约1.1e−18；63993条未受来源修正影响的结构预测逐值一致。研究完成不等于模型采用、发布或经济有效。

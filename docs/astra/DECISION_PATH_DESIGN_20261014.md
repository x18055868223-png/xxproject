# Decision Path：实盘决策实验台（第二版设计）

日期：2026-10-14 · 分支 `claude/astra` · 状态：已确认并实施（§9）。第一版（直接重排保单卡）已被用户意见替代。

## 0. 一句话

两侧保单负责选对象；Decision Path 负责核验对象；核验是锁定的前置动作，锁定是核验的结果。
长期要沉淀的，是一条从事实到决策最短、而且每一步都确有增量的最小决策链。

Decision Path 不是新的分析模型，而是一个实盘决策实验台：
- 它集中定义阅读顺序，并记录每一步是否改变了判断；
- 事实与分析仍分散在原来的组件里。

## 1. 职责划分

| | 两侧保单卡（候选页） | Decision Path（独立区域） |
|---|---|---|
| 职责 | 发现、比较、选择对象 | 核验一张具体保单 |
| 内容 | 腿、到期与剩余时间、短腿距现价、盈亏平衡距现价、短腿 Delta、到期前事件数；一个按钮"开始核验 / 继续核验" | 按固定顺序逐步核验，最后给出结论 |
| 去掉的东西 | 模型 Q1/Q2 正文、约简、四要素对照、锁定按钮、复核按钮（都移入 Decision Path） | 不复制地图、五要素、背景；只读它们的程序读数，并链接回原组件 |
| 迭代 | 基本不再动 | 以后调整顺序或删减步骤，只改这里 |

权利金是否留在保单卡上，属于待决定项（§8-1）。

## 2. 核验会话：绑定一张具体保单

- **开始核验**
  - 服务端创建一条核验会话，冻结当时那张保单的身份（`candidate_id`、`snapshot_id`、两腿、到期、侧）和开始时间。
  - 每一步的读数都从这份冻结快照计算。
  - 之后即使候选页换了腿或换了到期，会话仍然只围绕这张保单。
- **继续核验**：同一张保单若已有未结束的会话，回到上次的位置。
- **刷新到现在**
  - 核验通常要花几分钟。会话里提供一个动作：按同一合同重新取一次（复用锁定采样的同合同报价），每一步并列"开始时"和"现在"两个读数。
  - 这是取同一张合同的新报价，不是重新选择对象。
- **结论**：三选一，并写入会话。
  - **锁定追踪**：以结论时刻为 t0 创建锁定，锁定记录里带上核验会话 id。
  - **不承保**
  - **继续观察**：会话保持打开，可以稍后继续。
- **过期**：合约到期后会话自动关闭，结论记为"未结论"。

锁定可以由 Decision Path 的结论产生（记录带核验 id，锁定列表标“经核验”）；用户决定（§8-4）保留保单卡上的“直接锁定”，两种行为并存。

## 3. 推理链：先长后短，用数据削薄

起点是 9 步。步骤顺序是唯一需要实验的变量，以 `path_version` 标识。

| 步 | 问题 | 读哪里 | 读数（固定词表） |
|---|---|---|---|
| D0 资料 | 能读吗？ | 报价时效、FMZ 事实、来源 | 可读 / 部分可读（列出缺口）/ 停 |
| D1 责任 | 这张保单承担什么？ | 合约、赔付形状、到期 | 方向、责任区、最坏赔付形状、剩余时间（不出现权利金） |
| D2 位置 | 现价离责任区在结构上多远，途中有什么？ | 短腿距离对比到期前隐含波动、**本期 Call 墙 / Put 墙 / Pin（新增）**、空间位置、锚点、Gamma 体制 | 缓冲：宽 / 中 / 窄；途中先遇到：本期墙 / Flip / 无；钉住 / 放大 / 过渡 |
| D3 运动 | 正往哪动？会不会被放大？ | 量价路径、主动成交 4h/12h、M-DIE、Gamma | 朝责任区 / 背离 / 无方向；持续 / 新近 / 反复；若同时朝责任区且负 Gamma，判为易放大 |
| D4 外部 | 这期哪些外部信息值得看？ | 事件、跨资产、宏观 | 只列通过过滤的条目，其余写"本期不必参考" |
| D5 变化 | 怎么变到现在的？ | 多窗口字段、锚点与空间门变迁；核验期间"开始时 → 现在" | 持续 / 新近 / 反复 |
| Q1 风险质量 | 合起来风险是什么样？ | 程序汇总 D1–D5 | ≤3 条，每条引用一步 |
| Q2 风险补偿 | 给的钱够不够看？ | 净信用、信用占宽度、市场估价差、**RV 对 IV（可选新增）** | 补偿相对 Q1 的对照（不给概率） |
| 审计 | 模型认同吗？还剩什么要你判断？ | 对冻结快照的观察复核、决策约简 | 认同 / 分歧（逐条）；待你判断的问题 ≤3 条；按需触发 |

D4 的过滤规则：
- **事件**：只列合约有效期内的 6 类重要事件。
- **跨资产**：只说本期合约是否跨过美股交易时段，不进入判断。
- **宏观**：只有逆风或顺风、而且方向朝向卖出侧时才列出。
- **资金与慢背景**：永远不进路径。

防污染的硬约束：
1. 步骤按顺序展开。Q2 在 D1–D5 都看过之后才展开，审计在 Q1、Q2 之后才可触发。
2. D1–Q1 不出现任何权利金数字。
3. 读数只用固定词表。叙事只允许出现在审计里，而且必须引用程序读数。

## 4. 实验记录：这一步改变判断了吗？

- 每一步下面有三个可选的一键标记：更倾向承保 / 没变 / 更倾向不承保。不标记视为"没变"。
- 每次核验写一行记录，包括：
  - `path_version`、保单身份、各步读数（开始时 / 现在）；
  - 用户标记、每步停留时间、结论和锁定 id。
- 每张被核验过的保单到期后，用 Deribit 交割价回填到期结果（复用锁定的结算代码）。无论是否锁定，都有结果。
- 每 2–4 周生成一份短报告。对每一步统计四件事：
  - **改变率**：有多少次被标记为改变了倾向；
  - **共线率**：读数和上一步同向的比例；
  - **结果分离**：按读数分组，看到期结果分布。样本很少，只看是否明显分开，不算概率；
  - **结论来源**：哪一步之后倾向定型。
- **削薄规则**：一步连续 4 周既很少改变判断、又不分离结果，就降级为背景，`path_version` +1。目标是最后留下 4–6 步。
- **顺序实验**：将来可以给同一批步骤换顺序，发布新的 `path_version`，在不同时段使用，再比较结论来源和改变率。

## 5. 价格地图的缺口：本期 Call 墙 / Put 墙 / Pin

**现状（读视图实测，2026-10-14）：**
- 地图上的"磁吸位"是 gexmonitor 的 `magnet_price`，取全部期限，当时是 80000，离现价约 −3.7%。它不是本期的 Pin。
- 周度和 0DTE 两组的磁吸位都是 83000，地图没有画出来。
- 地图画了 gexmonitor 的周度和 0DTE "净 GEX 正 / 负墙"（例如 0DTE n1 = 83000、p1 = 86000）。但这组数据没有标明到期，也没有区分 call 和 put，所以不是 call wall / put wall。
- 本期到期（15OCT26）在 gexmonitor 里只有一个值：最大痛点 83500。

**判断：**这是缺口。对一张约 24 小时到期的保单，本期的 Call 墙、Put 墙和 Pin，是 D2 里最直接的结构位。

**补法（工作台侧，不改 FMZ）：**
1. 每轮刷新请求一次 Deribit 公开接口 `public/get_book_summary_by_currency?currency=BTC&kind=option`，一次就能拿到全部期权的持仓量、标记 IV 和标的价格。
2. 取合约到期那一期，用 Black-Scholes 按标记 IV 算每个行权价的 Gamma，再乘持仓量，得到 call 和 put 各自的美元 Gamma（按价格变动 1% 计）。
3. 由此得到三个位：
   - **本期 Call 墙**：call 美元 Gamma 最大的行权价；
   - **本期 Put 墙**：put 美元 Gamma 最大的行权价；
   - **本期 Pin**：到期前预期波动范围内，总 Gamma 最大的行权价。
   每个位都附上到期、时刻和口径，同时给出按持仓量计的墙作为对照。
   试算（2026-10-14 约 10:00 UTC，本期 15OCT26，距到期 21.6 小时，现价 83,335，到期前预期波动约 ±1,406）：

   | 口径 | Call 墙 | Put 墙 | Pin |
   |---|---|---|---|
   | 按 Gamma 加权 | 83,500 | 83,000 | 83,000 |
   | 按持仓量 | 85,000 | 83,000 | — |

   临近到期时 Gamma 集中在平值附近，Gamma 加权的墙会被拉到现价边上。所以两种口径都给，并且分开命名：
   - "本期 Gamma 墙"：反映对冲压力在哪里；
   - "本期持仓墙"：反映仓位堆积在哪里。
4. 地图上，这三个位用醒目标记并写明到期（"本期 Call 墙 85,000 · 15OCT"）。全期限磁吸位降级为"全期限磁吸"。gexmonitor 的 0DTE 墙如果与本期墙重合就不再重复显示。
5. 在数据来源注册表里登记，有效期按刷新周期设置。拿不到数据时显示"本期墙暂缺"，不回退到全期限数值冒充。

**FMZ 本体：**这一轮不需要改。本期墙只服务于工作台的保单核验，FMZ 的空间门仍用它自己的数据。将来如果要让 FMZ 也用本期墙，再按三层版本门单独发布。

## 6. 缺失维度审计

| 维度 | 结论 |
|---|---|
| 本期 Call 墙 / Put 墙 / Pin | 缺失，本轮补（§5） |
| RV 对 IV | 缺失。程序路由已标记为缺失；FMZ 快照只有 M-DIE 用的窗口级未年化数值，不能和 IV 比。Deribit 公开接口 `public/get_historical_volatility` 一次请求就有小时级 RV。可以本轮作为 Q2 的一行加入，也可以放到下一轮（§8-3） |
| 其余 | 不缺；是否重复由 §4 的实验记录回答 |

## 8. 待用户决定

1. 保单卡是否保留权利金。
   - 建议只保留"信用占宽度"一个比值，供 Put/Call 比较，金额留到 Q2。
   - 如果要彻底防锚定，可以全部移入 Q2。
2. 每一步的一键标记（更倾向承保 / 没变 / 更倾向不承保）是否默认开启。建议开启，这是验证"哪一步真正改变判断"的唯一直接数据。
3. RV 对 IV 放在本轮还是下一轮。建议本轮加入，它只需一次公开请求，而且是 Q2 唯一缺失的维度。
4. 保单卡上直接锁定的入口是否彻底移除。建议移除，锁定只作为核验的结论。

## 9. 用户决定与本轮落地（2026-10-14）

**§8 的决定**
1. 保单卡只保留“毛信用占宽度”一个比值；金额、费用、市场估价、最坏亏损都在 Q2。
2. 每步一键标记默认开启。
3. RV 对 IV 本轮加入（Q2 一行）。
4. **保留**保单卡的直接锁定：核验后锁定与直接锁定并存。

**不与原消费端冗余：三条规则**
1. **数据只复用，不重算。** Decision Path 的读数只把已有程序输出说成固定词表：空间位置（`astra_spatial_position_v1`）、决策约简里的市场估价与最坏亏损（`astra_decision_reduction_v1`）、事件日历、跨资产合约窗口、FMZ 事实、锁定结算代码。新增的只有本期墙 / Pin / RV（`astra_expiry_gamma_v1`），它同时服务地图和 D2/Q2。唯一的小重复是量价与成交的方向判断（页面五要素卡与 D3 各有一份“偏多 / 偏空”换算），规则一致、只有几行。
2. **细节只画一处。** 每步只给一个判断字和不超过几行证据，完整内容留在原组件，用“细节在：价格地图 / 五要素 / 外源性事件 / 推理审计”链接跳回（跳到地图会同时切到该侧）。D2 内嵌原有的“距离标尺”，审计步内嵌原有的模型 Q1/Q2 解释与复核按钮，都是同一个渲染函数搬家，不是复制。
3. **一个内容只有一个家。** 从保单卡移走（不是复制）：决策约简块、四要素对照、距离标尺、模型 Q1/Q2、复核按钮、事件明细（卡上只留件数）。决策约简的数字由 Q2 使用，它的旧渲染已删除。

**最顺手的消费链路**

价格地图（全局结构，含本期墙 / Pin）→ 两张保单卡（比较、选择）→ “开始核验”→ Decision Path（就在卡片下方，逐步展开、每步标记；需要细节时跳回原组件）→ 结论：锁定追踪 / 不承保 / 继续观察 → 锁定追踪（原有：依据账本、持有中复核、盈亏）→ 到期回填结算 → 离线报告（`tools/astra_decision_path_report.py`）。直接锁定是这条链的捷径，记录里没有核验 id，报告据此区分。

**实现位置**
- `tools/astra_expiry_gamma_v1.py`：本期 Gamma 墙 / 持仓墙 / Pin、ATM 标记 IV、24h / 7d 实现波动；工作台线程每 5 分钟一次（`ASTRA_EXPIRY_GAMMA_ENABLED`，默认开），状态存 `expiry_gamma.json`，读视图字段 `expiry_gamma`。
- `tools/astra_decision_path_v1.py`：`STEPS`、`PATH_VERSION`、每步读数纯函数。
- `tools/astra_decision_path_store_v1.py`：会话与 `decision_path/records.jsonl`。
- 工作台接口：`GET /api/workbench/decision-path[/<id>]`；`POST /api/workbench/decision-path`（开始 / 继续）、`.../<id>/refresh`、`.../<id>/step`、`.../<id>/conclude`。读视图字段 `decision_path`，锁定列表字段 `verification_id`。
- 页面：`decision.js`（新）、保单卡瘦身、地图本期墙 / Pin 标记；卡片与地图的预期波动在期限结构缺本期时改用本期 Deribit 标记 IV。

# 统计规律与机制研判：路线抉择

日期：2026-09-14。性质：原则讨论与待办登记。用户随后明确：统计与机制推理不互斥，可以以数据和统计强化模型、辅以因果推理，再检验组合增量。本文据此讨论职责与验收原则，**具体方案尚未采纳，不是交易规则或实施授权**。

## 一、已确认的暂停边界

用户要求先讨论根本路线。原 Astra v2.3／FMZ 1.6.3“空间锚、择时与选侧协同优化”计划列为暂停待办：环境职责调整、背景窗口补充、结构迁移记录和评审协议升级均不启动。评估33仍保留为理论假设，不能自动成为下一项实施任务。

本轮只核对既有资料、代码与公开一手资料，不修改 FMZ、Prompt、评级、页面或生产，不启动新回测、模型请求或定时任务。路线明确后重新审视待办，不能默认整份旧计划继续执行。

## 二、先校正路线的含义

“统计”并不等于“不预测”。它可以不依赖完整的经济因果解释，但仍须估计条件结果、赔付或交易回报。Renaissance 官方将方法描述为数学与统计方法；西蒙斯基金会公开访谈也专门列出寻找新预测因子的章节。这里引用公开方法定位，不推测其非公开交易策略。[Renaissance 官方](https://www.rentec.com/Home.action?index=true)、[基金会原访谈入口](https://www.simonsfoundation.org/2024/05/14/jim-simons-reflects-on-his-career-in-mathematics/)

历史规律是候选证据，不能由“曾经发生”推出“今后会按相同频率发生”。相同形态下的库存、波动、期限、流动性及报价可以改变。去主观化的可执行含义是让样本、规则、目标、失败和裁决透明且可复核；事件定义、研究选择与风险偏好仍需要判断。

当前链路中的“因果推理”主要是机制假设与事实解释，尚不是对冲义务、墙位或微观压力导致交易优势的因果识别。不能拿未经验证的机制解释与理想化的统计模型作不对称比较。

## 三、负责人的路线建议：统计检验决定规则是否采纳

建议以 **DIE＋Anchor 条件事件的统计研究**作为下一阶段验证主线，机制知识用于定义事件、压缩假设空间、改进条件选择和诊断失效。因果推理可以实质改变模型或决策，不局限于事后解释；改变是否有效仍需对照检验。LLM解释或人类直觉可以提出候选，但不能凭叙述有说服力就获得交易优势的身份。

这项建议有明确主次，不是让两套结论并列：当机制叙述与可靠的新样本结果不一致，应修正或停用对应规则；结果不明确时保留未知，不能用更丰富的叙述宣布通过。反之，统计关系不必等到经济故事完全解释清楚才能研究，但仍须检验数据泄漏、替代解释、成本及失效。

| 对象 | 当前可承担的职责 | 尚不能声称 |
|---|---|---|
| DIE＋Anchor | 定义位移、损伤、修复确认等候选事件 | 每次事件都是真实再均衡；所有版本的事件完全相同 |
| 期权空间与环境 | 候选特征、分层条件、机制假设 | 墙位必然承接、正净Gamma必然抑波 |
| 条件统计 | 检验事件后结果与基准是否不同，进一步比较实际补偿 | 历史相关性自动持续；显著性自动等于可交易价值 |
| D–S与LLM | 解释已有证据、提出或应用冻结的机制判据，另行检验决策增量 | 字母已经校准为胜率；更合理的说明代表更高净收益 |
| 交易员判断 | 提出遗漏机制与实际交易取舍 | 未单独记录的临场调整可归为模型成绩 |

若统计是规则的最终检验依据，Anchor与择时本身也必须允许失败。不能只检验“猜拳”，同时把空间锚和事件时机当作已经证实的优势。

## 四、为什么适配垂直价差，又为什么不能只看形态重复

信用价差的目标可以直接表述为：在事件与入场前条件相近时，给定期限和候选两腿，赔付分布如何变化。它不要求猜中精确收盘价，也不要求为每次涨跌寻找原因。

以同一计价币种、同一名义数量及明确期限计：

**条件期望净结果＝实际净信用－条件期望两腿赔付－尚未计入的成本。**

净信用若已扣除某项费用，不重复扣费。除均值外还须比较尾部、资金占用、覆盖率和估计不确定性。币本位赔付保留既有完整公式，不把美元宽度当成固定BTC赔付。

必须分别验证三层：

1. **事件是否有信息：** 相似期限与背景下，确认事件之后的分布是否不同于非事件基准。
2. **条件是否帮助选择：** 同一事件内，少量事前条件是否改善选侧或候选选择，胜过简单固定侧等基准。
3. **信息是否有经济价值：** 减少的赔付能否覆盖少收的信用、成本及承担的尾部风险。

第三层不因换成统计路线而消失。期权价格中的风险中性权重与现实频率并非同一概念，风险补偿也参与定价；因此“公开信息意味着卖方真实期望必为零”不成立，但发现历史规律同样不能推出市场漏价或正Alpha。[BIS：波动率概念与风险溢价](https://www.bis.org/publications/volatility-concepts-and-risk-premium)

## 五、现有资料支持到哪里

既有[研究30](30_局部定式长期验证结果.md)与[共识32](32_核心发现与后续迭代共识.md)已经进入统计比较，因此当前分歧是研究和决策的主次调整，并非项目从未使用统计。

- 176张确认事件、其中114张普通轮候选，适合探索共同事实与结果关系；它们已被多轮查看，不再作为未见检验集。多个事件共享交割日，不能把卡数当独立结果数。
- 2,643个长期时钟入场、881个交割日可以检验既定代理条件和策略背景，但不是2,643个原生DIE＋Anchor事件。其缺少完整历史Anchor、GGR和墙位；合约主动流与生产现货成交量柱也不同。
- X1/X3未通过、X2未形成合格候选，意味着已检验的局部代理方案未证明有效。它们既不能证明完整Anchor路线有效，也不能否定所有事件条件统计研究。
- 历史成交与mark提供有限经济描述，不能当成同步可成交双腿报价。当前报价不能倒填旧事件。

更好的算法无法补造过去的有效锚、来源更新时间或状态转移。把价格区间、事后最适锚或新模型重评当成当时原生输入，会换掉研究对象。

本轮代码复核发现，NR确认依赖事件上下文、损伤、修复计数和有效锚的接受过程；单张确认卡不足以重放此前全部状态。现有本地研究资料不含可覆盖该历史的完整连续状态流。但盘点文件 `selection-and-coverage.json` 留有9份服务器快照文件头线索，**不能由本地未取得完整日志推出服务器也没有，或直接决定只能从现在重新积累**。这些文件的完整覆盖、字段和回放可行性本轮没有远端核验。

只读代码依据：完整工作树 `tools/astra_light_study.py::normalize_archive`、`demo/最新交付物/neutral_regulation_demo_fmz.py::NeutralRepairSignalTracker.update` 与 `GexAnchorState.ingest`。研究包哈希复算不等于原生产事件状态机重放。

## 六、适配性、可行性与成本的判断

**方法适配，但当前数据尚不足以直接交付统计驱动的可靠交易决策。** 个人投资者可以研究单一资产、限定期限和少量条件，不必先建机构级系统。首要难点是可还原的事件与足够多的独立结果，随后是同期补偿；增加模型规模会提高样本需求，不会解决这些缺口。

事件定义收窄搜索空间，也会降低样本频率。“形态天然一致”需由固定可计算定义支撑，不能仅因都叫修复确认就忽略版本和路径差异。只保留确认事件可以研究确认后表现；若要判断择时检测器的增量，还需可比的非事件或未确认过程，不能从成功触发记录中恢复它们。

统计的主要风险是研究者选择转移到样本、标签和参数搜索。反复挑出最好结果，即使程序完全确定，也可能选中噪声。研究过程和试验次数需要留痕，不能每次修改规则后都把同一历史称为新验证。[Bailey等：回测过拟合概率](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)

## 七、统计与机制结合：检验组合增量，而不是相加信心

用户补充的联合方向是合理候选。统计可以回答相似事件中哪些条件有用，机制可以识别统计混合了哪些环境、为什么某些条件不能迁移、如何构造更稳定的特征。这类协同不要求先证明全部经济因果，也不以观点一致代替结果验证。

评估上分开四个研究对象：同交易基座的简单基准、仅统计条件、仅机制判据、统计加机制。保持信息时点、候选机会、期限和资金风险口径可比，保存未选结果。若机制是人工临场判断，应事前记录，不能事后按输赢补写理由。这不是要求每轮同时完成四组工程，可按资料可得性分阶段比较。

联合方案至少需要回答：加入机制后，相对统计方案改善了什么；加入统计后，相对机制方案改善了什么；最终是否胜过简单基准。可能表现为更少尾部亏损、更好的净结果或同等风险下更有效的覆盖，而不只胜率上升。

两路单独有效不保证组合更好；单独没有明确增量也不排除存在交互作用，但不能以此反复搜索已见样本。两路引用同一Anchor、Gamma或主动流时，不是两份独立市场证据。机制可以是模型内的条件，也可以是外部复核；不默认必须两个都同意才交易，否则会引入未经验证的新过滤器。

垂直信用价差的高胜率形态取决于腿位、期限与净信用，并非策略名称自带保证。它作为所有对照共同的交易基座，不能再被当成第三份独立优势相加。正净结果仍可能是承担系统性尾部风险的补偿；证明选择增量和证明风险调整Alpha是不同要求。

## 八、路线选择之前的最小决策问题

不先建设模型或扩大指标。先回答一个可行性问题：**能否以固定事件定义，从当时可得资料获得足够广泛、没有未来信息的事件与对照？**

后续若授权开展这项盘点，先核验上述9份服务器快照的覆盖、字段及连续性，再判断回放能力；不能仅根据本地资料缺口作最终裁定。

- 可忠实回放：可以考虑以历史事件条件统计为主，保留真正未用于研究选择的数据。
- 只能部分回放：明确哪些是假设代理研究；不能套用原生Anchor的名称宣布通过。
- 不能回放：原生自然积累仍可走统计路线，但研究速度受事件频率制约。应先评估这条等待路径的投入产出，不能为了快速得到结论而伪造完整历史。

这只是后续开工的判断门，不是本轮启动数据工程、自动报价、重评或新回测的授权。路线讨论未完成前，原优化计划持续暂停。

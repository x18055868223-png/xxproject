以下表述仅对应前序阶段，当前路线以方案07和项目记忆第0节为准。

## 0. 当前已批准的实施路线

用户已批准[信号舒适度评级与页面收束](../06_信号舒适度评级与页面收束.md)，已于 2026-09-08 完成本地实现与验收，尚未发布。前一版原生四态链路已完成本地验证，但未经页面发布确认，不能继续按“等待上一版发布”推进。

主路径是：producer 原生四态事实 → 同一次现有 LLM 对照复核产生 Put/Call D–S 建议 → 本地核验与限级 → 中文审计页供人工使用。B 启动页面注意力和筛选，不新增推送；A 是信号层准入，允许人工交易准备，具体两腿、报价、补偿和下单风控随后确认。S 为当期优先级，不是胜率或已验证寿命。

旧 confidence 与耐用分不平均、不新增数值准入线；复用它们的底层事实并按来源去重。旧 confidence 仍可能经既有 WAIT/BLOCK 影响准入，本轮不暗中更换机器消费者。原方向、NR、触发与执行许可保持；只读权限关闭不等于结构不适配。

页面包括展开区、提示和错误信息都退出机器字段、原始码、schema/hash、公式及实现说明；保留中文事实、重要数值与时效，完整审计资料改为下载。producer 四态与 LLM 舒适度分开留存；页面只显示最终等级和对应侧别，局部有效观察不因评级缺失而删除。

实现仍在 codex/astra-signal-rating-v1，基点为完整资产 2c7216229a0f64c95cc37355e6151bf0cee01189。此前指定的链路、场景、浏览器、隔离 API 和独立审查已完成；API 有失败与手动验收重试记录，不能写成每次稳定成功。2026-09-08 按用户提出的“空间约束先于动量”再次进行语义复核，发现工程检查未覆盖的判据和显示缺口，详见[评估](2026-09-08_结构优先评级与LLM健壮性评估.md)。当前建议先完成这些修正及重新验收，再经“当前本地页面可推送”确认向 xxproject 发布；不再将当前停点写成仅等待页面批准。此次为评估和文档更新，未改变运行规则，未提交、推送或部署。

本次核验后的稳定认识：D–S 当前是模型建议经本地限制后的行动优先级，不是已验证的价差适配度排序。来源可用不等于空间约束成立；有效引用不等于主张得到证明；同模型盲读与复核不是两份独立证据。真实返回中反证被整段过滤的问题须保留为反例，中文化不能删除风险事实。

对当前价差用途的研究建议是先解释不利侧侵入约束，再解释方向与竞争压力；约束可以单侧成立，也可以被有效的反向流推翻，不能把正 GEX 或某个原生枚举当作唯一通道。S 的额外事实必须解释用途增量；有效但不投票的数据仍可能有信息，不能把“不投票”当缺失。上述判据调整尚未实施，不追溯改变历史等级。实际交易是否值得做仍依赖具体腿、净补偿与持有/退出条件。

**最新澄清与当前研究方向：**用户明确 B–S 是总体证据等级，不是逐级增加条件或趋向完美行情。前段“先空间”的含义应是关注不利侵入这个目标，不能演变成固定空间指标先过硬门。主 agent 已将当前建议收束到[总体证据等级与最小推断链](2026-09-08_总体证据等级与最小推断链.md)，替代评估早期的具体分级修法。允许期权、量价、主动成交和价格响应相互解释，允许局部分歧及有用途的新描述量；同一评价维度下，B/A/S 表示总体支持有限、较强、很强，不要求新增来源。S 可来自已有事实关系的更强辨别力。

建议将证据等级和行动状态分开，例如“证据 A｜当前等待”；旧 WAIT/BLOCK 和执行权限不因此解除。当前代码仍限级到 B，必须在后续显式调整评级/展示契约后才能采用新含义，不能直接改名。贝叶斯先用于竞争解释和定性更新，未取得可靠似然前不输出概率；两张真实卡已有路径信息只是 OHLC 代理，不能据此声称观察到逐点吸收或未来寿命。此次仅更新研究文档。

# 总体证据等级与最小推断链

日期：2026-09-08，Asia/Shanghai。本稿承接[实际代码与 LLM 评估](2026-09-08_结构优先评级与LLM健壮性评估.md)。用户进一步明确：B–S 是总体证据等级，不能逐级增加理想行情条件；可复用期权、量价、主动成交、价格路径，允许有目的地合成新指标。以下为据此形成的当前研究建议，尚未修改评级代码或执行权限。

## 1. 修正此前过硬的表述

“空间约束先于动量”应理解为研究目标和论证关系：重点判断不利侧扩展是否受到约束；方向、主动成交与价格响应都可以参与建立这个判断。它不是“先证明一个独立且完美的空间指标为真，再允许其它数据发言”，也不是空间占多少权重、方向占多少权重。

不要求固定来源齐全、全部因素同向、正 Gamma、横盘、低波动或已经经历某种特定压力测试才能达到 A/S。不同证据组合可以支持同一级判断；反向成交与价格不跟随的组合可能支持吸收解释，并非天然互相抵消。与此同时，单纯“方向偏多”仍不能自动证明 Put 的不利侵入受约束。

此前代码反例仍成立：问题是缺少对主张的有效论证，不是 `structure=INSUFFICIENT` 这个字面状态本身绝对禁止高等级。若已有其它事实能建立更好的约束解释，应允许提出并校验。本文替代前一份评估第 5 节关于具体分级办法的初步建议；已核验的代码问题和原始证据保留。

## 2. 一个目标、两个侧别、相同评价维度

主命题：**截至本卡时点，现有证据整体更支持该侧不利价格扩展受到约束，还是约束正在被穿透或迁移？**Put 关注下行，Call 关注上行。它服务信用价差环境选择，没有假定某条未接入的短腿已经安全，也不声称约束能持续到到期。

比较两个竞争解释：约束维持与不利扩展。另保留“看似平静只因暂时缺少压力”等替代解释。固定同一组评价问题：事实有多直接、与该侧风险有多相关、来源/时点多可靠、是否重复、能否区分竞争解释、关键反证是否改变结论。不是每项打分后平均，也不是来源数量投票。

| 等级 | 总体证据含义（建议） | 允许存在的情况 |
| --- | --- | --- |
| D | 有效事实总体反对该侧适配解释 | 可以是高质量的反对证据，不表示数据质量低 |
| C | 可以形成判断，但尚没有明显支持该侧适配的证据优势 | 数据可用、结构普通；不同于缺数据 |
| B | 已有有辨别力的支持，值得关注；竞争解释仍有实质分量 | 有局部分歧或尚未解决的机制依赖 |
| A | 总体论证较强，约束解释比不利扩展解释更有依据 | 不必所有因素同向，不必等待完美确认 |
| S | 同一主命题得到很强的整体支持，关键替代解释更难成立 | 可以来自少量更直接的事实；不必增加来源、指标或特定行情条件 |
| 未评级 | 主命题无法有效判断、关键数据不可用或输出无效 | 局部事实仍然展示，不补成 C/D |

B/A/S 的差别是论证支持的强弱，不是三套越来越苛刻的交易标准。S 比 A 多的是整体证明力，可以来自已有事实的更清楚关系、更有辨别力的价格响应或关键不确定性的减少，未必是多出一张“独立票”。这些是版本化的专家判读等级，尚不是校准概率或已验证收益排名。

**证据与行动应分别表达。**如果继续把 WAIT/BLOCK 机械压成 B，字母就仍是行动等级，不能同时叫纯证据等级。建议最终只保留一套证据字母，另写“当前等待／风险阻断／可进入人工准备”；例如“证据 A｜当前等待”。A 级默认可以启动准备的含义，以原边界允许为前提；S 也不解除阻断。这需要显式修改评级与显示契约，当前代码的限级行为尚未改变，旧执行许可和触发规则始终保留。

## 3. 用已有资产形成推断链

推断顺序是信息依赖关系，不假装是已观察到的市场因果先后。

| 推断环节 | 当前可复用事实 | 解释任务 |
| --- | --- | --- |
| 结构与位置 | 有效锚、锚带、Gamma/墙位、净暴露及来源状态 | 哪些位置/反馈可能抑制或放大不利扩展？结构假设是什么？ |
| 当前压力 | 量价方向与强度、主动成交、宏观、资金费率/偏斜背景 | 不利侧压力是否存在？是持续推进、拥挤风险还是非方向背景？ |
| 压力对应的价格表现 | 已有路径效率原始量、开高低收、变化幅度、相对边界位置 | 压力是否伴随价格推进？哪些解释更像传导受阻，哪些更像约束失效？ |
| 变化与反证 | 评级前可取得的同版本快照、结构位变化、已有 episode/窗口事实 | 判断正在增强、减弱还是缺乏变化证据？什么事实会改变当前结论？ |

不是每张卡都必须完成四段才能有高等级。某一段未知时，检查当前论证是否依赖它；没有依赖就不机械扣级。证据之间先按来源与时间组织：期权衍生量不能拆成多次确认，量价与价格路径也有重叠。不同时间窗的成交与价格不能直接宣称因果吸收。

现有 CVD 逻辑已经区分买推动上涨、卖推动下跌、买被吸收和卖被吸收，保存同窗口的成交强度、价格变化与联合激活状态；应先复用这些原始关系，避免再造同名吸收模型。其“吸收”名称本身仍是价流象限解释，不是看到隐藏订单的事实。当前主干量价使用 24/48 小时，主动成交有 4/12 小时窗口，短路径又不同；先在同窗口解释压力与响应，再把多窗口分歧作为背景，不能把聚合值串成实际发生顺序。

已直接核验的复用限制：producer 的 `compute_price_path_efficiency()` 同时支持价格点路径与 OHLC 代理；两张真实研究源卡实际均为 OHLC 代理。9201 的值约 0.631，7cbd 约 0.668；这些表示开收净移动相对高低跨度，不是走势先后、反复测试次数或未来寿命。旧耐用层的“有利/不利”按旧信号方向计算，不能直接同时用于 Put/Call。低效率加“处于锚带内”被旧规则解释为吸收，只是启发式，不能冒充实际订单吸收的观测。

另一个必要来源边界：旧锚耐用逻辑在缺锚时可用现价、缺带宽时可用默认比例构造背景。这种回退不能成为“真实结构很稳”的支持证据。移除该支持不等于整卡未评级，仍检查其它可用论证。

## 4. 允许合成指标，但先增加关系信息

首轮建议只研究以下三种描述量，按用途决定是否计算，不新增一批总分：

1. **不利侧推进程度。**将已有价格净移动、跨度/路径长度分别按 Put 下行和 Call 上行解释。有价格点时描述实际采样路径；只有 OHLC 时明确只是柱内净移动代理。高效率朝不利侧推进可反对约束；低效率本身不等于吸收或低风险，完全平盘等边界情况单独处理。
2. **压力与响应关系。**同窗口的主动成交偏向，与价格推进程度联合呈现为推进、传导弱、分歧或未知。不把单位不同的两个数字直接相减；也不先编造吸收概率。卖压存在但下行难以推进只是支持传导弱的证据，仍要比较暂时无流动性、时间错配等解释。
3. **不利侧空间余量与迁移。**复用现价相对有效边界的距离；可用明确来源的带宽或同窗口价格尺度归一化。分开价格移动与边界本身移动，避免墙位追随价格时虚构缓冲增强。没有有效边界不造边界，允许其它机制路径继续判断。

每个衍生描述必须保存原输入、时点、计算方法、来源组和缺失处理。它不因有新名称成为新证据。旧置信/耐用总分不再加一遍；复用原始事实前核对来源权威，避免重复副本或陈旧字段重新进入论证。

## 5. 贝叶斯式更新与 LLM 的分工

可以借用贝叶斯方法的核心：先提出竞争解释，问一条观察在两种解释下是否同样容易出现，再按新增辨别力更新判断。仅仅“与约束相容”不够；若突破前也同样常见，这条观察的证据作用应很小。条件概率模型还必须表示来源依赖，不能把同源指标当作独立似然连乘。[Berkeley 贝叶斯网络说明](https://inst.eecs.berkeley.edu/~cs188/textbook/bayes-nets/representation.html)、[朴素贝叶斯的条件独立假设](https://scikit-learn.org/stable/modules/naive_bayes.html)。

当前没有对应事件、窗口、先验与似然的已校准估计，首版采用**定性证据更新**；不能让 LLM 随口填写概率，再包装成后验。将来如果做数值贝叶斯，须另行固定目标事件/边界/时间窗、估计参数、检验依赖和样本外校准；这不是现在启动评级的前置工程。[概率校准说明](https://scikit-learn.org/stable/modules/calibration.html)。

沿用现有两次调用：盲读形成竞争机制解释；对照复核检查来源、价格响应、反证和总体证据等级。它们是同一模型两阶段，不是两份独立市场证据。本地负责可确定的事实、单位、时间、重复来源和权限校验；LLM 负责相互关系与竞争解释。对复杂主张的本地检查也有能力边界，不能宣称只靠几个规则就验证了全部金融推理。

页面展示一条完整论证：等级与侧别、为何支持、最强竞争解释、当前行动边界、什么观察会改变判断。修复此前“报价词命中后删整段反证”的问题；附加 24 小时报告与核心评级按真实依赖分别验收，必要结构事实错误仍影响依赖它的判断。无需增加第三次正常调用或推送。

## 6. 最小验证与近期路线

先用少量有代表性的已归档卡和合成反例固定解释原型，不拿少量盈亏拟合权重：同样强方向在不同侵入/响应下允许不同等级；没有强方向但约束论证较强可以 A/S；同一事实调换顺序或换个衍生名称不能升级；增加无关缺口不降级；一个可靠反证可以压过多条弱支持；WAIT 只改变行动边界时不应伪装成市场证据变差。

第一步是复用已有数据产出可检查的命题与证据关系，补齐忠实显示；第二步才是冻结整体证据等级的原型和边界，做同输入复核稳定性与连续用途观察。不能声称已经找到统计最优路径；这是当前数据与个人维护负担下最有理由优先尝试的收束方案。新指标按是否增加辨别力决定去留，不按更多字段、更高分或更漂亮解释保留。

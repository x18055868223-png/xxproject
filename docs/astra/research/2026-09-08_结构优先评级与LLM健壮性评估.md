# D–S 评级的结构适配与 LLM 健壮性复核

日期：2026-09-08。范围：尚未发布的 `codex/astra-signal-rating-v1`，承接方案 06。用户要求评估分级依据、空间约束与动量的先后关系、LLM 使用及显示是否合理。本次运行代码保持不变；以下修订均为研究建议，不能作为已经上线的新规则。

同日用户进一步明确 B–S 应是总体证据等级，不能变成逐级苛刻的理想行情门槛。最新分级与推断建议统一见[总体证据等级与最小推断链](2026-09-08_总体证据等级与最小推断链.md)。本页保留实际代码评估和可复现缺口；第 5 节的初步修法不再代表最新研究建议。

## 1. 核心裁定

1. 当前 D–S 是“LLM 建议经本地限制后的人工行动等级”，不是经验证的垂直价差适配度排序，也不是胜率或净收益排序。此前通过的是指定场景的工程验收；不能扩张成评级判据与全部自然语言推理均正确。
2. 对当前末日/周末垂直信用价差用途，研究中心应是不利侧损失区的侵入风险。空间约束、竞争压力和失效机制优先于寻找强单向趋势。这里的优先是目标与证据关系，不是某个独立空间指标必须先通过，也不是调整一个空间/动量权重比例。
3. 空间约束仍是假设，需要事实支持。价格位于两道墙之间、正 GEX、锚数据可用，均不能单独证明约束有效；强不利流、跳跃冲击或结构迁移可以推翻它。不能先把空间当成可靠常数，再把所有反证降为无关倾向。
4. 当前 LLM 链路的权限限制与失败隔离有可复核实现，但判断语义仍不足以承担独立准入裁决。已发现实际 OK 返回的机制解释问题，以及页面丢失反证的问题。建议在重新发布验收前修复这些具体缺口。

## 2. 为何“方向很强”不等于“价差很舒服”

信用 Put 价差可以在价格不涨的情况下保留全部初始净收入，只要到期价格仍在短 Put 行权价之上；Call 侧反向。最大净收入有上限，继续朝有利方向移动不会无限增加到期收益。因此，模型主要任务不应是把方向强度排得更高，而应解释相关损失区为何不容易被侵入，以及什么变化会破坏这一判断。[OIC Put 价差](https://www.optionseducation.org/strategies/all-strategies/bull-put-spread-credit-put-spread)、[OIC Call 价差](https://www.optionseducation.org/strategies/all-strategies/bear-call-spread-credit-call-spread)。

这个结论不要求全市场对称横盘。下方约束可信且上方开放，可以服务 Put 侧；上方约束可信且下方开放，可以服务 Call 侧。顺向趋势可以帮助远离不利区，反向动量则是检验约束是否正在被侵蚀的证据。

需要区分未来实现波动与报价中的隐含波动：前者涉及路径和到期分布，后者同时影响收到的补偿。垂直价差两腿的波动敏感性会部分抵消，不能从“波动率高”直接推出净收入足够或一定不适配。低波动也可能没有足够净补偿。[Fidelity 价差说明](https://www.fidelity.com/viewpoints/active-investor/bull-put-spread)。

即使终点仍在获利区，期间不利移动仍可能触发退出、造成浮亏或增加成交成本。评级没有指定持有/退出窗口、具体腿和报价时，只能评价当前环境与复核资格，不能证明到期前始终舒适。既定 30/60 分钟观察探针不因此成为信号寿命。

GEX/墙/锚是结构代理，不能当作物理屏障。Cboe 对 Gamma 对冲的说明强调实际净头寸的符号、规模及相对流动性；做市商净正 Gamma 的标准 Delta 对冲倾向逆势，净负 Gamma 倾向顺势。这是机制参考，不能将其 SPX 数据结论外推为本项目 BTC 信号已有效。[Cboe 原文](https://www.cboe.com/insights/posts/volatility-insights-evaluating-the-market-impact-of-spx-0-dte-options/)。

## 3. 当前字母的真实含义

| 等级 | 当前实现的含义 | 当前不能据此推断 |
| --- | --- | --- |
| D | 模型认定不适配，或本地识别窗口明确失效后本轮回避 | 整个市场都差、另一侧也不能研究 |
| C | 有有效判断，但模型认为普通观察即可 | 经统计测得低收益 |
| B | 值得关注，或 A/S 被未解条件、旧等待/阻断、侧别等限制 | 空间一定比 A 差；B 可能只是工作流尚未就绪 |
| A | 模型建议准入，本地引用/质量/边界等检查允许 | 约束已被独立证明、具体报价值得成交 |
| S | 满足 A 的局部检查，模型还给出非重复来源的额外依据 | 已验证比 A 风险更小、增量收益更高或寿命更长 |
| 未评级 | 缺数据、输出失败、无有效模型等级或局部校验失败 | D，或市场本身没有机会 |

`tools/signal_llm_review.py` 中，B 及以上只要求至少一个可用底层市场引用；A/S 明确排除原生 `OPPOSED`，但并不把“结构来源可用”进一步检验为“约束主张成立”。旧 advisory 另检查 containment/fit，但这些状态本身仍由同一次模型响应声明。有效引用不等于引用能推出该主张。

主 agent 通过完整 entry → core → materializer 路径复现：原生结构为 `INSUFFICIENT`、支持列表为空，模型自行声明 containment/fit 成立，Put 理由只有量价偏多且评级依据仅引用 TMVF，最终仍为 A，并生成“可启动人工交易准备”的列表摘要。输入保留可用 Gamma/墙位背景，因此反例不表示整个记录没有结构数据；它说明现有入口未要求模型以这些数据建立可核查的约束论证。

同一市场事实的另一个对照中，温和资金费率作为“额外背景”引用可得到 S；仅在普通支持依据中也引用同一事实，最终变成 A。去重本身合理，但当前 S 对引用分配敏感，没有进一步核对这个背景究竟增加什么适配信息。问题不是 Funding 本轮不投票：有效非投票事实仍可有研究价值；问题是不同来源身份不能代替用途增量的证明。

旧方向和 WAIT/BLOCK 仍参与最终限级，所以当前等级混有环境、证据可用性和行动条件。保持这些限制有兼容意义，但最终字母不能同时被解释成纯粹的市场适配度标尺。即使将语义补齐，也只能先建立机制上的排序一致性；实际适配排序仍须前向证据验证，不能由字母定义自行证明。

## 4. 当前 LLM：可保留的设计与具体缺口

**可以保留：**同一模型的盲读和对照复核两阶段、原生事实独立保存、本地限级、错误时不产生准入、历史卡身份区分、物化与页面共享同一最终结果、不增加正常调用/通知阶段。

**两次调用不是两份独立确认。**两次沿用同一 `model` 参数；第二次又读取第一次结果。它能帮助核对遗漏、比较模型与旧系统意见，但不能靠意见一致证明真伪。

**范围耦合会影响可用性。**两张真实研究复制卡的最终工具首次尝试分别因 Gamma 枚举非法、24 小时基准不是最大情景权重而返回 ERROR；后续各做一次显式人工验收重试才得到有效记录。该事实证明失败被隔离，不能证明一次调用稳定。也不能用这两个例子估计长期失败率。来源：可见项目 `.artifacts/astra-comfort-v1-20260907/final_canaries/` 的失败/成功 JSONL 与摘要。

**实际反证被页面整段抹掉。**事件复制卡 9201 的 Call 原始反证为：“量价、宏观与偏斜均形成上行压力，若考虑与上行方向相反的结构需额外补偿，但候选报价与风险补偿未评估。”`comfortSideCounterText()` 因整段含候选报价词，将其替换为“尚无可用反对说明。”候选经济性确实不应成为信号评级门槛，但前半段的不利压力必须保留。该侧本来就是 UNRATED；不能仅凭此记录断言它只因报价而未评级，也不能擅自替模型补评 D。

**实际 OK 仍存在机制归因问题。**同卡 Gamma 深入分析一处写转正 Gamma 后波动压缩，另一处写“正Gamma推动的加速上行”，同时假设做市商按负 Gamma 方式顺势对冲。按其自身采用的对冲解释，正 Gamma 不能直接推出顺势加速；若要引用其它订单流或头寸变化，必须给出额外事实。当前局部 flip 数值/位置校验没有覆盖这种跨段机制解释。

**可用引用不等于有效论证。**当前规则对时间、来源、Funding 和部分 flip 位置做了硬检查，但没有一般性的事实蕴含校验；反证字段与支持字段也不因形式正确就保证用对侧别。S 的额外分组检查可防同源重复，尚不能证明新增事实与本笔用途相关、或比 A 多消除了哪项风险。

## 5. 本次评估早期的修订建议（已由后续澄清修正）

以下保留讨论过程；关于空间硬门槛、逐级升级和按行动限级的表述，最新方案统一由[总体证据等级与最小推断链](2026-09-08_总体证据等级与最小推断链.md)替代。不应将两份建议并列实施。

1. **先定义空间适配主命题。**每侧明确：约束对象/机制、现价相对结构的位置、来源与时效、当前侵入压力、关键反证、破坏条件。约束可以是单侧，不强制所有来源同向或必须正 Gamma。仅有强有利动量不得弥补核心空间论证缺失。也不能简单将某个当前原生枚举设为唯一通道：若模型提出另一条机制，必须说明对应约束事实与必要输入，不能只自由声明“成立”。
2. **把 A/S 的含义变得可逐项核对。**A 要求必要机制证据成立、关键反证得到有依据的处理、旧行动边界允许。S 还要说明额外事实实际改善了哪一项缓冲或降低了哪一项机制依赖；“多了一个不同来源”本身不够。沿用单套 D–S，但显式说明因环境还是因旧边界被限级，避免低等级被误读为较差空间。
3. **让 LLM 先回答命题，再形成等级。**两次调用均围绕结构与不利侧侵入组织；方向放在其下解释。用一张公开的分级判据表作本地映射，让 LLM 提供证据、异议和逐项判断，减少直接自由选择字母。这个变化仍依赖输入命题是否正确，不能宣称消除了模型错误。
4. **按依赖隔离输出。**同次响应中的核心评级和附加 24 小时报告分别验收；只有评级及其必要事实独立通过校验时，才可保留评级并将错误的附加报告标为不可用。JSON 整体损坏或核心引用不可靠时仍未评级，不从坏文本中强行抢救准入。
5. **事实由本地呈现，解释由模型承担。**可确定的价格位置、时间、来源状态直接引用本地事实；界面只做中文化和呈现。混合反证应在内容契约中拆清，不用命中一个词就删整句的办法改写判断原因。保留可读的“模型未完成有效判断”与“市场明确反对”的区别。
6. **先做判据一致性验证，再做用途观察。**固定事实只增强有利动量，不能自动修复失效空间；破坏核心约束不能反而升级；增加同源重复不能升 S；中性但约束有据不能仅因没有强方向而降级；删去非必要来源不应等同缺关键数据；调换事实顺序不应改变事实结论。模拟只检验语义，不生成盈利证明。真实用途观察覆盖放弃和未评级，不按成功案例挑样本。

这些修改优先于调旧权重、加入第三次 LLM 或扩大交易方案。先复用当前事实与状态形成小型命题表，不另搭一套信号计算或状态机。候选腿、补偿和退出职责仍保留在后续交易层；环境等级本身不能替代它们。既有 WAIT/BLOCK 仍可保留 B 级观察，不统一机械判 D；Gamma 等必要结构事实出错也不能以“附加叙事”为由绕过。

用户本轮明确授权本地实现、模拟输入、真实 LLM 复核与 FMZ 本地交付物审计；暂不推送部署。本授权取代旧文档中本轮不调用真实 LLM 的限制，不扩展到交易、服务器写入或风险模型上线。

## 最小结构

1. **完整冻结证据**：沿用现有 underwriting snapshot 和原始 MAP，保留原合同、来源、时间、数值与身份。旧 snapshot / packet hash 不改写。模拟身份和历史身份不能伪装成当前真实数据。
2. **确定性核算**：沿用现有合同核算。Put 深尾、Call 双盈亏平衡点、手续费覆盖、报价时间与深度、风险支持域均按现有程序处理。缺风险则 μ/M 保持 null；模拟完整账只证明算式和流程。
3. **单份复核输入**：由冻结体派生版本化复核投影，数值只引用程序核算结果；来源按身份集中，事实、解释对象和来源引用区分，避免整份 MAP / 原始内容反复嵌套。记录投影 hash 和实际发送请求。
4. **一个有界复核器**：继续使用现有 `run_review` 的预算、锁、尝试账、原始响应保存、快照绑定与验证器。正常只调用一次；仅传输或 JSON 格式失败允许一次恢复；语义拒绝终止。同一快照重复运行读取原结果，不为改善判断重呼。
5. **本地研究隔离**：显式研究入口可以解释模拟或历史冻结体，所有输出携带研究身份；沿用同一个尝试状态机。研究回执不进入生产 `attach_review`，不改变工作台现有门禁或执行许可。生产默认仍拒绝模拟与历史输入。

不增加多模型投票、循环反思、独立推理服务、第二套持久任务状态机或新风险模型。未来若需改用其他编排工具，必须先证明现有单次函数无法满足需求。

## 本轮真实调用合同

- 凭据只在进程内读取用户指定本地文件，不写入文档、提示词、请求证据或日志。
- 复用已有研究额度账 `.artifacts/astra-underwriting-v20-local-20260925-r4/research_llm_usage_ledger.json`，日上限仍为 **4**；旧日原账已备份，不清账、不换新路径扩额。日切由原预算实现自然处理。
- 本轮一个预先固定的研究候选作为真实调用 canary，正常一次、最多两次 HTTP。其余正常/失败/恢复/幂等验证使用明确标记的本地 transport fixture；不会冒充真实响应。
- 本地研究请求使用 DeepSeek 官方 chat completions 端点及 `deepseek-flash`，固定低推理强度、最多 8192 输出 token；格式恢复关闭 thinking。记录请求模型与服务端返回模型，不更改全局生产默认模型。
- 保存完整输入、原始响应、usage、finish_reason、响应模型、拒绝原因、请求/响应 hash 和额度前后值。真实语义失败即保留失败结论，不改验证器迎合输出。

官方 API 的模型、thinking 与 token 参数见 [Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)。旧 `deepseek-v4-flash` 名称涉及服务端别名映射，不能把请求字符串当成固定权重身份；见 [DeepSeek harness](https://api-docs.deepseek.com/guides/harness)。

## 本地验收与停止条件

- 冻结输入变更被拒绝；相同输入重建的核算和复核投影完全一致；投影缺数据不能通过摘要变成可引用事实。
- 模拟完整账、缺 μ、过期报价、同源重复、不同快照回执、格式恢复上限、语义拒绝、预算不足、重复调用零新增 HTTP 分别验证。
- 真实调用产生可读的本地研究回执或明确失败证据；原始响应和账不可被重试覆盖。HTTP 成功与语义通过分别报告。
- 生产入口拒绝研究输入/回执；`execution_allowed=false`；研究结果不证明市场有效性、风险模型合格、FMZ 在线一致或可交易。
- FMZ 只读审计必须给出根目录与开发树哈希/内部版本、状态生产者与消费者、冗余删除后影响、缺陷与优化分级。实际运行版本若缺外部证据，明确不能由本地文件推断。
- 独立 reviewer 审查后运行最小充分回归，浏览本地回执并输出验收清单。最终不 commit、tag、push、部署或改动 FMZ 交付文件。

# 时段、周末轮与评级效用：二阶轻量研究

本研究延续[研究23](23_接管信号短期期权适配轻量研究.md)和[盈亏平衡研究24](24_盈亏平衡侵入口径与PDF研究交付.md)。原176张接管事件、原卡、旧评审、市场资料和上一份PDF保持原样。本篇新增独立研究结果，不改变FMZ、生产Prompt、评级或交易权限。

## 冻结口径

普通轮仅纳入8小时＜剩余期限≤24小时的114张：偏多26、偏空40、中性48。62张因期限≤8小时排除，仅登记原因，不重新展示其收益。普通轮入场为确认后下一分钟现货开盘，到期为最近一次北京时间16:00。

互斥时段按模拟入场时间、左闭右开定义：美盘后04:00—08:00共21张，亚盘08:00—15:00为0张，欧盘15:00—20:00共26张，美盘前核心窗20:00—21:30共12张，美盘中21:30—次日04:00共55张。纽约日期和休市标记独立保留。亚盘为空是期限过滤后的事实；不解释成亚盘无效。时段与期限紧密关联，不宣称识别了时段的独立因果优势。

周末轮每周六09:00读取此前最近事件，09:01用当时分钟开盘重新选腿，周一16:00到期，持有约54小时59分钟。冻结范围内13轮，12成熟、1未到期；未到期记录和18个未计分情景保留。13张来源卡均在普通114候选中，离线评级去重后不增加请求。仅7月4日观察点的卡龄超过24小时，另作敏感性比较；24小时不是测得的信号寿命。

选腿沿用最近严格虚值的真实行权价，目标宽2000美元为主，1500／2500为对照；仅使用入场前已创建合约，实际宽度逐笔登记。净补偿为实际宽度入场折算价值的5%／10%／20%，10%为主情景，假设已经扣费，不冒充真实盘口。

侵入继续定义为完整币本位两腿赔付超过净补偿，即到期净亏损。短时触及不判负。偏多Put、偏空Call分别保留同卡相反侧；中性两侧独立统计，不事后择优，也不默认同时双卖。

## 保证金与APR

采用单例占用校准的保证金情景，系数λ约0.951659。逐笔估算保证金为λ×实际宽度／入场价格。逐笔回报为净盈亏／估算保证金。

分组主展示采用合计净盈亏／合计估算保证金，便于和资金时长APR对照。逐笔回报的算术平均保留在数据中，不与资金加权回报混用。APR＝365×合计净盈亏／合计（估算保证金×持有天数），另作λ上下浮动25%敏感性。

这不是历史实际APR，不复利、不模拟账户曲线，不包含闲置资金、实际组合抵扣或开仓时保证金。相同数量倍数会同比放大模型中的收入、赔付和保证金，不改变该情景回报率。

## 离线评级隔离

114张卡使用事实包2.1.1、Prompt2.2.1、输出2.2.0。执行前核实并冻结现行模型为`deepseek-v4-flash`，接口为现有DeepSeek Chat Completions。116份响应的模型名均为`deepseek-flash`；这是提供商返回名称，不是权重版本锁定。没有更换模型或生产配置。

模型只接收原卡时可得事实与通过校验的前卡变化，不接收未来价格、交割、盈亏、历史LLM结论或时段偏好标签。3／114张具有原生近端证据，86／114张原卡具有墙位事实；缺项保留，不用新资料补成历史事实。前卡可以来自原档中的事件或固定轮，只作为当时已知市场事实；固定轮不进入研究交易样本。

研究独立目录保留精确卡片、事实包、请求、模型配置、输入哈希、尝试状态、预算及全部响应。总额度与日额度均228次HTTP，并发不超过2；正常每卡一次，传输与格式恢复共用每卡最多两次。语义失败不重试，不为低等级重试。预算损坏、输入变化、模型或协议变化均拒绝继续；重启不清零，已有尝试不能强制刷新输入。

先封存全部评级，再连接收益。未完成评级禁止生成结果报告；可隔离的单侧失败保留另一侧，未评级不伪装成D。周末只引用来源卡时评级，不称为周六重新评估或55小时持续有效。

按D／C／B／A／S及“B及以上”“A/S”分别比较，保留入选、未选、未评级、原方向和相反侧，以及不同日期数。再检查原方向、月份、时段和资料覆盖的混杂；不因小组历史表现最佳就调权或写成生产规则。

## 已核验的数据计算

- 普通轮2052行情景＝114张×2侧×3宽度×3补偿；主情景228个侧别结果。
- 周末轮234行情景，其中216成熟、18未成熟；主情景成熟24个侧别结果。
- 普通轮114张覆盖58个北京时间入场日期、61个交割日期；同日、重叠期限和两侧不是新增独立样本。
- 周末12个完整窗口的平均振幅约2.61%，对应周二至周四同长窗口约4.52%，12／12周末较低。这只说明本批波动背景，不说明周末权利金更划算。
- 主情景周末中性Put盈利6／7，但合计净亏约0.000289 BTC，说明一次较大赔付可以抵消多次收入。

## 最终结果与判断

以下均为目标宽2000美元、假设净补偿10%、单例校准保证金的主情景。侵入按到期净亏损；资金回报是合计净盈亏／合计估算保证金。

| 问题 | 本批结果 | 可以支持的判断 |
|---|---|---|
| 美盘后是否优先观察 | 21张Put 19／21盈利（90.5%），Call 17／21（81.0%）；其余93张分别84.9%和65.6% | 值得作为“04—08时＋约8—12小时剩余期限”的联合观察条件；不能归因于时段本身。短期限仍用相同10%补偿，真实权利金是否足够尚未检验 |
| 周末轮是否适配 | 12个成熟轮Put 11／12盈利，Call 9／12；12／12周末振幅更低，平均2.61%对4.52% | 有低振幅迹象，但不等于补偿更好；中性Put 6／7盈利仍合计亏0.000289 BTC，尾部不能忽略 |
| 较高证据等级是否更好 | Put B 47／54（87.0%），未选51／60（85.0%）；Call B 33／45（73.3%），未选45／69（65.2%） | 局部筛选迹象，尚不足以硬过滤。Put资金回报4.4%对3.0%，Call约−1.0%对−3.8%，改善不等于已经盈利；A/S为0，无法判断 |
| 原方向是否有优势 | 普通66张有方向卡，方向侧51／66盈利，对照52／66；同卡固定Put 58／66 | 不能认定原方向筛选有稳定优势；本批起止价格上涨约22.3%，且无非信号对照 |

Put等级分布：D 4、C 46、B 54、未评级10。Call：D 2、C 50、B 45、未评级17。Put B覆盖47.4%、37个入场日期；Call B覆盖39.5%、27个日期。总计201／228侧有效（88.2%），91张两侧均有效，23张含27个未评级侧。未评级、未选及反方向都保留，不把双侧或补偿情景当独立新样本。

评级差异与资料、方向、月份有关：Put B改善主要在原中性组；有墙位Call子组中B资金回报约−0.5%，未选约−0.2%，并未更好。原卡7月的Call B弱于未选，9月较好。只有3张原生近端证据，均为最后阶段，不能识别其独立增益。周末来源Put B 6／7盈利、未选5／5，Call B和未选胜率均75%；没有一致周末筛选优势。

主情景美盘后Put资金回报6.7%、情景APR5924.2%，Call5.0%、4410.9%；全部周末Put4.4%、708.4%，Call6.2%、980.6%。这些高年化来自持有时间和保证金假设，不计闲置资金，不能写成实际年回报。完整三档补偿、三个宽度与λ±25%的对照随CSV/PDF交付。

最近严格虚值腿可能仍在价格锚带或墙位以内，因此本研究评估的是“信号评级＋这套固定选腿方式”，不是所有基于空间约束交易法的全面检验。

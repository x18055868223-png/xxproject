# 多元思维模型与训练

本框架服务后续信号调整与利用方式研究。**本次交付知识库、提示词和练习，没有训练模型权重，没有改变运行 Prompt，没有产生新回测成绩。** 下列试验均为建议／待验证，不能直接改写交易规则。证据截止日期及版本见[台账](../02_版本与证据台账.md)。

## 1. 从一个可判定的问题开始

先写清“谁在什么时间，利用什么信号，做出了什么不同决定”。主路径至少区分：producer 产生观察、审计/LLM 解释、人工选择用途、执行接受参数、事实反馈。当前自动连接缺口见[进度页](../03_当前进度与差距.md)；不得在研究图中默默补出自动下单箭头。

一次研究只选一个主要目标，例如方向信息增量、无效等待识别、候选排序解释、补偿判断、持仓风险收束。预测准确、解释清楚、执行可靠和净收益是不同目标；要分别测量，不能用其中一个替另一个验收。

## 2. 六个互补模型

这里的“模型”是思考框架。选择两到三个有助于当前问题的视角即可，多角色重复同一资料不构成独立证据。

| 编号 / 视角 | 适用瓶颈与必要输入 | 必问的问题 | 有界产出 / 误用边界 |
| --- | --- | --- | --- |
| M1 机制与因果 | 方向规则解释矛盾；需要输入来源、时序、可能的共同原因和反例 | 因子是结果、代理还是先行机制？若干预它，目标为何会变？市场状态是否同时驱动两者？ | 画机制假设图，列可区分的预测；观测相关不能自动证明干预效果，不凭叙事确认因果 |
| M2 信息与消融 | 因子越来越多而结果不变；需要来源图、基线与删除该项后的输出 | 新信息是否已被另一个字段包含？删除后哪些决定变化？增益来自新增信息还是样本筛选？ | 一个最小消融对照及成本；“熵减”只有定义变量、目标和估计方法后才是测量，未计算时只作研究原则 |
| M3 概率与校准 | confidence、win_rate 或 LLM 权重被混用；需要事件定义、观察窗、版本、完整预测和后续标签 | 这是质量分、排序代理、风险中性概率还是真实频率？70% 指哪个事件？拒绝和缺失如何计入？ | 事件字典、校准图与区分能力评价方案；不能把主观权重合计100当校准，也不能混用触碰与到期事件 |
| M4 控制与状态 | 信号过期、重复响应、错误等待；需要状态、触发、时间戳、转移和恢复证据 | 哪个反馈延迟？相同数据是否反复当新事件？正确风险动作是否被无关 pending 压住？ | 状态/转移表及反例序列；安全性和活性分别验收，不靠增加阻断制造安全感 |
| M5 经济决策与反事实 | 信号能预测但交易不赚钱；需要可成交价格、结构、费用、失败路径、替代决策 | 比“不用信号”多获得什么？风险是否只是转移？尾部改善是否值得成本？净credit与净期望差在哪里？ | 同条件净结果和风险分解；不得用裸腿终值实验证明受保护价差的完整收益，不将未成交mark当实际收入 |
| M6 权威与实际消费者 | 文档说已用，代码或人工行为未体现；需要入口→计算→消费→后果和权限配置 | 值在哪被读？零权重、不可达分支、兼容占位还是有意旁路？谁有资格把参考转成行动？ | 消费矩阵和最小变更影响检查；“未影响订单”不等于“无用”，但审计用途也要有记录 |

机制视角区分观测与干预，参考 [Pearl 原文](https://ftp.cs.ucla.edu/pub/stat_ser/r481.pdf)；信息视角的概念基础见 [Shannon 原文](https://people.math.harvard.edu/~ctm/home/text/others/shannon/entropy/entropy.pdf)。二者提供研究工具，不替本项目的因子增益背书。

概率评估应同时考察区分能力与可靠性；Brier 分数等综合评分并非只测校准，不能单独据其改善宣称校准完成。参考 [scikit-learn 概率校准文档](https://scikit-learn.org/stable/modules/calibration.html)。

## 3. 可复用研究提示词

将下列模板用于后续分析任务，替换方括号。它是离线研究提示词，不是生产模型的替代 Prompt。

```text
任务：检验 [具体瓶颈]，目标消费者是 [人/模块/函数]，目标事件与观察窗是 [定义]。
当前基线：[项目、SHA/文件哈希、内部版本、输入权威、既有权限边界]。
可用证据：[本轮材料]。相关历史卡：[只选必要的 K 编号]。
采用视角：[M 编号，选择两到三个并说明为什么互补]。

请依次输出：
1. 已证事实、机制假设、建议、未知项，明确分开；每个重要事实给出处。
2. 当前输入→计算→实际消费者→决策后果；指出没有证据的连接。
3. 原主张及最强反例；历史负面结论的适用范围，不能扩展成永久结论。
4. 最简单竞争解释：来源重复、标签泄漏、样本选择、费用或权限变化是否足以解释？
5. 一个最小可反证试验：冻结的基线、只改变的因素、时间切分、拒绝/缺失处理、
   目标指标、风险指标、成功/失败/证据不足三种判据；阈值在看结果前确定。
6. 试验结果将如何改变后续决定；什么证据仍不足以进入生产。

不得编造行情、成交、测试结果或来源；不得把建议写成已接受规则；
不得用相同来源的多模型一致制造独立置信；不得从参考信息创造交易许可。
如果证据不足，给出最小缺失信息，不用更多术语代替答案。
```

## 4. 主路径的三个优先练习课题

| 课题 | 研究设计建议 | 何时才算有进展 |
| --- | --- | --- |
| 信号究竟如何被使用 | 决策前记录版本、信号截面、人工原判断、看信号后改变的方向/等待/结构审视/放弃及理由；预先定义不用该信号的对照 | 得到可复核的用途链；先评估信息和决策变化，再评估实际经济后果。没有随机化或可信识别设计时，只报告相关改善 |
| 补偿职责去了哪里 | 固定目标执行线，记录候选的可成交净收入、风险暴露、补偿判断来源、拒绝原因；对照既有VRP与当前门的职责，避免比较不同产品/时间 | 能说明谁承担补偿判断；若没有就明确缺口。是否采用旧VRP是待决定事项，不能先接回再寻找理由 |
| 分数名实是否一致 | 对照 K06/K08/K12，定义目标事件并沿实际调用链检查；对零权重项做受控输入变化，对概率代理做留出期检验 | 能分别裁定不参与该环节、参与但未校准、有意审计旁路、用途未证；不使用一个“有效/无效”掩盖差别 |

数据设计须先冻结版本和时间切分，再观察结果。按 producer/Prompt/执行版本与事件或固定轮次分组；相同 episode、重叠观察窗不得跨训练与留出边界泄漏。记录所有触发、拒绝、缺失及未交易样本，并区分信号级标签与交易级标签。参数调整集和最终留出集分开，留出失败后不能改参数仍称原留出验证。

比较项至少包含既有方法、去掉新增信息、相同信息的简单规则；LLM 评估还应隐藏未来结果、冻结输入和 Prompt，记录输出变化及来源依据。人工复盘有后见之明风险，应优先保存决策前记录。样本量、成本口径和成功阈值需在试验前登记；本次不编造统一阈值。

## 5. 八道公开练习与参考答案

这些题目用于学习和一致性检查，答案公开，**不能当独立留出评测集**。

| 题目 | 合格答案必须指出 | 对应档案 / 视角 |
| --- | --- | --- |
| 1. KPF 的 A/B/C 在一段历史窗口不单调，因此永久删除所有价格锚研究？ | 只拒绝该配置和样本支持的主张；单一状态、重叠与距离基线有局限；保留反例与新的可检验替代假设，不能恢复旧权限 | K01；M1/M2 |
| 2. SLRP 降低触碰风险，所以净收益一定更好？ | 路径风险与经济补偿分开；权利金、费用、结构及退出会改变净结果；单链72h场景有不同方向结果，不能概括为全负或全正 | K02；M5 |
| 3. 短腿Delta为0.2，就能把价差真实胜率写成80%？ | Delta、到期ITM、触碰和价差盈利事件不同；模型测度也不同；当前字段是被排序使用的代理，需重新定义目标与校准 | K06；M3/M6 |
| 4. 三个LLM都给70%，是否说明后验可靠度提高？ | 同源输入可能高度相关；现有权重明确为主观情景；需要独立结果标签、来源核对和对照评估，合计100不证明统计正确 | K07/K08；M2/M3 |
| 5. 置信度改变 preferred_delta，说明它必然改变候选排名？ | 检查delta_fit的消费权重；整合manual默认manual=0，初筛与综合分该项关闭；不把此结论扩展为全部人工参数无效 | K12；M6 |
| 6. AUDIT_ONLY不下单，应直接删除？ | 先明确观察、解释与权限职责；记录是否帮助发现失效或改变人工等待；缺使用记录只能说用途未验证 | K05/K08；M6 |
| 7. 门越多越安全，任何pending都应冻结全部风险动作？ | 根据当前事实分类pending与动作；既验证不重复/不越权，也验证合法风险动作不被无关状态永久压住；未知事实仍按契约阻断 | K11；M4/M6 |
| 8. 新候选净credit为正且工程测试通过，能恢复实盘并称VRP已验证？ | 净收入不等于足额补偿或正净期望；工程测试不证明外部成交或策略经济性；指出补偿责任、目标版本与缺少的外部证据 | K10/K11；M5/M6 |

## 6. 如何训练与评估思考质量

建议循环：阅读相关卡片 → 不看答案作答 → 指出出处和最强反例 → 用另一个互补视角挑战 → 修订一次 → 记录错误类型。错误类型包括事件混淆、测度混淆、来源重复、过度证伪、消费链缺失、权限跃迁与测试边界混淆。

| 维度 | 0分 | 1分 | 2分 |
| --- | --- | --- | --- |
| 证据 | 编造或无出处 | 有出处但缺版本/范围 | 出处、版本与证明上限齐全 |
| 概念 | 混淆关键对象 | 能区分但不影响推理 | 区分后明确改变结论 |
| 消费链 | 只看字段名 | 找到计算但缺消费 | 明确消费者及改变的后果/缺口 |
| 反证 | 只找支持 | 列反例但不检验 | 竞争解释与可失败的试验明确 |
| 落地边界 | 越权或虚报完成 | 有边界但验收模糊 | 建议、试验与生产许可分开 |

该10分表是建议的学习量表，没有本轮实测成绩。含编造证据、将未验证概率当实盘许可、或擅改权限的回答须退回修订，不能用其他维度高分抵消。评估改善应使用新抽取、未见答案的版本化案例，保留失败答案与修订记录；评分者如使用模型，也需抽样人工核对。

训练的产物是更好的问题、证据链和可反证试验。是否带来信号或决策改善，仍需上述独立数据和真实用途评估，不能由练习得分代替。

# 主路径知识库与历史尝试分流

本专区服务后续**模型信号调整及信号利用方式**。它不是把旧资料全部重新启用，也不是实际训练模型权重；本次按用户确认，交付可重复使用的思考框架、提示词、正反例和评估方法。

当前优先入口：[单次信号内容信任协议](03_单次信号内容信任协议.md)。用户已确定垂直价差主方案，当前聚焦每项信号内容的来源、支持、反证和边界；交易框架比较暂后置。

## 主次结构

| 层次 | 保存什么 | 如何使用 |
| --- | --- | --- |
| **主：当前路径** | [当前进度与差距](../03_当前进度与差距.md)中的真实消费链、待补职责和关键校对 | 后续迭代先明确影响哪条当前路径，不能仅因某概念曾出现就重新接入 |
| **次：核心思想与尝试** | [核心思路与尝试档案](01_核心思路与尝试档案.md)中的原则、假设、失败和替代关系 | 提取有效问题与反例，保留证伪范围；历史失败不是删除记忆，也不是永久禁止研究 |
| **练习与突破工具** | [多元思维模型与训练](02_多元思维模型与训练.md) | 用多种互补视角审视同一瓶颈，提出最小可反证试验；不通过角色数量制造“独立证据” |

主次是同一 Astra 整理分支内的内容分层。知识库中的历史尝试不自动获得生产权限，新的训练提示词也不替换运行中的 LLM Prompt。

## 每次只带入相关知识

- 调整信号判断：读取核心原则、K01/K04/K05/K07，以及训练模型 M1–M3。
- 改变信号使用方式：读取当前路径 A/D、K08/K09，以及 M3/M5/M6。
- 遇到选腿或收益瓶颈：读取 K02/K03/K06/K10，以及 M2/M5。
- 遇到漏信号、永久等待、重复动作：读取 K04/K11，以及 M4/M6。

不要把这些卡片一律塞入每次模型上下文。先确定问题与消费者，再选两到三个真正互补的模型；其余作为检查盲点的备选。

## 阅读时的硬区分

“原则”是迭代约束，“机制假设”需要可观测检验，“工程实现”需要调用链，“用途价值”需要消费与结果证据。四者不能相互替代。

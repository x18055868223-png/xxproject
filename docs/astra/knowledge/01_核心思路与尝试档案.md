# 核心思路、证伪与形式化校对

核对日期：2026-09-07。判断依据是原文、具体代码消费和有限历史结果校对；不以文档声称“封版”作为有效性证明。本文保留原始目的，同时校正部分历史论证过强的表述。

## 1. 第一性原则：稳固什么，不预设什么

| 原则 | 当前应保留的内核 | 不能偷偷升级成的假设 |
| --- | --- | --- |
| 面向具体风险和用途 | 观察结构、判断倾向、检查补偿、执行与风险管理分别解决具体问题 | “中性”意味着低风险、稳定套利或总会回归 |
| 事实先于解释 | 锚的有效性需要行为证据；执行状态以订单、成交、持仓和结算事实对账 | GEX 轴、成交密度、LLM 文字就是价格真值或交易所事实 |
| 约束与收益一起考虑 | 保护腿、风险预算、真实摩擦、建仓失败与退出成本必须纳入 | 风险更小或触达更少，就一定更赚钱 |
| 信息要有增量 | 新因素须与已有信息比较，说明目标事件和实际消费者 | 多个名称/分数意味着多份独立证据；“熵减”一词证明价值 |
| 有边界的反馈迭代 | 记录 Trade/No Trade、失败与分歧，按版本和时点检验 | 单一案例可定永久结论；反复调参直到历史好看就是验证 |
| 权限与分工明确 | 方向、定价、执行、对冲和旁路解释各有权威范围 | LLM 一致、高置信或字段完整就可以新增交易许可 |

Gamma 对冲压力、LP 接管与再定价后均衡，是值得检验的**机制假设**，不是无需验证的第一性定律。当前原则总体延续，但“价格已包含一切相关信息”“Delta 就是触碰概率”“综合分数就是概率”不属于可稳固的原则。

## 2. 裁定词的使用

- **限定样本反证**：明确主张在已给配置、时间段、指标中出现反例或未达到预定效果，保留统计和适用范围。
- **工程替代/退役**：路线主动改变，或复杂度不值得承担；不自动等于理论永远无效。
- **保留为诊断**：有解释用途，未达到决策因子或概率模型的证明标准。
- **未验证**：缺少足够证据；不能写成无效，也不能写成可用。
- **名实不符**：字段有真实消费，但名字或文档承诺超出其数学/统计含义。
- **形式化待查**：声称改变决策但找不到消费者；检索范围与缺口必须写明。刻意的 AUDIT_ONLY 不在此类。

## 3. 知识卡片

### K01｜KPF 等级与“历史成交货架会承接价格”

**原问题**：短腿前方是否有可供反应的空间缓冲？问题有意义，但不必由历史成交量密集区回答。

**本次核对的反证**：`kpf/docs/KPF_INVALIDITY_REPORT.md` 与 `kpf_workspace/replay/kpf_replay_calibration.json`。JSON meta 为 56 个 as-of、520 个价位观察，90 天资料内扩张窗。24/48/72h 的 `monotone_A_ge_B_ge_C` 都为 false；72h 回拉率 A=0.307692、B=0.247863、C=0.311688，报告中的小数对应。

**裁定**：保留“该版本、该样本下等级不能按设计排序未来承接/吸附”的反证；KPF 作为整合主线的空间增量因子已退役。A 桶仅 26 个价位、有效天数 14，区间宽；random 非严格距离匹配，近带筛选也不是完整消除距离混淆；不能把单一行情段的观察失败提升为总体不可能性。原报告称“三重证伪”“与样本量无关”等措辞强于其统计证据，本档案采用较窄裁定。

**保存的价值**：距离匹配基线、等级单调性检查、从输出漂亮转向功能增量检验。**重启条件**：改变明确可检验的主张，使用新时期/不同状态和匹配基线，解释实际消费；不因重新命名 A/B/C 就恢复旧权限。

### K02｜SLRP 加宽：路径风险改善不等于经济优势

来源：`kpf/docs/SLRP_FACTOR_EXPLANATION.md` 及 `kpf_workspace/slrp/slrp_ev_kernel_report.md`、`slrp_deribit_ev_report.md`、对应 summary JSON。

历史核实验检验的是短 strangle 配对，而非完整带保护腿、实际费用和对冲生命周期。168 对、DVOL 代理与 Black–Scholes premium 下，RV>IV 条件加宽的全样本 EV 差约为 -0.024/-0.031/-0.035 个现价百分比单位；每个 horizon 的 RV>IV 子集只有 5 个样本。当前链 mark premium 的横截面回放却为 24/48h 负、72h 正（约 +0.059），报告自身判为 MIXED。

**裁定**：当时没有证明新增经济因子优于 fixed delta/IV，因此不接入主线的决定有证据支持；不是“所有 horizon 都失败”，也不是“所有风险效用下都没有价值”。加宽可能改善某些尾部指标，原始报告也列出该现象。若目标从均值 EV 改为尾部损失约束，须先声明新目标、保费牺牲和风险偏好，再做独立检验，不能事后换指标挽救旧结论。

### K03｜“市场已把空间风险充分定价，所以外部信息无用”

整合总纲 v0.3 §2 用市场 IV/Greeks 已覆盖空间风险解释取消 KPF。取消决定可以由 K01/K02 的实际增量检验、耦合与部署成本支持；但“市场定价存在”不能逻辑推出“任何外部变量均无预测或使用价值”。

**裁定**：保留减法决策，撤回普遍性论证。市场隐含分布是定价对象，不是物理分布的保证；新信息仍需与已有价格信息做条件增量比较。Black–Scholes 的定价推导区分风险中性测度与现实漂移，且其模型假设有局限。[Columbia 原始课程讲义](https://www.columbia.edu/~mh2078/FoundationsFE/BlackScholes.pdf)

### K04｜EDB 置信标定与 NeutralRepair

opus4.8 `HANDOFF.md` 记载 v0.5.3 强趋势时置信被压低的实盘观察和 v0.5.4 修复；这是具体旧标定的反例记录，不是 EDB 整体无效的证明。本次未取得并重放对应 FMZ 原日志，所以证据级别是“历史交接记录”，低于当前实验重演。

后续 NeutralRepair 的真实下穿交接、两次新鲜修复、活动位移阻断和 TTL 修复，保护的是**事件定义和时序完整性**。它们可以修漏发/误发，但不单独证明修复事件对收益有效。信号事件正确性、置信校准、使用效果必须分别验收。

### K05｜时区/耐久先验

“三年回测”文件明确只支持 `MARKET_PRIOR_VALIDATED`，不是 `SIGNAL_CALIBRATED`。它检查市场代理事件，不是数十万次真实策略信号。保留审计先验并不偏离分工；把它描述为信号胜率或将时段系数偷偷加入置信则偏离。

**裁定**：保留诊断；真实信号用途增量未验证。后续比较同版本、同触发类别、同目标窗的结果，防止时区仅代理波动或数据覆盖。

### K06｜Delta、触碰概率与 win_rate

旧总纲将 Delta 直接称为市场隐含触碰概率，表述不正确。在无分红 Black–Scholes 设定下，call Delta 是 Φ(d1)，风险中性到期价内概率是 Φ(d2)，而期间触碰又是路径事件；它们不应互换。[定价与 Greeks 推导](https://www.columbia.edu/~mh2078/FoundationsFE/BlackScholes.pdf)

本轮数学反例：S=100、K=110、r=0、σ=0.6、T=30/365，则 Delta≈0.319866，到期价内概率≈0.261057，相差约 5.88 个百分点。这是公式检验，不是 BTC 校准。无需计算真实触碰概率，已足以否定“这些量严格相等”的泛化。

当前重构 `src/planner.py:619` 确实把 `1-|Delta|` 赋给 `win_rate`，并在 `_rank_candidates` 中消费；它是有用与否待检验的排序代理，不能称为已经验证的交易胜率。`hedge_policy.first_touch_probability` 的 `HIGH/LOW` 也不能当作统计置信程度。**裁定：名实不符风险，不是死字段；未修改代码。**

### K07｜“熵减”“多个因子”和独立信息

信息论要求定义随机变量、条件信息和目标分布；多一个字段不自动增加条件信息。项目 soul 的熵减要求可作为问题选择原则，但尚未计算条件增益时要写“待验证”。[Shannon 原文](https://people.math.harvard.edu/~ctm/home/text/others/shannon/entropy/entropy.pdf)

CVD、TMV-F、EDB、LLM 若共享相同源截面，不能按出现次数计独立票。**裁定：原则保留，定量增益未证；要画来源图并做消融，不机械要求所有旁路影响下单。**

### K08｜LLM 主观情景权重与“Bayesian”

[当前 core Prompt](https://github.com/x18055868223-png/xxproject/blob/2c7216229a0f64c95cc37355e6151bf0cee01189/tools/signal_llm_review.py#L708)明确 `posterior_weights_pct` 是主观情景权重，不是已校准胜率。整数合计 100 只验证形状，不能验证先验、似然或校准。不要因为名字有 Bayesian 就宣称存在可复算的贝叶斯统计模型；也不应抹掉代码已经注明的主观性边界。

**裁定**：有意的情景参考，不是自动交易许可；新增决策价值待查。可用之处是明确反证、失效条件和下一观察；危险用法是把主观 70% 直接用于仓位或当独立概率投票。

### K09｜信号到执行连接

旧信号包直接消费路线在 v2.9.9 暂停后，被整合 manual-gate 的人工输入方式替代。执行仍有市场/预算/确认等真实约束，但 producer 不再直接决定开仓。

**裁定**：设计替代，尚未自动闭环。主路径知识库必须补“信号 → 人工用途 → 参数选择”的记录，否则信号研究与实际收益归因可能脱节。不能凭存在 `SignalContextUpdate` 历史 schema 宣称它在当前执行中仍生效。

### K10｜VRP 与净 credit 门

旧 manual-gate 的 `apply_vrp_gate` 有真实消费，新事实优先链已查 planner 则以 bid/ask、手续费、容量、credit、risk/reward 等筛选。未发现等同旧 IV/RV 风险补偿的硬门。

**裁定**：主路径职责待解释，不断言纯工程遗漏或擅自恢复旧门。净 credit>0 不推出期望收益为正；选腿比值和排序也不自动完成 VRP 理论职责。应明确补偿判断由谁承担、何时记录，以及信息不足时是什么状态。

### K11｜可靠性既要避免错动作，也要避免合法动作饿死

事实优先重构宪法要求交易所事实 → 归一化 → 对账 → 状态 → 一个下一意图 → 写门 → 重读。过期本地标记若永久压住真实持仓的合法 TP/对冲，也可能违背第一性目标。

**裁定**：这条原则是对早期“只要阻断就安全”的完善，不是放弃 fail-closed。必须先证明阻断条件或动作授权符合当前事实；同时保留取消/部分成交/未分类 pending 的重读与隔离。

### K12｜人工置信契合项：保留计算，默认排序权重关闭

整合工程 `demo/execution_build_manual_gate/realsrc/src/config.py:39` 的 `PLAN_WEIGHTS` 为 win_rate=0.50、rr=0.50、manual=0.0。`plans.py:98` 把人工 confidence 映射到 preferred_delta，候选记录 delta_fit；但 `plan_prelim_score` 与 `plan_rank` 均将其乘以 manual 权重。`strategy.py` 的初筛和菜单排序实际传入这组权重。

**裁定：当前默认配置下，人工置信的 delta_fit 项不贡献这两个阶段的排序分。** 这是具体的“形式保留／权重关闭”案例，不是整个人工审计输入都无效。方向、范围、预算和确认仍须分别检查；也不能将整合3.0.0的结论套到独立执行或重构版本。

保留该项是兼容、展示、未来选项还是失去用途，当前材料没有足够依据裁决其动机。后续可选择明确标示关闭、删除冗余或开展新试验，本次不自行开启权重。

## 4. 如何判定“只是形式”

对任何分数、字段或模块，按顺序追问：

1. 它声称解释什么目标，改变谁的判断？
2. 真实输入来自哪里，是否只是已有字段改名？
3. 沿生产入口能否找到读取者，以及分支、排序、展示或人工决策的消费证据？
4. 去掉它后哪个输出会变化？这个变化是否改善目标而非仅增加描述？
5. 若设计本来就是审计旁路，是否确实帮助定位缺失、反例或失效条件？若没有使用记录，标“用途未验证”，不标“必然无用”。

本轮已证的主要问题是**名实不符、职责未贯通和结论范围过强**，不能为了满足“找形式主义”而凭字段名称批量判死代码。当前执行的 win_rate 被排序实际消费；LLM 情景参考是刻意旁路；旧 KPF 的增量主张则有真实负面证据。这三类必须保持区别。

## 5. 本次校对后的主次关系

**主线保留**：可观测结构与真实事件、明确风险与补偿职责、正确使用信号、事实优先执行、可反证反馈。**次级归档**：KPF 等级、SLRP 经济因子尝试、旧自动信号接入、历史置信刻度与过时部署快照。

次级知识可以贡献基线、反例和测量方法，但不能未经新证据恢复原权限。下一轮首先解释信号使用链和定价职责，再讨论调参或新增模型。

# MAP 来源语义与四问工作台 v2.4.2 本地修订冻结

本轮以用户要求和上一轮页面审查为依据，修订 v2.4.1 的人读呈现：背景来源和口径不够清楚，摘要只取首个推动及首个分歧，合同优先区域没有解释排序理由。开发仅在 astra-signal-rating-v1 工作树进行；已有原始数据、失败、未提交文件与旧验收保留。

## 范围和候选

- 保留中性纸面、空间门置顶、全宽主工作台和底部审计模块。
- 背景分别说明 Farside 美国现货 BTC ETF 净美元流量、Bitview 持有者资本化价格与兑现活动、币安 BTCUSDT U本位永续原生持仓和已结算资金费、FRED 外部资本条件。
- ETF 原美元流量不改；仅在冻结 BTC 参考价格、币种口径、源身份、非未来及用途资格成立时增加名义 BTC 等值。公式为净美元流量 / 冻结 BTC 美元价，展示折算价和时点，不能声称实际买卖 BTC 数量。
- 资本化价格按 Bitview 源口径中文化，不替换成普通实现价格，不将名义成本线提升为 Deribit 可比支撑。
- 增加确定性的四问摘要：供需与背景推动、主要矛盾与缺口、本单位置、优先观察区与理由。替换页面重复三句摘要；旧冻结数据字段与历史证据保留。
- 优先观察沿用已有合同责任排序，公开理由和观察条件；不是新预测模型。只有合格可比区域才可称市场观察区，仅名义或缺失时明确无合格区域，仍展示合同风险线。
- 页面呈现分别标明合成、冻结回放和当前资料；本轮零真实 LLM。若接入服务器数据，只读已生产结果并保留实际截止，不补造 FMZ 原生门或候选风险参考。
- 用户追加整体数据与因果推理设计整理：采用事实、确定性解释、人工 LLM 意见三个明示层级，并梳理同源依赖和合同方向反证。详见[设计70](70_工作台整体数据与因果推理设计整理_v242_20260926.md)；仍不改变统计、门控或调用协议。

## 评价与停止条件

验证来源标签、单位和窗口；负流量 BTC 等值、缺价/未来/过期/不同价系拒绝折算；Put/Call 几何距离和未选保单；仅名义/缺区域的观察降级；金融账及权限不变；点击区域仅切换本地责任展示；手动回执仍绑定冻结版。

桌面 1440×900 与移动 390×844 检查四问、四背景、价格轴与量价/宏观层的布局、长中文换行、操作反馈和无整页横向溢出。若来源身份不明、币种时钟不成立、出现机器码主回显、统计概率或经济许可被派生、原金融数值改变，停止本轮验收并保留失败。

本轮不训练、调整选侧、改 FMZ 或服务部署、改变交易开关、启用自然卡验证，也不调用真实 LLM。本地通过、已部署的数据服务、工作台消费和经济有效分别记录。新版页面尚未取得本版本“当前本地页面可推送”的确认；完成实现及浏览器验收后保持本地可审阅。

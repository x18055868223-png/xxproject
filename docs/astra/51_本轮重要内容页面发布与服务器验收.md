## 服务器与页面核验

公网入口 `http://13.231.16.198/signal-audit/` 已呈现动态“本轮重要内容汇总”，且页面顶部没有固定 R17 裁定。线上浏览器已验证逐卡动态：09/22 最新卡重点为两侧证据比较、`TMV 0.7325 -> 0.518`、`Gamma $496.32M -> $450.38M`、`Pin 90000 -> 85000`；切换 09/21 卡后，重点变为“两侧暂不可比”及另一组数值。四文件公网哈希可用同目录 `verify_http_frontend.py` 复核；卡身份、评审签名及服务状态的服务器只读审计见 `audit_frontend_server.py.log`。浏览器逐卡观察记录在本次任务中，没有单独生成浏览器日志。

只读 `server_self_check_signal_stack.sh` 在 `SESSION_CONTEXT_REQUIRED=1` 下结果为 `24 OK / 2 WARN / 2 FAIL`，记录见根目录 `.artifacts/astra-card-highlights-deploy-20260923/run_server_self_check.sh.log`。其中服务 `activating` 是当时快照，不能写成全部服务长期失败；最新 `1.6.2` 卡缺 producer-native `near_term_market_context@1.0.0`，自检因此保留 FAIL。因此本轮不能写成服务器全栈通过。

## 证明边界

本次上线只是静态审计页面上线。它证明服务器当前页面能展示动态“本轮重要内容汇总”并移除顶部固定 R17 裁定；它不证明后端 materializer/runtime 已升级，不证明 LLM `2.3` 自然卡消费，不证明 FMZ 更新，不证明 90 日验证开始，也不证明研究或经济 edge 成立。

后端升级另需冻结并验收历史 `llm_review` 不被新版语义规则静默覆盖；若要展示新规则复核，应另存可追溯派生诊断。最新卡缺少的原生近端字段也不能由页面或 materializer 伪装成 FMZ 源端产出。两项都不属于此次静态页面发布的通过范围。

R17 的研究结论仍以[最终交付48](48_R17研究收束与最终交付.md)为准：风险工具有用，业务未成立。失败部署、回滚、自检 WARN/FAIL、旧 LLM JSON 改变风险、尾部和经济资料不足均继续保留。

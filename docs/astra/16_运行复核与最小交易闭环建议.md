# Astra v2.1 运行复核与最小交易闭环建议

核验日期：2026-09-11，Asia/Shanghai。本文基于服务器真实记录与当前部署代码，回答固定轮变化缺口、证据充分性、A门槛和前瞻解释问题。代码为xxproject `5b8b38e`，分支文档头为`2310814`。本轮只读生产、离线复现并保存研究结论，没有修改算法、Prompt、前端、FMZ或部署，没有调用模型重评。下一版方案均为**建议／待验证**。

## 1. 当前判断

当前版本可用于梳理市场环境、辨认侧别差异和准备研究问题；尚不能把字母本身当作“这笔末日垂直信用价差值得做”的充分依据。首要问题是事实口径与交易时间范围未完全闭合，而不是指标数量不足或必须生成更多A级。

下一版最短路线：先修变化兼容与Gamma来源/时点，再把同次评审收束为一张与拟交易期限相联系的准备单。保留D–S；不凭两张卡调整权重、制造A级或恢复独立24小时长报告。

## 3. 固定轮变化缺口：兼容校验误拦

23:00固定轮已有20:12事件前卡，间隔167.6874分钟，两者同品种、FMZ1.6.0、相同市场资料协议。transition已经存在，含8项主要变化、9项原变化骨架。缺口来自比较指纹将整个schema对象纳入，连“事件审计/固定轮审计”的记录类型差异也当作市场资料不兼容。

关键路径：`tools/signal_evidence_v2.py:_schema_fingerprint/_transition_matches`、`tools/materialize_signal_cards.py`的schema记录、前端`renderSignalEvidenceKeyChanges`。保护身份与真实schema版本是正确要求，但记录用途不同不能单独否决共有市场事实比较。

主agent在内存中将比较指纹与ledger派生声明统一排除record_type，保留品种、策略版本、时间和原记录哈希核验，恢复6项变化上下文（包含5项数值变化）：

- 现价77,729.67→77,344.01，约-0.4962%。
- 锚轴/翻转点约-0.0436%，Call墙不变。
- Put墙77,000→76,000，约-1.2987%。

最后一项有实际阅读价值：现价距Put墙扩大，并不一定代表下行更有保障，也可能来自结构位向下迁移。这正是仅看当前空间距离会漏掉的解释。

建议新增版本化的“市场事实比较兼容键”，不要更改旧原记录完整性指纹；事件→固定、固定→事件均覆盖，真实版本/来源哈希/时序异常仍隔离。旧卡若补展示，使用“本地核验的变化，未进入当时模型评审”身份，不重写原评审、不把研究结果冒充原生结果。

producer的`_gex_info_usable_for_signal`不接受partial，故这份看板没有进入GGR的冲突校验，原因码笼统写成STALE_IGNORED。事实包却将GGR推断简写为“负Gamma结构”，又把看板净GEX及部分墙位沿用GGR的22:57:58时间。主agent与独立explorer均复核了这一来源与时点混用。

两组数据不必代表同一个Gamma估计对象，不能因此直接将行情判成强正Gamma；同样不能将GGR的价格位置推断当成真实净Gamma必为负的独立证据。否则会形成“价格下移→被称负Gamma→再以负Gamma加强下行论证”的重复证明风险。

最小修复应分别保留GGR位置推断、看板净GEX、看板状态、各墙位/Pin/锚的实际来源、单位、时点及可用性；按选中的来源继承时效，明确来源冲突/方法差异。partial需按字段可用性处理，不能误写成时间陈旧。不要让正名义额自动证明波动抑制，也不要让来源较旧的事实借用较新的时间。

第一步可在审计输入中修正来源和语义。若以后改变producer对partial的采纳或旧GGR置信门，则属于信号算法消费者变更，应单独对照验证，不混入无声修补。

## 5. 证据数量够用，证据关系仍需校正

事实包已经包含空间位置、锚带、墙/Pin/翻转位、净GEX、量价、4h/12h主动流和价格变化、宏观、Funding、偏斜、数据质量及可比较变化。两张卡的两侧角色合计各引用14个不同事实ID，不能把它们当14份独立证据：方向、净变化、推进标签和流价关系有共同底层数据。

当前主要缺口：

1. 上述Gamma来源/时点，以及固定轮变化事实被误拦。
2. 当前真实输入的价格响应主要是4h/12h净变化，没有实际逐点路径、独立的短时波动尺度或拟交易剩余期限。不能由终点变化解释途中全部经过，更不能证明承接或未来寿命。
3. 部分解释仍把未知当反对。过渡体制表示抑制机制未确认，不等于已确认放大；未见上冲表示风险尚未发生，不等于已经验证了上冲被阻挡。
4. 固定轮Put D的“主要反证”写成未来承接时D判断会改变。这是反对等级结论的条件，不是固定适配命题的当前反证。证据角色已改善，但自由文本仍需围绕同一适配对象。

建议固定区分“当前反对事实”“有具体机制的竞争解释”“缺少证据”“未来改变条件”。市场永远可能反转这种通用句不应单独决定B上限。也无需强迫所有已有指标都在每张卡投票；模型应说明哪些关键证据决定结论，哪些仅背景/未使用及原因。

## 6. B与A门槛的判断

代码没有样本数量门，没有要求全部指标同向或正Gamma才可A；WAIT/BLOCK不压低字母。A/S要求有效引用与约束/压力响应论证，之后才由原阻断、窗口、侧别边界决定是否提示人工准备。

本轮只出现两个Call B有具体原因：证据主要为下行压力和上行侵入未出现，而对于上方约束机制的支持有限。不能据此认定应改成A；也不能据此宣布当前门槛已被验证合理。

但若将“必须先出现一次上冲受阻”“未来压力持续已被证明”作为所有A的隐含门槛，就会过度苛刻。A应允许不同机制组合，表示在声明期限/边界下支持解释较强，且重要竞争解释尚未得到同等事实支持。它不要求未来确定、所有因素一致或边界必须刚被冲击过。

建议重新审视“只有A/S才能开始人工准备”的单一用途：B可以启动候选搜集与比较，A表示更高的环境证据支持；候选是否值得进一步执行仍要看两腿、净补偿和硬风控。不可据此无声撤销当前WAIT/BLOCK或执行约束。环境字母没有校准成交易收益排序，不应成为永远无法跨过的候选研究入口。

## 7. 建议／待验证：下一版最小交易闭环

定位为“证据可信、期限明确的一张交易准备单”，沿用一次综合评审，复用既有候选/VRP/费用资产，不另造总分或长报告系统。

实施顺序：

1. **修事实**：变化比较兼容、Gamma来源与时间；对旧卡只增加明确身份的只读研究/展示投影。验收用本次两张真实卡的冻结输入，原记录和原评审哈希不变。
2. **补用途**：选定拟交易到期日/准备持有窗口，从已有合约与候选接口或人工输入取得。未选期限就明确仍为环境快照。现价距墙是市场结构距离，现价距拟卖出腿才是这笔候选的损益距离，两者分开。
3. **补最少新事实**：优先核验并复用既有短时K线/价格响应、候选IV与报价、费用和到期时间。由此解释缓冲相对短时波动尺度、压力是否正在传导、边界是否随价格迁移。DVOL或年化波动只作粗尺度背景，不能直接当同期限概率区间；缺实际分钟数据就不伪造细粒度路径。衍生量继承同源关系，不增加独立票。
4. **收束准备单**：优先侧及D–S → 本次期限 → 关键结构与最强反证 → 一个候选的两腿/可成交报价/净补偿/最大损失 → 基础情景、破坏情景、重新复核条件。报价与损益由既有确定性函数计算，LLM负责解释；当前许可与人工确认继续保留。

验收先看来源、语义与工作流，不以少数盈亏拟合：事件与固定互比、同源冲突、同置信不同结构、横盘也可强证据、强动量不自动A级、未知不自动否决、一个来源修复只影响依赖主张。一个候选生成一条实际决策记录（做/不做及原因），到期或退出后保留标的期间不利移动及真实报价允许计算的结果。不建设多策略回测平台，也不承诺从极少样本证明收益。

## 8. 前瞻解释：恢复用途，绑定期限

建议在最高辅助决策内加入简短的**到拟交易到期/退出时点的条件情景**，不是恢复独立24h调用：主要情景如何延续，哪种可观测变化削弱本侧，何时需要重新读取当前事实。24h可作为另行注明的背景窗口，不能把每张末日期权候选都强行用24h预测解释。

用户交易跨到次日时，24h结构展望可以有价值；但它必须说明适用时间与证据衰减，不能把当前偏空外推为未来24h必跌，不能用文学式路径或未经校准概率造成虚假确定性。新卡/手动候选复核可更新结论，旧卡继续标卡时状态，不能显示为此刻实时建议。

## 9. 外部机制依据与范围

[OIC信用Put价差说明](https://www.optionseducation.org/strategies/all-strategies/bull-put-spread-credit-put-spread)说明：到期损益取决于两腿行权价和净收入，横盘或适度有利移动也可盈利；环境评级不能替代候选损益。两腿波动敏感性可能互相抵消，不能把“IV越低越好”当通用规则。具体BTC合约应继续使用本项目对应的结算单位和费用计算，不能套用股票期权乘数。

[Cboe对0DTE交易流与做市商Gamma的分析](https://www.cboe.com/insights/posts/volatility-insights-evaluating-the-market-impact-of-spx-0-dte-options)说明实际净仓位及对冲流关系的重要性。此处只支持“Gamma标签/成交量不能单独证明价格路径”的机制审慎，不将SPX研究结果直接当作BTC策略实证。

## 10. 接管结论

优先级固定为：证据血缘和比较口径 → 与拟交易期限/候选的对应关系 → 等级解释及条件情景 → 连续用途记录。暂不按最高仅B放松门槛、不加B±，不因需要前瞻解释恢复第二次调用。工程自检通过与语义/交易效力分开记录。本轮没有执行上述升级，后续实施仍需按项目发布流程交付本地可审阅结果。

## 当前裁定

以一次综合评审解释当前空间、不利侧侵入、竞争解释及变化条件。B/A/S 是总体支持有限、较强、很强；不是逐级增加完美行情条件或概率。证据与行动分开；旧权重、confidence、NR、触发及执行许可不改。停止新卡独立 blind、transition LLM 和 24 小时长报告；保留历史读取与显式离线研究。

## 冻结接口

| 等级 | 总体证据判断 | 与行动的关系 |
| --- | --- | --- |
| D | 有效事实总体反对该侧适配解释 | 本轮回避；不代表未来必亏 |
| C | 可以判断，但没有明显支持优势 | 普通观察 |
| B | 已有值得关注的支持，竞争解释仍有实质分量 | 启动页面注意力，不新增推送 |
| A | 整体论证较强，适配解释更有依据 | 当前本地边界允许时可进入人工准备 |
| S | 整体支持很强，关键替代解释更难成立 | 同样先过本地行动边界，优先复核；不要求更多来源 |
| 未评级 | 必要事实或有效判断缺失 | 不用低等级掩盖错误；合法观察继续可读 |

本轮没有训练统计评级器或贝叶斯概率模型。级别来自有来源的定性推断及本地有效性检查；不能保证换一次模型评审仍得到完全相同字母。复现优先使用已归档的固定输入与响应，不通过多次请求挑选等级。

输入 `signal_evidence_packet@2.0.0`：`identity`（card_id、symbol、strategy_version、as_of_ms、source_record_hash）、`facts` 列表、`limitations_cn`。事实固定包含 `id/topic/label_cn/value/unit/source_refs/source_group/observed_at_ms/window/usable/summary_cn/limitations_cn/dependencies`。只有白名单原始事实和确定性关系，不放旧评分、旧方向结论/建议、完整 rank、完整 transition 或旧解释树。

事实工具 `tools/signal_evidence_v2.py` 导出 `build_evidence_packet(card, previous_card=None, transition=None)` 和 `packet_hash(packet)`。缺失是缺失；数据值为零不是缺失；前次不匹配仅使变化事实未知。`previous_card` 须匹配 transition 的 ID、原始记录哈希、时间、品种与 producer/schema 版本；不得自行合成 transition 原始证明。

评审工具 `tools/signal_review_v2.py` 导出 `build_request(packet, model, recovery=False)`、`build_review(card, payload, packet, model=..., reviewed_at=None)`、`build_error_review(card, packet, reason_cn, model=..., reviewed_at=None)`、`build_summary(review)`。主协议 `signal_llm_review@2.0.0`，当前Prompt `signal_llm_review_prompt@2.0.1`（旧2.0.0仍可读），模式 `single_evidence_v2`。

当前模型响应包含 `side_evidence_ratings` 与 `price_bias`（旧Prompt2.0.0仅前者）。`price_bias` 明确填写价格倾向、依据、反证、改变条件及引用；其方向独立于价差等级和行动权限。`side_evidence_ratings`：`put_credit/call_credit` 两侧，每侧有 `grade`（D/C/B/A/S 或 null）、`basis_cn`、`market_counter_cn`、`alternative_cn`、`next_observation_cn`、`invalid_if_cn`、`evidence_refs`、`counter_evidence_refs`、`unresolved_conditions_cn`。各引用必须指向输入事实 ID。无需固定来源齐全；S 不要求新来源。未知/非投票不自动反对。模型不输出许可和交易参数。

本地评审对象包含 `schema_version/prompt_version/review_mode/status/model/provider/reviewed_at/input_packet_hash`，及唯一 `integrated_trade_advisory`。该对象包含：

- `side_evidence_ratings`：每侧保留上述字段，新增 `status`（RATED/UNRATED）、`validation_reasons_cn`；无效侧 `grade=null`，保留合法局部观察。
- `price_bias`：价格倾向对象1.0.0，含本地ASSESSED/UNAVAILABLE状态及具体原因，参与同一结果哈希；旧卡缺失时不补造。
- `local_action_state`：每侧 `state`（PREPARE/WATCH/WAIT/BLOCKED/AVOID/UNRATED）、`label_cn/reasons_cn`；本地根据旧真实边界生成，不让模型改许可。
- `action_summary_cn`：本地按两侧状态合成；不另算全局等级，不暗示双侧同时交易。
- `market_facts`：输入事实的完整可追溯副本；普通页面只展示中文 label/summary、时点和限制，不输出机器值对象。
- `quote_boundary_cn`：本地固定的候选两腿/报价/净补偿/风控待确认说明，不作为评级必要数据。
- `validation`：局部失败原因及摘要哈希；技术信息只在下载中。

materializer 新摘要字段 `signal_evidence_summary`，版本 `signal_evidence_summary@2.0.0`，包含两侧 grade/status/basis_cn、两侧完整 action_state、action_summary_cn、as_of_ms、input_packet_hash 和 `assessment_hash`。`assessment_hash` 是上述完整 integrated_trade_advisory（剔除 validation.assessment_hash 自身）的 canonical JSON SHA256。新旧协议严格分流；旧 final_grade 仅是旧版行动评级，不混入新筛选。

## 调用边界

默认新主流程每卡一次 DeepSeek v4 flash 高推理，沿用 240 秒/32768 token 请求上限；恢复复用既有非思考交付方式。每个 card + 固定 packet + prompt + profile 的全部 HTTP 尝试共享最多两次额度，跨进程保存；日预算60和锁沿用。不因低等级重试。网络/空内容/截断/JSON或结构格式错误可恢复一次；事实/引用/权限/401/403失败不自动恢复。

新流程不自动重评历史；已存在任何版本成功 sidecar 的卡仍保留原评，指定隔离复制卡可显式验收。只读事实归档及 transition materialization 继续，不因取消 transition LLM 删除变化事实。

# 建仓质量优先的阶段研究设计

日期：2026-09-21。身份：根据用户最新目标形成的阶段设计讨论稿，尚未冻结下一轮实验，不是已验证策略或生产规则。本轮只有资料、数学和代码路径复核；没有新增绩效结果、训练、LLM请求、部署或90日观察。

## 1. 这一阶段应该解决什么

用户要求：最终模型不能依赖完全的选边猜测，应通过统计规律、因果链分析、精算、信号择时和结构择优，提高短期限垂直信用价差的建仓质量。研究可以不依赖黑天鹅单卡概率的精确估计，但不得将未知尾部当零或剔除已发生的尾损。

建议主问题：在相同风险口径下，能否事前识别较适合参与的机会，并对具体结构提供超出简单几何基线的比较信息？选侧是其中一项动作，暂缓同样是合法结果。

v1.2共同风险水平MSE改善、两侧差值MSE恶化，只提供重新检查机会质量的理由；它不证明风险排序、低风险分组或择时已经有效。v1.2三项候选失败及旧X1/X3失败保留，不改名重跑后宣称新的独立发现。

高胜率需要限定为具体虚值信用结构、期限和信用条件；不是所有垂直价差的保证。大额亏损属于损失分布的右尾，Put可能对应价格左尾。主损失究竟由少数极端日还是反复中等侵入贡献，应从完整账本分解，不能先假设只有黑天鹅值得担心。

## 2. 核心切入点：同侧结构差额可缩小需估计的问题

设A为原结构、B为同侧外移结构，保持相同交割日、实际宽度W、名义数量及结算币种，持有到期。用官方交割价S计算完整币本位赔付L。

`结构B相对A的净结果差 = C_B - C_A + L_A(S) - L_B(S) - 额外成本差`

C为两腿信用，费用只计一次。对应的条件期望赔付节省为：

`D(x) = E[L_A(S) - L_B(S) | 卡时可得信息x]`

- 两组均安全：赔付差为0。
- 两组均穿过保护腿：赔付同为W/S，差为0。
- 只有中间的有限交割价格区间，外移才能减少到期赔付。

这使结构比较能够聚焦有限区间的概率质量和赔付深度，无需先准确拟合极远端尾部形状。未知分布仍影响中间区间的发生频率，不能宣称完全不需要概率估计。尾部抵消仅指相对到期赔付，不是风险对冲：两组各自的绝对尾损、持有期间保证金和强平风险继续存在。

外移赔付较低本身是数学单调性，不能当作新发现。需要检验的是：条件信息是否比距离、宽度、期限、简单波动基线更准确地估计D(x)，以及实际少收的信用是否低于有证据支持的赔付节省。无报价时只能输出研究性的信用让渡边界及不确定性，不能批准交易或声称正EV。

这不是已失败PAIR_RIDGE10的重新命名：PAIR比较Put减Call，两个方向的尾部并不相同；此处比较同侧结构。不同宽度、期限、名义或结算条件不具有上述尾部抵消，暂不与首轮主问题混合。

## 3. 将择时拆成可识别的三个问题

| 问题 | 需要固定什么 | 可以检验什么 |
|---|---|---|
| 赔付风险口径上哪些机会更适合进入候选 | 可比期限、距离、宽度、方向及观察机会集合 | 状态是否区分未来完整赔付、侵入深度与尾损；同时报告覆盖和放弃机会，真实参与资格另需报价 |
| 同一机会如何选结构 | 卡时、交割、方向、宽度和名义 | 相邻外移结构的赔付节省及可让渡信用；同卡比较避免混入日期差异 |
| 同一机会是否等候 | 原合约及交割日，或明确记录重新选腿 | 固定合约等待只改变入场信用、持仓时长和路径暴露；到期实际赔付相同。重新选腿则必须另算结构效应 |

不能用到期更近、卖腿更远或事后确认才留下的成功机会，冒充择时能力。未等到确认、确认后失败、数据中断和未参与均保留。触腿、最大不利波动及回撤是路径诊断，持有到期研究不能把它们直接记作已实现亏损或收益。

固定合约等待须同时报告原始BTC赔付，并预先固定比较使用的归一化分母。现有`loss_normalized = payout_btc / (actual_width / entry_price)`随入场参考价变化；不能将这个分母变化解释为实际到期赔付改善。

## 4. 因果链应承担可证伪的职责

每项机制主张需要保存：事前假设、当时可得事实、竞争解释、可观察的后续预期、反证条件、影响哪一段候选赔付。

例如，若声称某侧空间约束在持续，不能仅引用墙的位置；需核对锚/墙是否迁移、时间是否一致、不利压力发生时价格响应如何变化。它产生的是待检验的预期：在可比几何和期限下，相关侵入区的到期频率或侵入深度是否更低。短时响应减弱也可能是流动性不足、压力暂歇或环境继续迁移，不能直接命名为承接。

先使用少量已有共同特征检验背景与近端响应的增量，不增加综合分数或状态模型。自然卡独有的原生空间事实只在有真实历史快照或授权后的前向资料中检验；不能给历史价格补造Gamma、墙或自然卡冲击起点。观察性关系不能仅凭机制叙事升级成已识别因果效应。

LLM只解释适用性、冲突、缺失与反证；统计数值保持原样。统计和机制同源不是独立确认。正常每卡一次LLM、最多两次HTTP共享恢复额度保持；不因等级低或措辞不满意增加调用。

## 5. 最小实施次序及当前资产缺口

### 第一项：已有预测能否识别赔付风险意义上的机会质量

在独立修订目录先冻结分组、权重、评价、候选范围与停止条件，再复用现有逐行年度预测。

按预定的少量风险层级，分别检查统计估计和几何基线；比较时控制期限、短腿距离、实际宽度、侧别和简单波动。不能用全体模型分数分位数创造有利阈值，也不能将共同水平MSE改善直接当成排序改善。若需要新切点，仅用相应训练期确定，并明确整项仍是已看历史上的开发诊断。

输出完整赔付、发生赔付、侵入深度、ES95、真实尾损、交割日覆盖、未选机会，以及年度和日期集中度。频率、严重程度与损失贡献分开；中等侵入与保护腿突破分项后必须能合计回完整损失，不截尾。

### 第二项：最小同侧结构账本

已核对 `tools/astra_joint_dataset.py::select_legs`：每侧选择最近严格虚值的短腿，再按目标宽度选保护腿。`tools/astra_joint_v11_data.py`复用该函数。现有不同target_width主要改变保护腿，并非同侧同宽多个外移短腿的完整覆盖。因此当前预测表不能直接冒充已完成结构择优实验。

可复用现有合约资料、卡时参考价、官方交割价和`payout`函数，在新身份下生成原结构与一个有限外移结构的标签。必须核对两腿在观察时已经挂牌、实际宽度一致及数据可得时间；缺少有效配对就记缺口，不用不同宽度硬配。不需要重下全部行情，也不先训练新模型。

若只能构建标准化研究合约，单独标记为假想几何标签，不称真实挂牌或可成交结构。无同期报价时先做差额标签与条件估计诊断，不算真实净收益。

### 第三项：少量机制增量和真实候选补偿

仅在前两项显示具体剩余信息缺口后，预登记少量可重建的机制变量。旧X1/X3失败作为既有反证，不能以重新命名绕过。可解释机制也必须通过相同候选集合的增量比较。

实际报价只补有限候选两腿及未选对照，不以完整期权链为开工前提。真实组合报价、两腿bid/ask近似、mark和成交分别标识。固定合约等待效果依赖这些同期记录，不从K线赔付补造。

## 6. 通过与停止

本阶段有用的交付是：明确哪些机会差异可预测、哪些结构差额可估计、资料不足时哪里必须留空；不要求每张卡输出交易方向或概率。

- 条件关系若不超过简单几何/波动解释，或控制期限与距离后消失，停止该条件路线。
- 若仅由少数日期支撑或年度反向，明确不稳定；不据此继续搜索更漂亮的分组。
- 风险降低若由覆盖骤降换来，须连同放弃机会评价；不能只展示选中样本。
- 报价消耗了赔付节省，报告没有经济增量；相对改善也不自动代表绝对EV为正。
- 尾部样本不足不恢复逐卡尾部百分比；真实尾损仍进入完整评价，风险情景不赋予虚构概率。
- 每个候选预算及固定终点先记录，失败不自动扩大搜索；所有已研究年份保持开发身份。

自然NR仍为主要实际效果对象，全市场共同截面和新价格事件分别保留身份。原方向、几何、固定Put/Call、统计单用、联合、暂缓和未选继续留账。数据冻结至2026-09-13 UTC、最终拟合截至2026-08-31；加入新资料需另记身份。研究训练如有必要仍最多6CPU、一个本地任务。

本设计不重开v1.2候选、不替换qualified模型、不改变FMZ、触发、权重、交易权限、调用预算或前向窗口。下一实验需要单独预登记；本地页面推送门和实际影子启动门不变。

# Astra 联合研究 v1：实施规格与里程碑

本方案已获用户明确授权，接替讨论34中的“尚未采纳”。当前目标是完成可复现的价格再平衡研究与本地影子版本；经济结论允许有效、未证明有效、资料不足。FMZ保持1.6.2。此前v2.3建议仍保留历史身份，只采用本方案明确列出的职责。

## 1. 分开三个问题

主线：价格位移 → 再平衡候选 → 条件赔付估计 → 机制解释 → 参考价差比较 → 到期验证。

1. 空间：再定价后形成的成交中心、偏离及迁移是否提供约束信息。新均衡可以远离旧价格。
2. 择时：冲击立即、首降温、其后15/30分钟，与可比非事件观察相比是否改善表现。
3. 选侧：统计、机制和联合特征在同一交易基准下，是否优于固定Put、固定Call及等权基准。

高胜率不等于经济优势；没有同期两腿净信用时，只能检验赔付和情景表现。LLM不修改数值模型，不把D–S平均进概率，也不临场修改封存规则。

## 3. 事件与特征

复用当前M-DIE纯计算。闭合UM分钟绝对值≥0.65登记冲击；之后首次≤0.42登记降温候选。保留冲击时刻、首降温、+15、+30分钟四种观察。0.42是新事件观察参数，不冒称现行NR确认门。

同向冲击≤45分钟归入一episode；反向强冲击连续两分钟终止原事件的后续观察并新建事件；最长等待360分钟。缺分钟中断连续性，不跨缺口确认。未降温、再次冲击、反向和过期完整入账。新增未来数据不能修改已经发出的观察。

特征只使用观察时点以前的闭合分钟：15/30分钟成交额÷成交量中心及偏离、相邻15分钟中心迁移、区间扩张与位置、路径效率、同窗净主动量和价格响应、4/12/24小时背景。零成交或缺字段保留缺失；分钟采样与OHLC不能证明逐笔路径或分钟内高低点顺序。衍生关系不增加独立证据票数。

UTC09/15/21保留时钟观察基准，并标记是否处于episode；不能把所有时钟行称为非事件。现行NR独立关联，重合事件不重复计算独立样本。

## 4. 模型与检验纪律

主模型为二部GAM：L2 Logistic估计赔付发生；正赔付Gamma回归估计条件均值，两者相乘为预期赔付。数值为二次样条、5个训练分位节点；Logistic C与Gamma alpha各0.1/1/10。缺失、尺度、节点及编码只在训练拟合。归一化目标为赔付BTC÷(实际宽度/入场价)，可以超过1，不裁尾。

唯一挑战者CatBoost深度3/4、学习率0.03、最多500轮；先在训练期内部尾段确定早停轮数，再以固定轮数重拟合完整2020—2021训练集，2022只用于预登记候选选择。统计/机制/联合三组采用相同目标、时间切分与日期权重。期权增量只能在相同可用样本上比较，不用完整资料筛选效应冒充特征增量。

2020—2021训练，2022选择，2023单次历史测试；先封存模型选择，再开启测试。episode和交割日成组，清除跨边界结果窗口；每交割日等权，两侧、宽度和重复观察不增加独立样本。至少100训练交割日、正赔付至少30交割日，不足只报告经验与不确定性。

模型选择依次核对期望赔付误差、校准、选侧与尾部；一倍验证误差内选GAM。预先指定联合相对统计、联合相对机制两项比较，交割日/连续七日重采样并控制多重比较。没有净报价的检验不能通过净edge验收。

方法依据：[频率与严重程度建模](https://scikit-learn.org/stable/auto_examples/linear_model/plot_tweedie_regression_insurance_claims.html)、[概率校准](https://scikit-learn.org/stable/modules/calibration.html)。这些方法不是“天然最优”的承诺；本轮不追加HMM、深度时序、强化学习或在线贝叶斯状态机。

## 5. 参考交易与影子运行

下一分钟开盘进入，最近一次北京时间16:00到期，严格8小时＜剩余期限≤24小时。Put/Call两侧均保留，最近严格虚值的当时已创建短腿；保护宽度2000为主、1500/2500敏感性，目标不可得取最近可用宽度，等距较窄。该规则不约束交易员。

币本位两腿到期赔付按官方交割计算；净补偿5/10/20%仅为假设情景。有同时间买卖方向盘口及深度时才进入严格净表现组；报价年龄≤10秒、腿间差≤5秒，不为更好报价重抓。选择少赔侧不能在无报价时称更值得卖。

研究侧车从1.0.0登记，保存事件、as-of、到期、来源、参考两腿、模型及训练截止、输入和预测哈希、范围与缺口。前向按闭合分钟去重，每市场最多一次请求；新事件独立影子列表，不触发FMZ卡、通知或LLM。自然审计卡在原单次评审前读取已可用摘要，迟到摘要只补充显示，不重跑评审。

本地训练最多6 CPU线程、一个任务。服务端仅部署标准库推理制品，新增峰值内存≤96MB。导出验证预处理、中间值及最终预测，绝对/相对误差1e-8。训练栈不进入服务器。

## 3. 前序交易用途研究建议：当前后置

以下保留前序研究理由，当前以第0节的内容信任任务为先，不继续展开交易方案、参数或影子策略。

**工作判断**：当前最值得先查的是信号的具体用途与反馈目标是否明确。不能仅因迭代次数多，就预设全面调权可以解决问题。

**建议的短路径**：固定一个可追溯的信号版本和一类现有候选规则，先检验信号用于“接受/否决一笔候选”是否带来增量；这是最小用途试验，不预设过滤一定有效，不代表永久禁止研究选边或退出用途。

1. 先写一页用途约定：决策时点、候选如何产生、实际剩余到期时间、既定持有/退出规则、已有执行与风险边界。信号对未来多久有支持尚未知，不能要求用户主观填一个寿命；先按第4节区分时间语义，再检验固定窗口。不把调整多个环节捆绑进同一次比较。
2. 先审一小批连续、同版本、真实记录，例如10个案例，仅定位数据、语义、时效和消费错误；不得挑最成功或最失败案例算胜率，展示样例不能当实盘证据。
3. 若记录足够，再做前向影子比较：同一时点、同一候选、相同事前风险口径与固定退出规则，仅改变是否接受；基础候选不能先被信号筛选。保留所有机会与否决，不把省下的风险预算重新加到获准交易上。
4. 比较整个机会集合的净结果、被避免的损失、被错过的利润、参与率与尾部/路径风险。没有同期报价则只能检查方向/路径，不能编造期权净收益；影子估算不是实际成交。
5. 用具体误差决定修改位置：数据错修输入，语义错修定义，期限错修用途窗口，方向描述对但交易差查结构/报价/成本，才到证据支持的权重调整。每次只改变一个主要假设，保留原基线。

十个或几十个案例只用于诊断/流程试行，不能认证稳定收益或尾部安全。已有连续观察跨版本或跨市场状态时不能直接合并校准。工程缺陷可单独修复，但须留版本分界；不在试验中静默换模型。

### 历史方案范围讨论：主方案已确认，研究对照暂后置

**前序建议记录**：曾建议主方案与一个替代对照并置研究。用户现已接受垂直价差主方案，并要求暂不讨论交易方式；以下替代对照与升级条件只作历史留档，不表示当前获准开展。既有资产、经验与较低新增验证成本不能被理解为已证最适配或必须收回既往投入。

- 固定的应是完整规则：交易机会怎样产生、如何入场、风险预算、退出/失效处理与不交易条件。只固定“末日价差”名称还没有回答怎样交易，更不要求每轮都交易。
- 若信号描述当前结构但不支持该价差的风险窗口，研究上记为用途不匹配/未知，不强行交易，也不据此判整个信号无效。现有基线必须可以被替换或停止，不能因工程已做就免于经济性检验。
- 若开展一个替代对照，优先考虑单持仓、无加仓扩张的简单方向/突破规则，用固定入场、初始风险规则和跟踪退出检验方向/路径信息；它只是较直接的用途对照，不是已证优于价差或已授权的实盘迁移。假突破、反复止损、手续费/资金费和滑点仍须计入；移动止盈不保证可按触发价成交。
- 常见区间期货网格暂不作为第一新增研究项：需要区间往返、库存/持仓上限和突破后处置的独立依据；模型中性不能自动作为网格依据。已实现网格小利润须与未平仓损失、资金费和清算风险一起核对。此排序不是否定所有网格变体。
- 多方案“同时运行”和“按环境切换”分别评估：前者需要各自效果、相关风险与统一预算，后者还需要前瞻固定且有增量的选择规则。方案名称不同不证明风险分散，不能事后为每段行情选择赢家。
- 对照分两层：同一方案内比较信号使用与否，候选保持一致；跨方案比较使用共同的决策时点与信息集、各自预先固定的机会规则及可比的事前风险口径。止损估计风险不等于硬封顶风险，同名风险预算不证明两者尾部相同。分别保留净结果、风险暴露与维护成本，不直接比较名义仓位、保证金收益率或胜率。
- 升级/替换依据：前向、未参与调参的对照显示实际用途增量或必要的风险改善，成本后结果与压力损失符合预设目标，个人能维护。结果不足保持未知；不因单个好案例、更多术语或现有投入而升级。具体窗口/阈值尚未确定，比较尚未执行。

机制参考：[OIC价差结构](https://www.optionseducation.org/strategies/all-strategies/bull-put-spread-credit-put-spread)、[Bybit期货网格说明](https://www.bybit.com/en/help-center/article/?id=000001829&language=en_US)、[CME止损订单说明](https://www.cmegroup.com/education/courses/things-to-know-before-trading-cme-futures/futures-order-types)。仅用于核对收益/风险机制；具体交易场所规则与策略表现不得直接跨市场套用。

## 4. 信号先按用途解释，不再增加一个总评分

当前直接采用[内容信任协议](knowledge/03_单次信号内容信任协议.md)作研究入口：逐项核对事实、代理、解释与预测；可信程度绑定具体主张，来源核验与结论支持分开。高confidence、因子多数同向或LLM一致均不单独提供概率保证。时间支持仍未知时保留未知，不把状态TTL当寿命；当前不把这一研究重新扩成交易选择讨论。

研究记录先分开四件事：输入是否可用；结构与方向有哪些支持/冲突；前提对哪个时间窗有效、何时失效；是否与具体价差的亏损路径有关。报价补偿和执行许可仍由相应职责独立判断。已有confidence保留作研究变量，不把它当仓位或胜率刻度，也不在本轮修改生产输出。

## 5. 什么证据才允许改变路线

- 改动前写明：原问题、触发变化的具体案例/新证据、被否定的假设、最小替代、预计改变哪个消费者，以及验收/停止条件。
- 只有新事实、可重复错误、前向对照或用户明确改变目标，才足以提出路线调整；单次盈亏、新术语、模型一致或文档变长均不足以独立支持调整。
- 若候选过滤没有显示增量，先检查数据与用途定义；证据足够时可以放弃该用途，保留信号作为观察工具或另立一个可检验用途，不自动扩大系统。
- 样本不足保持“未知”；框架好看、代码通过、历史观察较久，都不能替代明确目标下的验证。
- 每次结论变更同步[路线与规则](04_后续路线与接管规则.md)、[台账](02_版本与证据台账.md)和[进度](03_当前进度与差距.md)。记录新裁定为什么替代旧裁定；用户确认、工作判断和待验证建议始终分栏。

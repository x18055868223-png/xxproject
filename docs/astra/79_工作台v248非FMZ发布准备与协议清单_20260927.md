## 本轮明确边界

本地前端 v2.4.8 修复 all 数值轴域与实际同版合同显示对象不一致的问题。all 包含本轮允许共轴的两侧两腿及 BE，focus 保持当前侧聚焦与域外说明。缺截止或不同截止的另一侧不冒称同版。等价差必须对应等坐标差，标签位置与价格点不得互相替代。

模型、财务计算、执行许可、FMZ 本体与真实评审频率不变。FMZ 内部候选版本仍为 2.0.1；非 FMZ 软件包包含的 FMZ 文件只能作为一致性参考，不代表运行实例已更新，也不在完整安装器的安装目标中。

本轮允许本地代码修复、隔离材料化、打包和拒绝路径验证。提交、tag、推送、部署与服务器权限变更尚未授权。前端必须经本轮浏览器审阅并获用户明确“当前本地页面可推送”后，才可进行项目发布。项目权威为 xxproject，origin 是静态部署辅助镜像；不能用镜像提交替代 xxproject 的完整项目资产。

## 接线与安全入口

已部署 MAP 生产链的选定接线为：

```text
ASTRA_MAP_SOURCE_MODE=producer_manifest
ASTRA_MAP_SOURCES_ENABLED=0
ASTRA_MAP_PRODUCER_CURRENT_PATH=/opt/astra-map-data/state/current_map.json
```

这是一份应与实际私有 env 比对的最小配置，不授权直接覆盖现有 env。producer_manifest 读取生产端冻结记录并验 manifest/hash/源时钟/用途资格；页面 GET 不抓慢源。生产端 KPF 指针 `/var/lib/astra-kpf-light/published/current.json` 不要求映射为工作台 collector 示例路径；只有另选 collector 模式才核验其独立 KPF 路径，不通过软链或数据库共享制造接线。

工作台只绑定 loopback 8895，沿用现有 service 和 Apache/Nginx 路由示例。公网 HTTP 继续只读，评审 token 只能经可信 HTTPS 或已验证 loopback 入口提交。禁止关闭证书验证、放开明文 token 或降低未认证 POST 拒绝条件。GET 工作台、GET review-state、未认证 POST 拒绝分别记录；代理路由存在不等于已在服务器加载。

## 迁移及回滚顺序

1. 获准后先只读取得真实 unit/timer 状态、当前文件版本、代理配置及 producer 健康。若 SSH 仍因私钥 ACL 被拒绝，停在该边界，不擅自改权限或绕过保护。
2. 备份上一个已验软件包、实际 unit/代理/私有 env 配置，保留旧卡、sidecar、状态/冷却/幂等记录及共享 HTTP 账本。私有配置不进入公共包、日志或项目记忆。
3. 更新文件前静止所有会读取或写入被替换工具的工作台/materializer/旧自动 LLM 任务；单位不存在可跳过，停止失败不得继续写入。安装器停止 materializer timer 不会改变其原 enable 状态；记录实际状态，验收前若需要重启服务器，应先明确禁用该 timer，防止重启后自动写卡。data-only 安装器与完整安装器分别执行和验收；已部署 KPF/MAP/接收服务不默认重装。
4. 安装非 FMZ 资产，核对包与 manifest；复核代理语法和私有接线。先只读启动工作台，缺当前原生 FMZ、μ 或其它关键输入时门继续关闭；不强行补绿。
5. 手动评审启用还需既有 token、共享账、冷却、幂等、单任务及协议真实 provider 验收。调用预算不足时等待另获足够预算，不能换账本规避；此前 2.4.6 成功不替代 2.4.7 验收。
6. 回滚先停新工作台及相关 writer，恢复上一个已验非 FMZ 软件与配置，保留运行证据；不回滚/覆盖 FMZ，不恢复旧自动 LLM timer，不覆盖预算或冷却状态。旧 materializer 是否恢复须另有明确决定和兼容验收。

# 牌手完整输入：实现说明

给 Astra。目标是让现有工作台数据引擎产出牌手能直接读的一局输入。这一份说明加上文末案例就是全部要求。不要再设计一套协议。

## 要交付什么

每一局交付一份牌手正文，结构固定为五段：这是什么局、怎么读、规则、本局牌面、读完后另写、若已经持有。规则和牌面必须在同一份里。只改规则、或只留旧的 Player View 字段，都算没完成。

正文是给牌手的，不是审计报告。内部可以用现有结构生成它，但哈希、Schema、字段白名单、Unknown 清单不进入正文。

案例使用 2026-11-11 约 14:00 UTC 的冻结记录，短腿是为摊开路径而外移的演示，不是当时的原选候选。实现时用引擎里的真实候选。实盘短腿通常约 0.35 delta，入区前的路会更短。不要把案例的行权价抄进生产。

## 认知路径

牌手做的是末日轮信用垂直价差。判断的是：这一次交割前，接不接这份短腿责任。不是预测涨跌，不是给未来 24 小时或 48 小时定方向。

空间是骨架。现价走到短腿必须经过哪些位置，这些位置上的库存和已经发生的路径，决定条件是否可接受。运动不另做指标。TMV 是二阶多空压缩，从牌手输入中移除。代替它的是一阶路径：碰到没有，穿过后最远到哪、回没回，现价在哪一侧。

倾向必须形成，否则信息没有增益。倾向只许是「正在靠近还是离开哪些位置，这条路紧还是松」。不许写成看涨、看跌、会突破。紧和松需要剩余寿命的尺度。尺度只取本期到期隐含波动折成的预期波动。没有这个数就写「未提供」，禁止用已实现波动率、TMV 或美元距离自行判断远近。

至少一侧可接受就必须 Accept。两侧都有具体不利事实才 Reject。义务未知、缺尺度、缺成交，都不是弃权理由。有已知的关键数据或明确外源干扰落在剩余寿命内，这局不发牌；这是组局过滤，不是牌面上的宏观分析。

持仓不是新的一局。用入场时记下的条件和破坏标准对照后来的路径。条件被破坏可以在到期前结束。

## 设计要点

牌面按这个顺序写。

1. 责任。指数、剩余时间、两侧短腿和保护腿、责任区间。然后按行走方向列出指数到短腿之间的主要位置，由近到远。覆盖落在入区前的主要 OI 与 Gamma 位置。同一价格的多重角色合并。已在责任区内或远在路径之外的，不充当必经位置。
2. 尺度、体制、翻转轴。剩余预期波动尺度写一次。市场净 Gamma 只写正负和粗幅度。翻转轴写现价在轴的哪一侧、轴在短腿之前还是之后。轴若在短腿之后，写明它不是入区前缓冲。
3. Put 入区前，由近到远。每一站三件事，属性附在同一句里。
4. Call 入区前，由近到远。本期 Pin 写在它所在的那一站，作为属性，单独能看见，不升成主线。
5. 现货成交只放限定：价和流是否一致。不合成方向。

每一站的三件事：

- 碰到没有。写法只用「反复穿过」「穿过数次」「没碰到」。次数可以留在内部，正文不拿次数比较两侧。
- 穿过了：首次穿过后短时间里最深到哪里，那段时间是否回到原侧。现价在哪一侧。
- 没碰到：路径最接近时还差多少美元。有尺度时再写约多少倍。

主动成交附在该站后面，只和这一站并读。没有落在入区前的成交接受区就不写。ETF 流入不写。

路径窗口长于剩余寿命时，写明这是已经发生的路径，不是交割前的预测。「最深」若只覆盖首次穿过后的 1 小时，必须写明，不得冒充全窗最高、最低。引擎若另有全窗最高、最低，在路径段首加一句，不替代各站的穿过事实。

## 什么进，什么不进

| 内容 | 决定 | 原因 |
|---|---|---|
| 入区前位置、属性、OI | 进 | 空间骨架 |
| 穿过、极值、是否回到原侧、现价在哪一侧 | 进 | 一阶路径，用来形成倾向 |
| 到期隐含波动折成的剩余尺度 | 进，只一个倍数 | 让美元距离能放进剩余时间；不判断贵贱 |
| 本期 Pin | 进，只作为所在那一站的属性 | 它常在入区前，埋掉会看不见；升成主线会偏科 |
| 翻转轴的位置关系 | 进，一句 | 用来定位，不作为障碍或方向 |
| 净 Gamma 正负和粗幅度 | 进，一句 | 体制背景，不证明对冲方向 |
| 该站附近的普通期权成交 | 进，附属 | 只和该站的路径并读 |
| 落在入区前的成交接受区 | 进，作为该站属性 | 远处的不写 |
| TMV 及任何多空档、强弱分 | 不进 | 二阶意见；路径事实已经代替它 |
| 已实现波动率 | 不进 | 与路径极值重复，并会诱使和隐含波动比贵贱 |
| Theta、Vega、Rho、Vanna、Charm、Volga、Zomma、Speed | 不进 | 是价格敏感度，不是路还在不在 |
| 微笑模型、锚点评分、路径效率、宏观、ETF 流入 | 不进 | 不改变某一站有没有被穿过 |
| 经济、权利金、摩擦、滑点 | 不进 | 末日期权流动性不稳定，这层不要求牌手判断 |
| 穿越次数的显著性、粘性分数 | 不进 | 单局次数没有显著性；局内不是样本 |

义务方向和强度未知时，正文只保留「未知也不弃权」这一句，不展开 Unknown 列表。

## 读完后牌手要写的

不要在牌面里预写结论。要求牌手另写：

- Accept、Reject 或 Unknown，以及选侧。
- 承担条件：经过哪些位置之后才承担这份责任。
- 路径倾向：靠近还是离开这些位置；没有尺度就写明松紧无法确认。不写涨跌。
- 有效破坏：哪些位置被怎样穿过，或现价相对它们的一侧反转。浮亏、短腿 delta、义务未知、时间变短，单独都不算。
- 两侧各一句。都可接受时说明为什么选这一侧，不比距离、OI 或次数。

至少一侧可接受就必须 Accept。

## 持仓

同一责任的后续时点用同一套路径重生一份短牌面。只对照三句：现价相对入场依赖的位置是更远、更近，还是已经穿到另一侧；剩余时间更短时重读距离，没有新尺度就不临时判断远近；入场之后有没有新的穿过，旧的不算。破坏标准触发就可以在到期前结束。不重选方向。

## 用现有引擎时

从已经有的空间结构、OI、Gamma 位置、Pin、翻转位、净 Gamma、路径穿越和期权成交取数。TMV 可以仍留在工作台，不写入牌手正文。预期波动尺度从本期到期隐含波动来；找不到就写未提供，不要换算。不要新增评分字段。案例里的数字是冻结事实，生产输出必须来自当次引擎，不得回写成案例。

## 验收

拿一个真实时点生成一份正文。牌手读完后能指出指数到两侧短腿之间的主要位置，以及每站碰到没有、现价在哪一侧，不需要再猜中间还有什么。正文中没有 TMV，没有涨跌结论，没有 ETF，没有希腊字母表。尺度要么是倍数，要么明确未提供。

# AI牌手完整输入

**数据身份：真实冻结市场数据 + 明示构造的演示责任。**
这是一轮末日轮信用垂直价差。Deribit BTC，2026-11-12 08:00 UTC 到期，读取时剩余约 18 小时。要决定的是：在这一次交割前，接不接这份短腿责任。不是预测价格。

剩余寿命内若已有已知的关键数据或明确外源干扰，这局不发牌。牌面不分析宏观，也不分析 ETF 流入。本局没有附带此类事件；没有标记，不得自行弃权。

实盘短腿通常按约 0.35 delta 选出。本局为摊开结构把短腿外移，不是约 0.35 delta，这里的美元距离不是实盘短腿的通常距离。四个行权价都在该期原生网格上。不是当前行情，不含事后结果，不预设选侧。

## 怎么读

先看现价走到短腿必须经过哪些位置。每一站只有三件事：碰到没有；穿过的话，短时间里最远到哪、回没回原侧；现价在哪一侧。没碰到，就写最接近时还差多少。

Pin、Gamma 墙、OI 集中、成交接受区都是这一站的属性。成交接受区只有落在入区前才写。主动成交只附在该站旁边，不另算一票。

距离先写美元。若给出本期到期隐含波动折成的剩余尺度，再写成倍数。尺度只用来读距离，不表示贵贱，也不预测会走满。本局没有这个尺度，就不写倍数，也不把美元换成远或近。

要建立的倾向是：交割前，价格正在靠近还是离开这些位置，这条路是紧还是松。必须点名位置。没有尺度时写明松紧无法确认。不要写成涨跌或会不会突破。

缺成交，省略。主要位置少于两个，只说明该侧不够清楚，不自动 Reject。义务方向未知，继续判断。缺尺度，继续判断。

## 规则

现象不是结论。至少一侧可接受，就必须 Accept 并选侧。只有两侧都被具体不利事实排除，才 Reject。没有可接受侧且关键资料堵住判断，才 Unknown。

两侧都可接受时，选入区前结构更清楚、穿过后的去向和现价跟承担条件相符的一侧。不比美元距离、OI 总量或穿越次数。本输入不含经济与成交可行性。接受只表示这条交割前的路径条件可接受。

## 读完后另写

先给 Accept、Reject 或 Unknown，以及选侧。然后只写：

- 承担条件：这一次交割前，经过哪些位置之后才承担这份责任。
- 路径倾向：正在靠近还是离开这些位置。没有尺度就写明松紧无法确认。只写位置，不写涨跌。
- 有效破坏：哪些位置被怎样穿过，或现价相对它们的一侧反转。浮亏、短腿 delta、义务未知、时间变短，单独都不算。
- 两侧各一句。都可接受时，补一句为什么选这一侧。
- Reject 写两侧各自被哪项事实排除。Unknown 只写堵住了哪一项。

不用盈亏改写当时的牌面。

## 若已经持有

对照入场条件和破坏标准，只看三句。现价相对那些位置，比入场时更远、更近，还是已经穿到另一侧。剩余时间更短时重读距离；没有新尺度，就不临时判断远近，时间变短本身不退出。入场之后有没有新的穿过；之前已经发生的不算。破坏标准有没有触发。

条件还在就继续。条件被有效破坏，可以在到期前结束。不重新选择方向。义务未知不能成为退出理由。

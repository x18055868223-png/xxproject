# 07 试答：完全对称合成控制

主模型同上下文试答；本例刻意不提供可区分两侧的路径优势。

Put 76,000/74,000，路径79,000→78,000→76,000；Call 84,000/86,000，路径81,000→82,000→84,000。现价与Pin同为80,000，两侧短腿都距现价4,000、约2倍同一到期尺度，OI数值对称。两侧站点及短腿均未触及，当前分别在Put各位置上方、Call各位置下方；没有穿越反馈可以证明哪边的结构更可靠。

剩余18小时内，Put的有利路径是留在前置位置及短腿上方，不利路径是下穿两站进入76,000；Call对应地是留在下方有利、上穿两站进入84,000不利。两侧都可有条件承担，历史横盘与净流持平没有给任一侧增加优势。

**Accept · Call，明示为等价选择，不声称择出了更优侧。** 比较结果是现有信息确实不区分优劣；选择Call只为完成本次影子承接，不是依据展示顺序、默认偏好、未观测胜率或捏造的结构优势。本例不计作“成功识别相对优势”，也不因平局输出Reject/Unknown。

冻结Call 84,000/86,000，依赖81,000、82,000的空间顺序；承担当前两站均在现价上方的条件，入场后新采样上穿81,000即触发本局Revoke标准。最强限制是这些位置尚未受到测试，不能把未触及解释成有效阻挡；Pin在现价，没有独立方向或吸附保证。

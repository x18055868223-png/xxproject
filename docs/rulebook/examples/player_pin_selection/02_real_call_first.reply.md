# 02 试答：同一真实截面，Call 先展示

主模型同上下文顺序对照；输入为同名 `.input.md`。与01不是两次独立模型抽样。

Call责任67,000–69,000，现价66,767.6在外，前方没有中间站。67,000兼有Pin属性，但仍是一条边界；67,500在区内。此前已穿入、甚至采样越过保护腿，最近12:59返回。剩余约18小时内，维持67,000下方的恢复有利；上穿这条边界后并没有67,500的事前保护。当前约0.18倍尺度的余量与已发生恢复一起读，不能单把恢复或距离作为接受结论。

Put责任64,000–66,000，当前在66,000上方，入区前同样零站。窗口最低66,507.7仍未进入，但这不提供阻挡能力。交割前留在66,000上方有利，下穿后向64,000深化责任不利；约0.61倍尺度的距离只是当前余量。4h/12h下降及现货净卖是其主要反证，不能因最近5分钟上涨而忽略。

**Accept · Put；Call也可有条件建立，比较后仍选择Put。** 两侧都不能借中间结构阻断：Put当前余量与窗口未侵入状态同时成立；Call需维持刚恢复到67,000下方的状态，且现价更靠近这条曾被反复跨越的责任起点。这个组合差异支持Put优先；Call的恢复和负现货流方向则是明确的相反证据，尚不能被解释成剩余18小时必然持续。

Pin为67,000，与Call短腿同位，并不在当前向Put短腿的路径上。接受Put时冻结66,000/64,000及“入场后不出现新进入66,000责任”的条件；新采样下穿66,000才按本局标准Revoke，不以Pin或净流单独退出，也不把历史最低当新增支撑。

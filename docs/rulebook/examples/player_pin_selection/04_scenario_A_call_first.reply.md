# 04 试答：合成情景A，Call 先展示

主模型同上下文顺序对照；行情与03相同，仅展示顺序改变。

Call卖84,000/买86,000，现价80,000在责任外；入区前顺序81,000→82,000。两站被穿过后当前在下方，短腿未见进入、窗口最高83,200。余下18小时维持两站下方有利；重新上穿两站并进入84,000不利。站点首小时未立即回收是反证，不能因为当前在下方就称为稳定阻挡。

Put卖76,000/买74,000，路径79,000→78,000→短腿。79,000与Pin同位，只是一站；两站与76,000都曾被穿过，当前已返回上方。维持返回状态可使Put有条件接受；重新沿下行穿过这些位置、再次进入76,000则不利。当前5分钟向79,000靠近，4h下行与净卖同现只作同尺度窗口的辅助事实。

**Accept · Call。** 两侧都可建立，Call的具体优势是已回到两站下方且责任短腿尚未侵入；Put虽已恢复，却在已被走过的路径上重新接近第一站。双方距离与库存相同，选择不来自这些量，也不是Call先出现。相反证据仍是Call两站缺乏即时阻断表现：本次只承担当前侧别成立的条件，不押注站点必然有效或价格继续下跌。

冻结84,000/86,000和81,000、82,000依赖位置。若入场后新采样上穿81,000，原先“两站位于现价上方”的第一项依赖被破坏，续判Revoke；否则在原条件仍成立时Hold。79,000 Pin与负流不独立决定接受或退出。

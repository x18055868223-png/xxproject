# 06 试答：合成镜像情景B，Call 先展示

主模型同上下文顺序对照；行情与05相同，不是独立抽样。

Call 84,000/86,000当前在责任外，但上行路径81,000 Pin→82,000→84,000都曾被走过，短腿曾进入后返回。到期前维持返回状态有利；再次向81,000、82,000推进并进入84,000不利。当前5分钟向81,000靠近，4h价格上涨与现货净买同现，使这个方向的条件值得收紧复核；两者不是同一个5分钟窗口，不能拼成即时成交因果。

Put 76,000/74,000的路径是79,000→78,000→76,000。两站被测试穿过，但当前处于上方；最低采样76,800，未见短腿侵入。剩余18小时内维持两站上方有利；重新下穿两站后进入短腿不利。库存位置不是保证，尤其首小时未回收的事实需要保留。

**Accept · Put；不是在先读Call可接受时结束。** 双方都可建立，Put相对优势在于当前侧别已离开两处前置位置、短腿保持未侵入；Call虽已返回，却重新朝其第一站接近。距离与OI相同，比较基于路径状态差异。主要反证是Put两站曾失守，若再次下行，不能假设会自动挡住。

冻结Put 76,000/74,000及79,000、78,000依赖位置；入场后新采样下穿79,000，原“两站均在现价下方”的第一项条件被破坏，Revoke。未触发且原条件仍成立则Hold，不用Pin、现货净流或时间单独改写退出标准。

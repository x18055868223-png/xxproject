# 05 试答：合成镜像情景B，Put 先展示

主模型同上下文试答；价格轨迹、Pin和现货流相对情景A反向构造，不是真实行情。

Put责任74,000–76,000，当前80,000在外，入区前79,000→78,000。两站曾被下穿，当前已在上方；窗口最低76,800，短腿未见进入。剩余18小时内维持这些位置上方有利；下行重新越过79,000、78,000而进入76,000不利。首小时没有迅速返回上方，不能把它们称为已证实的支撑墙。

Call责任84,000–86,000，入区前81,000→82,000，Pin在81,000。两站与短腿都曾被上行穿过，短腿曾进入至84,800后返回，当前在下方。维持返回状态仍可承担；重新上穿81,000、82,000并到84,000不利。最近5分钟正向81,000靠近；4h上行与现货净买同现是对应窗口的辅助，不证明余下18小时继续上行。

**Accept · Put；Call可接受，但Put相对更优。** 两侧距离、库存相同。Put当前处在已穿两站的责任外侧且短腿尚未侵入；Call则在曾走入责任的路径上重新接近第一站。Pin与正流没有增加票数，而是提醒Call剩余路径余量可能正在收缩。最强反证是Put站点也曾被穿过且首小时未回，它们没有可靠阻断保证。

冻结Put 76,000/74,000及79,000、78,000依赖位置，接受当前位于两站上方的状态。入场后新采样下穿79,000，第一处依赖位置的侧别被改变，触发本局Revoke标准。该标准来自位置依赖，不来自对上涨的预测，时间缩短、净流或Pin变化不单独退出。

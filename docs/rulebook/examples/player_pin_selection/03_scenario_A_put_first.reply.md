# 03 试答：合成情景A，Put 先展示

主模型同上下文试答，仅用于检查比较行为；全部行情为合成测试设定。

Put责任74,000–76,000，现价80,000在外。下行先经79,000 Pin/OI/Gamma同位位置，再经78,000；这些位置曾被穿过，短腿也曾进入至75,200，后来返回。到期前仍在这些位置及短腿上方有利；重新下穿79,000、78,000而接近76,000不利。两站与短腿现在都在现价下方，支持有条件承担，但不能将已穿过的站点当作必然缓冲。

Call责任84,000–86,000，上行先经81,000、82,000。两站曾被上穿，当前在其下方；短腿84,000未见进入，窗口最高83,200。剩余18小时内维持两站下方、未进入84,000有利；反弹重新越过81,000、82,000并到84,000不利。首次上穿后一小时没有立即回到下方，说明站点并未展示可靠的即时阻断，不能夸大回收质量。

**Accept · Call；Put同样可接受，但Call更合适。** 两侧短腿距离都是4,000、库存数值相同，不能以这些排序。可区分的事实是：当前已处在Call两站下方、尚未侵入Call短腿；Put的两站与短腿都已被下行走过，现在价格又向下方79,000位置靠近。选择Call依赖已观察到的空间侧别与责任未侵入的组合，不需要预言下跌继续。

4h价格下降与现货净卖同现，可辅助提醒Put方向的路径余量收缩；最近5分钟也靠近79,000，但不能声称已有同窗5分钟成交确认。Pin只是79,000这一站的属性。Call最强反证是81,000、82,000曾被穿过且首小时未回，未来重新上行时不能指望它们必然拦住价格。

冻结Call 84,000/86,000，依赖位置81,000、82,000；本局承担条件为维持已回到两站下方的状态。入场后新采样上穿81,000，意味着这条最先依赖的位置被穿到另一侧，触发本局Revoke标准；到期尺度变化用于重读距离，不临时改写该标准。Pin或净流单独变化不退出。

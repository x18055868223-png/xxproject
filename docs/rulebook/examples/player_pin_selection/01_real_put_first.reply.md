# 01 试答：真实截面，Put 先展示

主模型同上下文试答；输入为同名 `.input.md`，不使用后续行情。以下是可核查的判断摘要，不是内部思考记录。

Put 卖66,000/买64,000，现价66,767.6在责任外，入区前零站。窗口最低采样66,507.7，未见进入短腿，不能把这段历史当成阻挡下跌的缓冲。本次剩余约18小时内，有利路径是在66,000上方完成交割；不利路径是无中间站地接近、下穿66,000，随后进入两腿之间。767.6美元约0.61倍本期尺度，不能当作足够远的保证。

Call 卖67,000/买69,000，当前也在责任外，入区前同样零站。短腿与Pin同位；67,500在责任内，不提供入区前缓冲。窗口曾进入且最高采样越过保护腿，12:59已返回短腿下方。到期前维持这次返回有利；重新上穿67,000、再走向67,500与69,000不利。现价距离刚回收的边界232.4美元、约0.18倍尺度，不能仅凭已返回就认为责任已经稳住。

**Accept · Put；两侧均可有条件承担，Put相对优先。** 我比较的是两侧都零站时的边界状态：Put仍未见窗口侵入，Call是穿越后的恢复状态；再结合剩余期限下的当前余量，Put对“短距离内再次跨回已穿边界”的暴露较小。这是这份牌面上的条件取舍，不证明Put有更高胜率；不是因为它先展示或只因距离更远。

最强反证是4h/12h现货净主动卖与各自窗口价格下降同现：这对Put继续维持责任外不利，对Call保持返回状态有利。最近5分钟的小幅上涨不能消除这个反证，也不能把它外推到剩余18小时。Pin在67,000、现价上方，不能说负流正在把价格吸向下方66,000 Pin；期权Put净卖也不作为下行判断。

冻结责任66,000/64,000，依赖合同边界，不把66,507.7历史最低造为支撑。承担无中间站的路径，续判条件为尚未出现入场后新进入66,000责任；新采样从66,000上方穿至下方即触发本局冻结的Revoke标准。净流或Pin变化只提醒复核，不单独触发退出。本次为影子选择，不是下单授权。

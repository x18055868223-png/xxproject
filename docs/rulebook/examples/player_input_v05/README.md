# 示例来源与补充上下文

本目录全部为模拟教学牌局，不是当前实盘数据；不包含预设评估答案。

空间、库存、路径、期权主动成交复用 ../player_view/accept_boards.json；原始 board 哈希与 observation refs 只对应这些事实，不证明补充的TMV或报价。

本例额外模拟：截止1794405600000，两窗价格运动源均已就绪，TMV24h与48h的价格分量均为向上；同标的BTC、同一截止，窗口分别为此前24/48小时。此为明确给定的模拟TMV输出，不声称从原始board重算得到。上线取L5.volume_price的tmvf_24h/48h价格分量（core.trend_direction及就绪状态），核对对应源时间；不使用final_state综合强弱代替价格运动。将其相对每侧短腿的含义追加到position.description，不伪造board来源引用。

本例合同经济信息另行模拟：每侧数量1 BTC；PUT收取权利金0.0040 BTC，CALL为0.0030 BTC；各侧全生命周期手续费与滑点预算均0.0006 BTC，分别剩余0.0034/0.0024 BTC。假定同一截止报价下两腿可按该预算成交、合约数量与到期匹配。费用是本例预算而非交易所费率；剩余补偿不是期望利润，也不证明责任值得接受。

持仓实例须另带冻结入场条件、有效破坏标准和入场截止，再提供同一责任的新牌面；本例处于未下注阶段，无入场条件。尚未实现自动TMV投影或WPEM持仓接入。

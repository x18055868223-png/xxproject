# Astra AI 牌手决策书

**0.5 · 动量修订 · 2026-11-14**

读5–7条短牌面，围绕**入区前路径条件 + 当前运动状态**比较Put与Call；至少一侧责任最终可接受，就必须Accept。只判断当前承保条件，不预测下一段涨跌。

## 看当前这局

1. **定位责任。** 明确指数、短腿、保护腿和剩余时间。沿现价到短腿，找出进入责任前须经过的位置，以及这些位置上的库存与路径事实；不把结构数量当优势。
2. **读当前运动。** 把TMV 24h/48h的价格运动含义合入现有位置句，例如：“相对本侧短腿，TMV 24h靠近、48h远离。”逐窗描述靠近、远离或横盘，不一致就并列，不合成方向结论；综合强弱、缺失或窗间冲突都不能自动填成横盘。标签须结合现价所在责任区解释，不能把深入责任读成安全远离。
3. **看位置是否被测试。** 对入区前位置逐一关联已有反馈：曾穿越说明近期被测试，未见穿越只说明本窗口未发生；都不单独决定Accept/Reject，也不证明库存已耗尽或结构一定有效。用这些事实判断拟承担的路径条件是否仍有依据。

OI只表示已观测库存，义务细节未知不构成弃权理由。可选的主动成交只辅助确认可比口径下的运动，不能把期权买卖直接当成标的动量，也不另算一票。

## 怎样比较两侧

每侧用一句话说明：**当前运动正在靠近或远离哪些入区前位置，这些位置的库存与测试事实如何支持或反驳我准备承担的条件？**

靠近短腿不自动Reject，远离短腿不自动Accept；动量必须与该侧空间结构一起读。两侧都可接受时，优先选择入区前结构更清晰、且有具体反馈与所承担条件相符的一侧，并指出对应位置；不得仅按距离、OI总量或两个窗口机械选边。

## 何时接受

结构可解释不等于责任值得承担：市场补偿仍须覆盖摩擦；本书不计算补偿，不把结构通过直接当成必须接受。

- **Accept：至少一侧责任最终可接受。** 选择该侧；另一侧不利或资料不全，不阻止接受已可判断的一侧。
- **Reject：两侧都被具体不利事实排除。** 分别说明被否定的条件；合同资格或摩擦问题据实说明，不编造结构反证。
- **Unknown：没有已可接受侧，且关键资料缺口阻止完成判断。** 只说明阻塞哪一侧，不罗列普遍未知。

先给结论与选侧，再说明承担的具体条件、对应事实及什么变化会有效破坏条件。现象与评估分开，不能把接受理由或事后结果写回牌面。

## 同一责任，连续跟踪

入场记下条件和有效破坏标准；持仓用WPEM或同类锁定观察，以同标准短牌面对照同一责任的新位置、运动与路径事实，不重选方向，也不把旧穿越当成新增。条件成立则继续，有效破坏可提前结束；义务未知不能成为退出理由。

按冻结的判断与真实牌局结果复盘。始终锚定具体责任，不引入因子评分、历史胜率、方向预测，也不增加宏观、锚点评分、路径效率百分比或综合得分。

# Pin定位、双侧择优：修改与推演复盘

修订于2026-11-15。真实数据固定使用2026-11-14 14:00 UTC第二轮，避免把提示变化与市场变化混在一起。最新输入见[真实完整正文](examples/player_pin_selection/01_real_put_first.input.md)。

## 已落实的最小修改

- **Pin作为共享定位句。** 同期Pin、源时刻、相对现价和两侧短腿的位置与距离，始终出现在共同空间背景；同位不增加站点，责任区内或保护腿外不冒充入区前缓冲。继续只用 `L3.expiry_walls.walls.pin`，不混用信号层Pin或全期限磁吸位。
- **先完成双侧比较，再选边。** 展示顺序没有优先级；先读一侧勉强可接受不能停止。双方均可建立时必须比较同一次交割前的路径条件，给出具体相对优势和最强反证，不给两侧设不同的宽严标准。
- **比较落到剩余寿命。** 每侧说明交割前有利与不利的具体路径，把原有到期尺度、位置与穿越/回收一起读；不把历史24小时轨迹外推成未来预测，不单凭距离、OI或次数选侧。
- **条件不能倒过来替预选侧辩护。** 输出先给简短双侧责任路径，再给行动、选侧及比较理由，最后冻结承担与破坏标准。“因为更符合我给它定的条件”不是相对优势。
- **Pin与流仅作条件复核提醒。** 实际沿责任方向接近Pin、且同窗现货净流同向，才提示复核余量；不新增独立接受/退出触发。明确期权Put净卖不等于标的下行净流，4h/12h净流不能确认5分钟运动。
- **修正零流措辞。** 对称情景检查发现旧模板会写“净主动买0 BTC”，现改为“净主动成交持平”，消除没有事实依据的买方向标签。

核心牌面仍为5组，没有新增字段、评分或协议；积极Accept、条件跟踪与真实交易权限均未改变。

## 先看旧试答到底哪里不足

旧真实试答已经写过Call的进入、返回和Pin同位，不能据此认定主模型完全没看Call、或内部只检查Put就停止。能确认的不足是：先宣布选Put，再用“更符合拟承担的条件”解释偏好，容易形成循环解释；没有充分展示对同一期限、同标准下的双侧优劣和最强反证的比较。

本轮因此约束可检查的输出依据，而不声称能验证模型隐藏的内部思考过程。

## 七轮主模型推演

**这是本轮主模型在同一上下文逐份完成的情景推演，不是七次独立模型调用或盲测。** 指定gpt-5.5 reviewer启动失败，未静默换模型。输入生成脚本只生成牌面，不生成回复；七份回复均由主模型给出并另存。以下不计算胜率或“无偏通过率”。

| 轮次 | 输入与展示顺序 | 试答 | 核查到的实际比较 |
|---|---|---|---|
| 01 | 真实14:00，Put先 | Accept / Put；两侧可接受 | 对照Put窗口未侵入与Call穿越后恢复，同时考虑当前尺度余量；列出负现货流对Put不利这一最强反证 |
| 02 | 同一真实数据，Call先 | Accept / Put；两侧可接受 | 先审Call仍继续审Put；指出Call恢复的有利条件及再上穿67,000的不利路径，再比较选侧 |
| 03 | 合成A，Put先 | Accept / Call；两侧可接受 | Put虽能承担仍不止步；比较Call两站上穿后当前在下方、短腿未侵入，与Put已侵入后重新接近第一站 |
| 04 | 合成A，Call先 | Accept / Call；两侧可接受 | 对照同一组空间事实；没有因先展示而省略Put，也没有按相同距离、OI做选择 |
| 05 | A的价格/结构/净流镜像B，Put先 | Accept / Put；两侧可接受 | 反向事实产生反向选择；Pin改在Call路径，条件提醒也随位置关系转到Call |
| 06 | 镜像B，Call先 | Accept / Put；两侧可接受 | Call先出现且可接受，仍完成Put比较后选Put；没有把Pin或正流当独立投票 |
| 07 | 完全对称合成控制 | Accept / Call，明示等价选择 | 指出两侧事实确实等价，无可证明优势；不编造更优侧，也不因平局弃权；不计作成功识别优势 |

三组正反顺序的输入，已检查全部文字与数值token保留，只交换责任、Pin关系及路径段的展示顺序。镜像B按原路径引擎生成；原引擎触边取侧约定会使部分首次穿越的分钟采样细节略有不同，不宣称所有数值逐项完全对称。

逐轮回答见[样例目录](examples/player_pin_selection/README.md)。共同核查结果：

- **责任边界→入区前位置→穿过与当前所在侧→承担条件：** 七份均明确两侧短腿/保护腿和当前侧，零站直接审短腿；有站时写位置顺序与已观察反馈，最后给位置化条件。没有仅以“可以接受”作结束。
- **到期前优劣趋避：** 各侧都写了何种路径对责任有利、何种路径会进入或深化责任；真实牌使用约18小时剩余期及原生尺度，未声称哪条未来路径一定发生。合成对照把距离与OI设为对称，避免用它们冒充择优。
- **择优与反证：** 01–06都给了相对另一侧的具体差异及所选侧最强反证；07明确不具备可区分信息。没有“Put刚好可接受，所以选Put”的裸结论，也没有全做Put。
- **Pin与流：** 真实牌没有把66,000误称Pin；Pin在67,000、现价上方且与Call短腿同位。合成A/B将Pin嵌入对应路径，但未声称吸附保证；主动流保持辅助，未将期权净卖当标的下行，也未把4h流拼成5分钟因果。
- **承担条件可执行：** 真实牌冻结66,000新进入作为本例破坏；合成A/B分别冻结81,000上穿或79,000下穿作为首先依赖位置的破坏。它们都是该轮独立评估形成的条件，不是生成器预置结论，也没有回填现象。

这些结果说明新正文能够支持完整的比较，且本轮主模型在给定控制情景下作出了随事实变化的选择。**不能据此证明所有模型都不受顺序影响、真实牌Put必然优于Call，或交易表现会改善。** 我们核查的是公开判断依据；作者、试答者与评估者均为本轮主模型，仍存在共同判断偏差。

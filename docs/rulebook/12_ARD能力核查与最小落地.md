# ARD：能力核查、最小落地与真实A/B

修订于2026-11-15，真实测试仍冻结在2026-11-14 14:00 UTC左右。原一阶路径基线保留不动。

直接使用：[B版完整输入](examples/player_ard/generated/B_input.md)。对照：[原版A输入](examples/player_ard/generated/A_input.md)、[A试答](examples/player_ard/A_reply.md)、[B试答](examples/player_ard/B_reply.md)。B仍是原5组事实，只在空间背景旁增加一段ARD和必要读法。

本轮最重要的事实是：**本期Pin有入场前历史；旧空间评分不是Pin停留率；本次4小时窗内Pin从68,000变为67,000。** 这局可以补充锚变化和价格相对位移，但缺少可靠的窗前半宽，不能生成真实停留率或邻域离返故事。A/B均为Accept / Call，ARD没有被包装成已证明的选侧优势。

## 1. 当前能力审计

| 对象 | 真实实现与核查结果 |
|---|---|
| 本期Pin生成 | `astra_expiry_gamma_v1.profile`：按同expiry的期权OI、IV、forward和剩余期限计算无符号美元Gamma，在本期预期波动范围内取Call+Put Gamma最大的行权价。它与信号层有效Flip不是同一个锚；Pin改变不能直接归因为OI改变或庄家行动。 |
| 工作台更新与缓存 | `astra_workbench_v20.refresh_expiry_gamma`正常约5分钟更新，失败保留旧值和原钟并标注最近失败；`state_dir/expiry_gamma.json`是当前缓存，不是完整逐次历史。 |
| 入场前Pin历史 | `astra_research_archive_v1.collect_structure`独立收集未来56小时内到期，写`structure/YYYY-MM-DD.jsonl`，不要求候选锁定或持仓。通常30分钟一行，剩余6小时内每次10分钟timer采集。真实15NOV26文件从11月13日即已有记录，不能说Pin只在WPEM锁定后才存在。 |
| 旧空间评分 | `compute_anchor_gravity`对最近144根成交量柱的绝对归一化偏离取截尾均值，再转换分数；不是半宽内停留分钟比例。至少20个有效值预热，首尾各去1个值；窗口不等于固定4小时。 |
| 旧半宽 | `compute_band_half`使用最近60根成交量柱的去趋势标准差、Spring和现价裁剪，默认约3至6倍标准差、下限现价0.1%、上限1.5%；无有效标准差时回退0.5%。本轮只复用已实际输出的半宽，不在ARD中重新生成回退值。 |
| 历史回看风险 | 正常逐柱追加后，旧ND不整体重算，但同一deque可以混合不同时点的Flip与半宽。`_evaluate_anchor_for_completed_bars`处理待补历史柱时使用处理当时的GEX快照及当前标准差，不能据此声称每根旧柱都面对当时已知锚。代码也没有Pin迁移历史用于这项评分。 |
| WPEM | `CandidateResearchArchive`按同candidate采样，`compose`可回放，`compose_current`只读当前点。当前服务实查为`active_locks_only`，历史采样`false`；它不提供本期Pin每次刷新的独立时间线。ARD复用结构归档，不另建WPEM或第二份Pin状态。 |
| 分钟价 | 现有`Deribit.index_path()`取`btc_usd`两日分钟路径；归档常在结算处理时保存`index_path@0.1`。本轮继续使用上一版已截断至读取时刻的原始分钟数据，绝不读取后来低点或outcome。 |
| 半宽历史是否可直接用 | `astra_underwriting_fact_context_v20._space_context`未投影`band_half`，故旧case及该投影的WPEM上下文都没有它。实查当前FMZ配置指向的原生环文件只保留近期截面，没有目标窗前记录；另外旧native缓存也不覆盖目标窗。不能反推半宽、借今天的半宽或另造阈值。 |

结论：Pin历史与价格数据已有；历史采集可用时间和方法版本没有完整留存，不能直接当成因果对齐资料；目标窗半宽在已核实输入中缺失。无需重建Pin采集系统，只补原记录的必要元数据。

## 3. ARD计算口径

- 窗口固定为两侧较早读取时刻之前4小时；各expiry单独读取。一分钟采样只用截止前原价，无插值。跨expiry、非`btc_usd`、相同时间冲突值均不并入。
- 每个价格采样只取**当时已经可用**的最近Pin；沿用结构归档现有40分钟缺口限度，超过即缺失。按最近已知记录作阶梯参照不等于断言两次归档之间Pin真实未变，240/240对齐也不代表工作台每次刷新都有历史。
- 半宽只接受窗前已知、原生明确输出且在既有40分钟FRESH口径内的值；整窗固定这一美元半宽，以Pin为中心。原值经过上限裁剪时保留事实标记，不另设否决。它复用了原尺度，**不等于把原Flip评分改名**。当前才形成、过期、缺失或无法确认来源钟的半宽都不回看使用。
- 停留率是有效、等间隔分钟样本中落在`Pin±固定半宽`内的比例；分母不含缺价或过期锚样本，同时显示有效/应有样本数。半宽缺失或历史方法不可比，不给整窗比例；比例也不是连续交易时间或吸附概率。
- 离开/返回只在同价Pin、同来源/方法、连续分钟的同一片段内确认。Pin跳变、方法变化或断点切段，不能把“锚移到价格附近”当作“价格返回”。保留最近离开与返回；旧返回后又离开时明确未返回，不能拿旧回收证明仍围绕。
- 分别报告价格位移、Pin位移和`价格−Pin`变化。仅当完整可比采样中的绝对相对距离逐样本不减且端点增加，才描述采样距离持续扩大；一般只说端点变化。同向端点变化不证明跟随或因果。旧方法版本未冻结时只读位置差异，不归因实际结构、模型或参数改变。
- 当前Pin与两腿的关系继续由原Pin位置句给出，程序不解释对哪侧“有利”。ARD与原穿越/空间评分共用数据，不增加独立票数，也不新增任何自动动作门。

## 4. 真实新增正文

详见[生成的ARD段落](examples/player_ard/generated/ard_excerpt.md)。关键数值：

- 10:00:18—14:00:18 UTC窗口，所见Pin从68,000到67,000；最近变化观测于10:30:25，采集回执在10:30:26确认已完成。
- 240个分钟价格均可按最近已知锚对齐。覆盖端点价格位移−568.3美元，Pin位移−1,000美元；价格减Pin从−664.2变为−232.4美元。
- 10:31起同价已知Pin片段，价格减Pin从+207.2变到−232.4美元。不能将整窗距离缩小解释为向一个始终固定的67,000回归，也不能将后段的跨侧端点变化说成持续迁离。
- 缺窗前原半宽，不计算真实停留率、最近邻域离返或“持续吸附”；历史方法版本未冻结，不证明锚移位的原因。

## 5. A/B试答与信息增量

两份输入同一冻结市场状态；A逐字等于前版，B只多一段ARD和读法。两次试答由主模型顺序完成，非独立盲测。项目固定gpt-5.5的explorer和reviewer均尝试启动但账户不支持，未降级替代；主模型负责源码、原始记录、测试及公开判断依据核查。

| 核查项 | A与B对照结果 |
|---|---|
| 围绕、回归、迁离 | A不推断机制；B补出锚也变过，明确端点跨侧不是持续迁离，邻域离返资料不足。 |
| 停留率当吸附概率 | B没有捏造比例，也未从缺数据推出安全。计算测试有比例场景，文案不称概率。 |
| Pin驱动价格 | B明确两者位移不能证明因果；没有把共同下移变成预测。 |
| 与具体责任绑定 | B说明当前Pin不在Put向66,000的入区前路径上，与Call67,000同位；没有新增缓冲。 |
| 原路径与量价反证 | 两版都审查Put同向下行/净卖、Call已回收但仅0.18倍余量，没有被ARD转移注意力。 |
| 同源重复计票 | B指出12:59短腿回收与跨越同价Pin属于同一路径，不能多一票。 |
| 选侧与承担条件 | 两版均Accept / Call，最强反证仍是Call小余量；检查时钟和原破坏条件不变，未将ARD加入退出门。 |

**本局证明了事实和解释范围有增量，没有证明选侧、条件质量或经济表现提升。** A本身没有犯固定Pin历史回看错误，因此不能故意把A写差来制造B优势。历史行情只用于事实/格式回归，后续独立冻结样本才可能检验决策增益。本轮不新增这类研究系统。

## 6. 验证、使用与剩余缺口

相关**163项测试通过**，覆盖Pin稳定反复回归、稳定迁离、锚价同向迁移、锚跳变伪回归、缺历史、同短腿/不在入区前、方法变化、分钟缺口、后到数据、未来半宽与固定条件回归；原生producer测试直接验证无持仓时已写Pin来源、方法、状态与真实可用钟。CLI、函数与离线复现输出一致；没有把选侧写成测试预期。

在工作树`.worktrees/claude-astra`复现A/B（输出新目录）：

```powershell
python docs/rulebook/examples/player_ard/reproduce.py --out .artifacts/ard-ab-replay
```

普通新归档自动读取同expiry的结构行：

```powershell
python tools/astra_player_input_v1.py --archive ARCHIVE_ROOT --expiry-day YYYY-MM-DD --round r2 --out hand.md
```

`--ard-history`可显式提供结构历史；`--ard-band-snapshot`可提供窗前原生半宽；`--without-ard`保持A版。未知可用钟的旧记录不会凭tick钟拼接；本例兼容处理只适用于有同次真实采集回执的记录，不泛化猜测其他历史。

正文现在可直接给AI。当前尚未部署采集补丁，现网仍不会原生写新时间/方法字段；本地重放和新代码producer已验证。完整停留/邻域离返需要在窗前保留已有原生半宽快照，本例无法补回；分钟采样也看不到分钟内穿越。WPEM今后可读取同一结构历史与纯计算函数，本轮没有改其采样或另维护Pin状态，也没有声称在线续判已接通。
